# 视频关系监督怎样进入完整LoRA，以及这次尚未证明什么

2026-10-15，主讨论科学分析。对应唯一active design `docs/designs/video_effect_parameter_compiler_20261015.md`，包括实施前四格联合探索修订及task25的OOI监督缺失裁决。本文解释已定合同，不增加实验、损失、选择规则或验收前置条件；当前没有本批性能结果。

## 1. 本次改变的是教学内容的监督对象

上一稿终局Q的问题不在于网络小或监督少。若完整当前状态、任务目标和继续策略已给定，环境的最终成功分布本来就不必再依赖教学视频。额外输入V没有规定它应学习视频中的哪种操作内容。共同专家LoRA监督则允许同task所有视频映射到同一个终点；它确有控制正例，但不能单独解释某条视频的操作内容怎样帮助当前真实失败。

新合同把这两种要求分开：共享Phi学习从RGB及exact language读出实际手、物体、关节的变化；任务内编译学习怎样让当前policy更接近这一条视频展示的关系过程，同时保护自身任务成功。前者的标签是合法non-held视频实际对应的物理量，后者的标签是当前自身动作干预产生的真实后果。两者都不需要知道新教学的teacher actions。

这不是已证明的“操作知识理解”。关系标签规定了可检验的可见内容；观测模仿目标把这些内容变成实际选择依据。视频观察不到的力、稳定接触、因果必要顺序和未展示的替代策略，没有因为坐标准确或顺序保留而自动得到监督。

## 2. Phi为什么比一个接受V的终局Q更受内容约束

实际输入是每帧两相机的512个source投影patch，加合法文字embedding。Phi以手和匿名实体query读取这些有空间位置的patch及语言，然后沿每个slot的真实帧顺序处理整段视频。loss中的位置、旋转、语义、presence、joint及hand-q来自原28任务的真实标签；相邻变化项要求预测实际变化，而不是只拟合一个场景均值。Hungarian匹配只确定监督索引，不把teacher实体表作为新condition输入。

语言可以决定关注对象，也可能提供很强的任务先验。然而在相同语言和相同帧索引对应不同真实物理关系时，只依赖语言和索引的预测不能同时正确拟合这些标签。这个约束是有条件的：它需要真实标签存在差异且图像足以识别差异；对遮挡、对称、近似共同轨迹或监督不足的情况，不能推出模型一定使用了有用视频信息。

时间RoPE只进入Q/K，还有一个明确的算子边界：假设每帧进入时间模块的slot value完全相同，单独改变注意力权重仍只能得到相同value的加权和，不能凭空生成一段不同的物理运动。实际视频使帧表示不同后，时间attention才有内容可选。这约束了纯时钟生成，但不能排除把手的外观变化当作阶段线索、学习平均操作过程或依赖其它视觉捷径。

OOI监督只是一种公开对象关注列表到可表示实体的proxy，不等于所有因果相关实体。task25的region真实owner是被原registry排除的main_table，所以该task的8条视频整组OOI监督缺失；不能把region名字中的stove当成实体真值。224条几何/运动教学保留，OOI有效条件216条，各原损失组系数仍为1/8。这限制了“已经提供完整关注对象监督”的主张，不用伪造标签填平它。

## 3. 视频参与标签的定义，这个标签仍有偏

在固定教学预测及固定实体匹配后，完整自身轨迹H的分数是

`R_V(H) = 2 * success(H) + exp(-DTW_distance(H, Phi(V,L)))`。

对完全相同的一对真实分支H+、H−，把V替换为另一条呈现不同关系过程的教学，可能改变视频项的差值；不保证每一对分支都有变化。这与只向终局Q追加一个可能被忽略的输入不同：教学内容参与了训练目标的定义。任务内的真实success仍来自自身环境，不来自teacher标签或离线专家结果。

这个结论也有可失败条件：Phi可能把两段视频读成相同目标；错误实体匹配可能把真正变化对错对象；DTW可能把非必要运动、错误高度或手的靠近当作有利变化。即使GT关系目标也偏向特定示范路径，不能保证最优任务策略不变。接受规则按四个适应初态的真实成功数优先比较，减少了这四个状态上视频项挤掉成功的机会，但它不能保证新初态保持能力。

因此本批无视频臂回答的是“在相同优化器与预算下，这个视频关系评分是否带来增量”；它不等于充分训练的强语言RL，也不能排除一个另行训练的语言关系模板有同样作用。两个正确视频的独立读出、预测/真值评分对照和任务分布会缩小解释范围；完整视频必要性仍不能只由胜过该无视频臂宣布。

## 4. 真实动作分支怎样提供可用余切

在一个真实当前状态，原生policy给出raw首块均值a。连续30维使用`a_cont ± .1*u`，夹爪使用以`sigmoid(a_grip)`为概率的五维Bernoulli；四个分支是这两种采样的Cartesian组合。每个分支都保持相同历史和当前完整LoRA，首块之后由同一当前policy继续到真实结束。

每格的边际都是同一个Gaussian连续动作×Bernoulli夹爪联合分布。Gaussian均值的score为`s*u/.1`，Bernoulli logit的score为`z-p`；实际完整结果乘这些score，再对四格等权，就得到该首块探索目标的梯度估计。父完整episode分数是在新u/v之外取得的baseline，不能把相关的另一格冒充独立baseline。

逐步executed mask表示哪些动作实际发生；未执行的45个native动作以及成功终止后的动作没有环境后果标签。连续坐标经过clip也不要求对环境或clip求普通导数，因为分差是在采样后的真实环境中取得。四格反相关及相同未来noise用于降低方差，不增加独立样本数。

这仍是局部目标：当前访态、当前完整历史及后续policy在分支中固定；探索夹爪与部署的无探索控制也不同。将这些余切沿当前轨迹求和，不是整个未扰动部署policy的精确梯度。候选完整再试和新初态读出承担了这个近似是否有用的检验。

## 5. 余切怎样进入实际38-target算子

已核现有实际消费者：`src/ember/writer/practice/execution.py`保留50×32原生noise，用十次`z[k+1]=z[k]-.1*v_Lambda(z[k],tau[k])`得到输出，只执行前5×7；`PolicyContexts.activate`在每次forward及checkpoint replay重绑完整因子。不是给一个额外动作头训练后再称它改变了policy。

令`F_Lambda(o,L,epsilon)`为上述十步积分及冻结unnormalization后的raw首块，`J = dF/dLambda`。实际actor loss为负的`mean_e[T_e * dot(F_Lambda, stopgrad(g_e))]`，故反传给完整因子的方向是`mean_e[T_e * J_e^T g_e]`。每条episode只均匀抽一个决策点，乘其真实决策点数T_e恢复该episode的决策和；四episode仍等权。

梯度穿过十步积分。具体递推为

`D_Lambda z[k+1] = (I-.1*D_z v[k]) D_Lambda z[k] - .1*D_Lambda v[k]`。

38个target是18层action expert的q/v投影及action_in/action_out投影。第l层实际算子为`W_MT,l h_l + c_l B_l A_l h_l`，其中`c_l=alpha/rank`。q的修改影响当前action token怎样读取上下文，v的修改影响被聚合的内容，输入/输出投影影响flow latent与动作表示的转换；这些作用沿原生非线性计算共同形成J。不能把单个target的参数变化直接等同于某种物理行为。

没有teacher动作恢复，没有选择一条成功动作轨迹后做MSE/FM拟合。采样动作只用于询问真实环境；更新消费的是分数差所定义的余切。外部干预自身也不是部署policy的新执行器，最终只保留一套完整LoRA。

## 6. 为什么同一固定LoRA可能迁移，为什么仍可能失败

部署时LoRA不含teacher帧时钟。它修改的是每次真实自身输入产生的hidden映射，因此有能力在新状态下产生不同动作，而不必逐帧重放教学。但“固定参数能够闭环”只是可表示性，不能推出这几个适应状态学出的修改会迁移。

把因子写成`Lambda=Lambda0+S*u`，S就是现有`PolicyContexts.prox`从初始A与MT dense update定义的固定每因子单位。对一个暂时固定的正预条件P，局部一步的形式是

`delta a(x') ≈ eta * G(x') P sum_e[T_e G(x_e)^T g_e]`，其中`G=dF/du`。

这个表达式用于说明依赖，不是把实际Adam简化为无历史SGD的精确等式。它说明新状态的动作变化由新旧状态原生Jacobian的对应决定，而不是由视频目标好看或旧状态分数增加决定。相似的物理阶段如果在source/MT hidden中形成可复用敏感方向，可能带来迁移；阶段、对象绑定或hidden方向不一致时，也可能无效或损害已有成功。

初始化非零A、零B使首步A梯度为0而B可学习。对单个层，首步写入依赖`A0*h`；在新hidden上产生的对应含`h(x)^T A0^T A0 h(x')`，并被实际下游导数和十步flow耦合调制。这给出了一个具体限制：初始适应不是任意改变每个输入方向，它继承了低秩因子及预训练hidden的几何。后续B非零才可能同时修订A；有限预算未必足以重建一种陌生控制能力。

本批不另加Jacobian探针或kernel测量来证明这个解释。真实候选在适应初态的收益，以及其固定LoRA在分离新初态的保持/得失，就是当前已有完整消费者可以给出的判断。

## 7. 已有结果怎样约束本轮的解释

关系G/F的真实关系监督与GT替换未产生总体修复，所以不能说缺一个几何标签就解决旧问题。本轮实质差异是下游消费当前自身反事实结果，直接修改当前完整参数；不是将关系再映射到一个共同专家终点。LocalField、joint action-effect及原生J的历史也使“有梯度就有效”不能成为本轮结论。

物理干预局部J的旧误差比.29736和Goal/Long残余说明线性后果近似有边界。本轮用真实完整续跑取得分差，减少了对那个局部物理模型的依赖；成本及方差并没有消失。G/BA端点已有强控制正例，而多实践和纯V/VL的seen提升没有稳定held增量，说明新增反馈必须产生真实、保持能力的参数修订，不能只增加输入或训练量。

本批冻结后按以下因果位置消费同一批原件：预测关系评分与GT关系评分的分支排序是否矛盾；评分改进有没有变成候选的真实改进；四适应状态改进能否转到分离新初态；收益是否跨task/suite并保留MT已有成功。每一步只改变对应解释的支持度，不能把数个不同条件下的局部正例拼成完整方法通过。

若预测与GT排序冲突，先承认目标读取可能误导；若二者一致而真实成功不变，关系模仿目标、探索范围和参数更新仍未区分；若只在适应状态提高，就限定为未取得迁移。没有结果之前不预定增大模型、补动作标签、换DTW权重或延长同一假说。下一项工作必须由完整结果改变方法判断，而不是由某个局部指标可继续改善来决定。
