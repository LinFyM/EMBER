## 现在真正需要解释的事

EMBER 希望将 **exact language + 正确、action-hidden 教学视频**，在 rollout 前一次编译成完整 task-conditioned LoRA，
使冻结的 π0.5-LIBERO source 在未见初始化完成任务。目标是初次生成就有效，并在强 MT 参照之上获得稳定、广泛的实际能力；
部署后逐任务优化不是当前目标的替代。

目前最强原 T 的单 checkpoint Validation8 为 **161/400**，强 MT300 为 **153/400**；相邻较晚 T 点为
147、154、160、154、159，尚无稳定显著的优势。另一方面，selected T 的 correct / same-task-other / public-only /
cross-suite-wrong 为 **161 / 150 / 103 / 65**：教学条件确有功能作用，不能把它简单判为完全忽略视频。
但这些差额也不能自动证明学到了可迁移的操作规则，或把所有条件收益归为新操作知识。

上次专家建议共同学习条件读取与写入；实际条件读写 C 将两侧参数、时序解释器与真实 FM 共同训练，
seen 从 **91→115/144**，held 从 **137→140/400**。后续动作校准、动作/效果信用、关系监督、共享 RL、
特权示范动作参照及在线视频控制诊断，也没有给出比强参照更可靠的完整方法。
这些实验分别约束了不同假说，**并未共同证明唯一根因，更没有证明目标原则上不可行**。

主讨论需要承担的缺口是：积累了大量局部事实，却未将它们收敛成能解释正反结果、预测下一完整方法的认识。
这次审阅应允许质疑我们的问题分解、数据与学习设定、架构基础和决策方式。

## 本次审阅的核心问题

**在当前输入与监督下，怎样才能把教学中的操作证据学成能在新任务自身状态上调用的控制规则；
现有方法究竟在哪些联系上缺乏支持，什么完整原理最值得保留、撤换或重建？**

完整提示词要求先重建“为什么尝试—实际改变什么—正反结果—为什么转向”的历史，再重点分析：

1. 为什么可表示 MT 式共享解、又有额外教学信息，却没有稳定明显超过强 MT。
2. 为什么已有真实视频作用和 seen 学习，仍没有可靠的跨任务控制迁移。
3. 现有数据、监督与梯度是否足以教会所需联系，什么捷径也能降低训练误差。
4. 为什么容量、读出和局部闭环的正例反复没有变成完整方法。
5. 主讨论的推理与投入选择出了什么问题，应保留、撤换或重建什么。

这些是需要专家解决的困难，均不预填根因。请优先形成一个有证据的完整方法判断及可失败预测，
而非未排序的模块清单；也请指出我们可能问错的问题。

## 材料的边界

- 近期正式400指固定 Validation8 的单 checkpoint；历史的不同 split/source、seen144、局部32与新增训练留出16不能混排。
- 本次只导出已经存在的数据并重算统计，没有新模型 forward、环境步、标签或 checkpoint 选择。
- 远程可审源码、配置、数学关系及导出成败；第二轮补充部分原有逐步状态、接触统计与RGB图，但未上传完整权重、
  全部RGB／连续轨迹或X/H/余切大张量。CSV 是原始结果的字段投影，并非物理轨迹的完整独立复现。
  功能 JSON 是既有原件读回，不能声称专家重跑了它；具体覆盖与有效性边界见本轮补充。
- 历史记录中的服务器绝对路径只标注来源；本目录新增 provenance 使用 run-relative 标识。
  可直接访问的证据在 Git 内给出，不要求专家访问服务器。
- 本轮核对发现9月17日审计有仅本地可读的原件链接；现补40份开发记录、复用6份旧导出并修正46处入口。
  封存控制审计排除；远程材料覆盖主要科学判断，不声称包含全部早期原始资产或可完整重跑每个实验。
- **Test 和 shuffled/reversed 封存结果排除在本次方法审阅之外**，即使历史可见也不得反哺设计。
- 只保持最终部署与信息墙：合法教学视频/语言、冻结 source、rollout 前一次产生完整单套 LoRA、
  视频动态证据有必要增量。具体 memory、rank、A/B 分工、层对应和 decoder 都可质疑。
