这次工作的主体是数学与机制分析，不运行训练、环境或新实验。我们不要求证明当前设计正确，也不预设必须换 Transformer、删除 B₀或继续当前递推。

EMBER 的目标是：以冻结 generic π0.5-derived source policy 为底座，用 exact language 和 action-hidden 正确教学视频，
在 rollout 前一次性生成一套完整 task-conditioned LoRA，使机器人从新初始化闭环完成任务。
视频动态证据应提供必要条件增量。部署没有 teacher action/state/reward/task ID、环境试错、逐任务梯度优化或第二套 adapter。
训练可用授权 non-held task 的 actions；Validation/Test 不产生梯度。任务目标不是复现教师轨迹，也不是让内部指标好看。

希望你先独立重建并判断下面这条链，再对照主讨论的假设：

```text
合法视频与语言 → 公共策略下真实 X/H → 地址与变化 Value → 条件矩阵 M
→ 唯一 (A, B0+M) → 自身状态下全层 hidden 与十步动作生成 → 真实 FM 的学习信用
```

分析须具体到特征来源、实际依赖、算子和学习条件。请检查哪些性质能严格推出，哪些只是归纳偏置，哪些需要尚未证实的语义假设。
共享 A 不等于教学与执行已经对齐；去掉 B₀不自动破坏共享 A；M 是实际 B 的一部分，但当前 delta 递推不是生成 B 的唯一方法。
局部秩、条件数、梯度夹角或 frozen 改动变差，都不能单独证明整体能力上限或 fresh 共同学习失败。

请形成你自己的主要判断，重点包括：

- 现有教学特征和逐帧变化能区分什么任务相关信息？它们如何、在什么条件下足以确定对新自身状态有用的参数作用？
  把可观察性、表示能力和实际学习联系分开；不要给未验证 hidden 命名成对象角色、接触或技能。
- 共享 A、公共 B₀、Value 的 P/C/D/O、固定 probe/native 读取和 M 递推，各自增加了什么约束，又失去了什么自由度？
  哪些约束有助于迁移，哪些可能制造混叠、覆盖、错误归因或难学的共同映射？请给出条件、反例或必要推导。
- 哪个限制最可能解释现有完整证据，包括 T 的正例、T/U 排名随阶段反转、成熟平台、same-task 换视频交换，

  说明竞争解释和你对各解释的信心，而非只列所有可能性。不要把有限train面板或参数投影比例解释成未见task性能。
- 据此提出你最支持的完整改进机制。说明合法输入如何形成特征，如何写成唯一 LoRA，如何作用于自身执行，
  真实训练梯度为什么有机会学到并保持这种联系。允许保留或撤换当前模块；参数少、改动小、形式漂亮都不是独立优势。
