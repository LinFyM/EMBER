## 怎样使用证据

本包优先复用已入Git的旧原件，补入近期仅存在运行目录的小型报告、指标及原始结果字段投影。新增文件的来源、保留字段和核验结果由`evidence_index.json`登记；来源使用run-relative标识，不要求远程读者访问服务器。

每个结果必须同时看起点、训练任务范围、教学条件、实践与query初态、单点/相邻点、完整方法/组件以及参照口径。不要把训练域G的425/576、完整Writer的400行、source首写的144行或控制器参考混成一个排行榜，也不要把不同阶段的分数拼成端到端资格。

原始大权重、全量视频/连续状态、H/X/余切大张量和数据集不放入Git。逐行成败可独立重算，不意味着远程读者可以重跑物理仿真、重新验证全部视觉解释或检查所有梯度。不能从已导出的汇总冒称已独立复核未上传的张量。缺口和有意排除项在证据地图中明示。

历史Test及shuffled/reversed封存控制不作为本次新设计或选点证据；仓库中已有的历史可见性不解除此边界。本包不新增这些样本、结果或标签。运行中的资源/进程信息也不构成科学证据，不把主机私有配置或凭据带入导出。

权威顺序：Owner最新明确要求 → 当前Owner要求文件 → 项目科学合同 → 本次状态 → 历史方案。这里的整理不能新增Owner没有要求的固定轮数、冻结课程、低维公共空间或形式审批门槛。
