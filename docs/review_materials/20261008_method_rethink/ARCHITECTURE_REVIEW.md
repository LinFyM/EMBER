# 第六轮架构审阅：把教学、实践与固定LoRA连成可实施方法

2026-10-08，主讨论在阅读[第六轮正文](EXPERT_RESPONSE_ROUND6.md)、核对相关实现与数据合同之后形成的判断。
本页区分专家候选、已核事实和待解决的问题；没有新增实验结果，也没有把候选登记为active design。
Owner最新原话与实际后续提问见[第4、5节](OWNER_FOLLOWUP_REQUESTS.md)，新专家直接委托见[最新提示词](EXPERT_PROMPT_FRESH.md)。

## 1. 当前核心与主讨论取舍

完整适应系统应当从教学获得实际有用的操作知识，以自身实践检验和修正，再将能力落实到唯一固定LoRA。
整个过程替代旧Writer，可以含共享模型、搜索、过程状态及任务内优化；整体性不要求单网络或对环境全程反传。
不能把收益主要来自额外任务内训练、视频仅有形式输入的系统，当作已经解决EMBER问题。

第一阶段先让最终完整策略明显超过强MT；不要求先胜过充分语言适应或补齐全部视频controls。
这是推进顺序的放宽，没有取消视频实质贡献这一核心。从第一个有信息量的完整循环就应观察：
视频改变了什么有用尝试或学习，实际反馈又怎样改变其使用；按具体机制选择少量公平证据，避免全部推迟到末尾。
输入敏感、参数不同、wrong下降或单个局部正例都不足以证明这种贡献。

主讨论继续支持“教学引导行为发现，再学进同一LoRA”的大方向。第六轮更具体，但尚有四条关键联系需要设计到可计算、可学习。
新专家可以重构或删去不能成立的模块，应独立选择一条完整主设计；这些审阅意见不要求把第六轮所有模块变成必需项。

## 3. 四条需要补齐的联系

### 3.1 操作字段与现有监督之间

合法训练中有物体位姿、关节开度和接触等信息，并不等于已有“必须先释放”“保持打开直到下一阶段完成”等过程标签。
第六轮用到的真实目标 `g*`、保持条件和事件标签，需要具体构造规则、数据来源和消费者。
一次成功轨迹能显示发生了什么，却通常不能单独识别每个动作或保持条件的必要性。专家已经承认这一点，缺口在于如何落实。

新设计应分开直接字段、可通用计算的关系、仅从视频推断的假说、需要实践辨别的条件，以及当前无法支持的字段。
允许通用关系词汇和控制先验；不能为held task手工写正确操作程序，再归因于视频理解。
若所需监督不能从已有数据或有界新增交互获得，就应删减或改写表示，而不是把未知标签藏进损失符号。

### 3.2 视频操作与实际命令之间

`A_tilde = E(A, S, z_k, xi)`仍将关键联系封装在符号内。
当前控制合同为20Hz的增量OSC_POSE，7维实际动作；原生policy每次给50步、实际执行前5步。
视频里的局部路径、期望位姿和控制增量并非同一个量：坐标、尺度、当前姿态、夹爪时序及跨replan反馈必须连起来。
例如“沿把手上方退出”“先松手并保持抽屉打开”，需要说明从视频证据到实际前5步的计算，及与当前动力学/接触不符时如何修订。

自身RGB与真值state可以校准视觉读出，但这不自动回答“为什么这次操作方式更有效”。
实践须具体改变下一次视频解释、候选构造或学习目标，区别于仅让感知坐标更准确。
这不要求另建通用世界模型，也不禁止实用控制原语；应说明先验提供什么，视频和实践真正决定什么。

### 3.3 比较操作方式时是否偷换了目标

第六轮提出 `w(h) ∝ p_vis(h) exp[β Q(S, E(A;h), g(h))]` 来安排操作假说。
若只改变同一目标下的操作方式，比较具有清楚含义；若 `g(h)` 也变，高分可能偏向更容易的弱目标。
“抽屉打开过”比“手退出且抽屉仍保持打开”容易，Q更高未必说明视频理解更好。
这是条件性风险，并非宣称该公式在所有使用方式下都错。

需要确定比较时固定的任务目标/保持要求、哪些独立视频或完整环境证据允许修订它们，以及冲突如何处理。
目标版本和经验重新认证能维护一致性，不能单独解决目标选择的合理性；不能由自选弱目标再为自己生成正例。

### 3.4 可计算的前缀损失与最终能力之间

第六轮的双独立噪声energy-score形式在相应条件下是合理的分布拟合损失；本次审阅没有把它的符号或系数判为错误。
相关一般性质见[Gneiting与Raftery，2007，§4.3](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。
它拟合被认证的经验分布，并不自动保证认证正确、覆盖足够、最终任务收益或此前能力保持。
完整可微双采样、两侧梯度和新噪声避免了部分退化，也引入实际反传与数据需求；不能用一般统计性质代替当前模型上的可学性论证。

需要选择并说明：完整轨迹FM、局部经验与功能保持如何组织；有限局部经验怎样改变普通新噪声下的动作；
相对更简单的可行目标增加了什么必要作用，成本依据是什么。可以保留或替换energy score，但须作出主设计选择。
首批完整循环应能分辨“有效行为根本没发现”与“已发现却不能学进最终actor”，不等大矩阵结束再追问是哪一层失败。
辅助过程状态若含最终RGB/proprio/语言不可区分的历史，也会产生可观测性障碍；不能假定一个固定LoRA总能吸收额外信息。

## 5. 新专家本轮应交付什么

先根据上述缺口作出方法选择，给完整数据流、关键计算、标签/梯度分工和一条可执行的适应算法；
使用具体任务贯通教学、实践、反馈重读、有效经验、LoRA更新和固定后新初态执行。
允许删去不必要模块，允许保留需有界实验检验的假说；不要求先证明必定成功，也不把每个未知变成独立长期探针。

随后给首批小而完整的学习方案：主要未知、实际任务/教学/初态选择依据、交互与更新预算、
能分辨视频操作知识贡献的最小公平比较、最终裸actor证据、预期耗时与继续/修订/停止分支。
正式400条件适应成本和同condition新初态泛化须分别说明，不能用少量LoRA复用掩盖教学条件数。
第一批具体规模由方法与成本决定，不照搬第六轮的未验证估计，也不要求一开始完成全部正式评测。

回答应足以让主讨论据此冻结首批科学合同，实验session据此实现和运行；不能只给候选菜单、未来工作清单或无监督来源的公式。
当前仍是材料交付与设计委托，没有新active design或实验启动。
