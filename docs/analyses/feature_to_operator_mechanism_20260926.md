# 从教学特征到执行算子：计算审计与下一方法假设

2026-09-26。Owner要求开始推进完整机制分析后的工作产物。本文是**方法假设与实验取舍**，不是已验证根因、
新方法成绩或GPU运行合同。最初形成于S0执行期间；其完成裁决已补入§11，Reader工程已验收、正式学习已撤回，
执行状态以[progress](../../progress.md)为准。

## 1. 本轮作出的判断

不能继续把问题概括成“没读到视频”“缺时序模块”或“只差LoRA出口”。当前C0完整400的正确/另一正确/语言
为120/132/121，旧大幅落后语言的现象没有稳定复现；冻结后续内容干预27对20/80又表明存在有限有益作用。
另一方面，几轮保留联合特征、原生续算和功能辅助的学习均没有获得足够能力。这些事实要求解释**知识怎样被学成
执行条件下可用的作用**，而非再次用张量完整、非零梯度或更大结构作充分理由。

本轮最初形成的候选是：**以执行状态查询教学内容的原生功能读出，建立可实测的条件控制函数，再检验它能否被
唯一完整LoRA承接。** 它包含一个必须允许失败的前提：合法视频读出本身要有真实闭环能力和有益教学贡献。
没有这个前提，不开始蒸馏，不把弱动作头重新称为功能教师。

后续独立推导在§10进一步收紧这个理由：当前LoRA已有逐query的特征信用；可精确编译的线性读出与LoRA
连梯度也等价。候选真正改变的是非线性、按执行query读取完整教学memory的参数化，不能把它说成补上缺失梯度。
因此候选成功仍只建立功能教师的前提，不自动定位Compiler，更不保证能传给最终LoRA。

接管后的近似历史复核见§6.1：旧Video Functional已有联合表示/执行读头学习，原生中层续算也已有独立反例。
撤回把“联合学习”本身作为新理由的表述，下调Reader正式学习的优先级；工程完成后进一步撤回630学习提案。
工程通过没有补出新的科学投入理由；完整裁决见findings§160。

这不是认定“固定LoRA不能按状态选择动作”。它本来可以。所比较的是两种条件作用的参数化与学习接口，
不把单层线性与整网非线性混为一谈，也不以放宽后的读出模型成绩冒充EMBER部署结果。

## 2. 现有代码实际上处理了什么

核对对象是当前`writer/{video_program,procedure,temporal,model,supervised,function_credit}.py`；
原科学模型C0的实现来源为dca1b550，最近S0开关不改变下面完整内容路径的定义。
记语言为L，教学帧为I_t，机器人执行查询为x=(o,s,a_tau,tau)，四个轴t/h/tau/native depth分别解释。

| 接口 | 实际计算 | 可以说什么；不能说什么 |
| --- | --- | --- |
| q_j | exact task token经原生text-only路径、Text Meta及2048→256投影 | 语言位置地址；不是已标注实体 |
| E_tj | 同帧原生图文task token投影，加q_j查询256个真实agentview patch的读出 | 当前C0教学侧单相机；双相机是执行侧，不能混为一个输入合同。E不是纯动态量，同j也不保证是稳定物体轨迹 |
| H_th | 真实图文prefix下，公开固定noise、tau=1的完整50×1024 Action Expert响应 | source动作计算表征；不是teacher正确动作或观察到的未来 |
| P_t | 初始mean_h(H)投影；每层重新读完整H、前后E，随后因果时间attention | 有学习过程关系的输入和算子；没有显式标注的抓取/放置阶段 |
| C_j | 每语言位置跨帧读取E，再沿语言轴处理 | 全视频语义内容；该读取自身对帧集合置换不变 |
| 参数slot | Core读取→Core条件的中心化P读取→AdaLN→slot交互 | 条件化的参数内容；slot/rank不是已知技能或物体 |
| A_l,B_l | 共享家族head从slot生成两侧完整因子，加合法identity模板 | 决定实际policy层的条件作用；参数相近不保证行为相近 |

具体地，FrameRead满足

```text
r_j = W_o sum_t [(1-lambda)/T + lambda alpha_tj] W_v E_tj.
```

在固定E时，这个读出本身不保留顺序；顺序还可经P传递。原件中中心内容选择较小只能描述这个接口，
不能推出内容选择没有功能价值；BF16权重和误差不能计为学习出的选择（findings§155）。

Procedure到slot的Value为

```text
p_r = W_o sum_t beta_rt W_v(P_t - mean_t P_t).
u_r = (1 + gamma(p_r)) * RMS(c_r) + beta(p_r).
```

中心化去掉了Value均值，但P仍进入Key，不能宣称整条函数对P公共平移不变。时间编码、内容相关权重和后续非线性
也使一般已训练模型的“S0广播首帧”不必等同于给P输入常量；fresh零读出初始化存在下文§11的特殊不动子空间。
上述性质没有单独证明某个实际有用特征被丢弃，更不自动支持取消中心化。

部署第l个target上的更新则是

```text
delta y_l(x;V,L) = B_l(V,L) A_l(V,L) h_l(x)
                 = sum_r b_lr(V,L) <a_lr(V,L), h_l(x)>.
```

h_l由机器人自己的当前图像/state、动作latent、flow time及前层适配共同决定。
A定义对当前激活的作用方向，B定义输出方向；整个深层policy仍可形成复杂的状态条件行为。
A/B有基变换不唯一性，因此不能把某个rank坐标直接解释为“拿起”“再放下”。

## 3. 现有监督并未缺少跨episode信用

一个teacher生成同一LoRA，训练query来自同task其它episode。现实现先累积完整LoRA cotangent，再同版本重放Writer：

```text
g_w(V,L) = sum_q omega_q d loss_FM(F_source+w(x_q), y_q) / d w,
g_phi = [d G_phi(V,L)/d phi]^T g_w(V,L).
```

这是链式求导，不是截断掉动作信用；对query求和也不是新增的工程错误。
难点假设是：每个query需要的条件作用，必须经过一个共享参数生成Jacobian，才能给教学特征信用。
公式只给出这个依赖，不证明梯度必然冲突、必须改FM、或某个辅助loss一定更好。

在理想teacher/query条件独立的已知task分布下，同task固定LoRA可以最小化该task期望风险；有限池排除teacher
会有采样依赖，不能把理想独立性无条件套到真实sampler。即使语言唯一标识task，有限模型仍可能借视频学会
未见任务的操作规律。两点应同时保留：**不能用视频差异大小定义教学成功，也不能用训练有静态解证明视频无用。**
完整推导与限制见[信息可识别性分析](video_information_identifiability.md#3-为什么跨episode-fm允许视频无关解却不证明视频无用)。

## 4. 下一假设要改变的具体联系

当前Compiler先将教学内容变成一套A/B，再由未知的执行状态使用。候选功能读出则显式学习：
**对于当前执行特征，教学中哪些内容应改变该层输出。** 对一个可微cross-attention读出，记

```text
q_l(x) = Q_l h_l(x),
k_i = K_l m_i(V,L),  v_i = V_l m_i(V,L),
alpha_i(x,V) = softmax_i(q_l(x)^T k_i / sqrt(d)),
R_l(x,V) = U_l sum_i alpha_i(x,V) v_i.
```

m_i须来自真实q/E/H及有序处理，Value不能由task ID、动作标签或执行query构造。
执行query来自当前policy，且只在这个训练/诊断读出中使用；最终Writer仍只能读取L,V。
语言解释关注对象和目标；时间内容提供观察到的状态与变化；query决定这些内容何时对自己的计算有用。
这是拟学习的角色，不把注意力权重本身当成已理解操作的证据。

若g为下游动作损失对R输出的梯度，局部精确导数为

```text
d loss / d v_i = alpha_i U_l^T g,
d loss / d k_i = alpha_i [g^T U_l(v_i - v_bar)] q_l / sqrt(d).
```

它显示同一真实执行query怎样同时训练“读哪个内容”和“该内容产生什么作用”。与当前路径相比，候选把这段
query—教学内容的交互显式放在原生动作计算里，不先要求所有作用经自由参数生成间接建立。
这提供一个具体学习假设，而不是有用知识必然学成的定理。它不是“第一次给视频query级信用”；见§10的精确等价式。
表示欠缺、有限任务支持或学习预算仍可能使它失败。

为防止再次混淆层次：固定LoRA单target是线性算子，R通常是非线性函数，但整个LoRA policy不是线性的。
不能由此证明rank16不够，不能将读出优胜唯一归因于softmax，更不能将它作为逃避MT-BC下界的借口。

## 5. 最终怎样接回唯一LoRA

这里的R是候选功能教师/诊断参照，不是增加一套部署控制器。只有它在独立episode和合法视频上取得行为证据后，
才值得检验如下完整方法：

```text
L,V → 共享原生图文/Action特征 → 有序教学表示
    → G_phi一次输出全部38-target A/B
    → 冻结source依自身状态执行。

训练监督：跨episode真实LoRA FM继续端到端学习G_phi；
合法训练task上的功能读出R只提供同坐标的附加监督，不进入部署。
```

候选监督对象是**在真实执行特征上的作用**，例如`BA h`对`R(h,V)`，不是任意专家A/B的欧氏坐标。
若用于学习，R须在学生自己的h上取值，不能用另一个运行路径的h冒充同一点；辅助项中的h可stop-gradient，
避免学生仅通过移动查询特征降低局部匹配误差，而主FM仍保留完整反传。
教师标签来源、R是否冻结、权重及学习节点必须在后继合同明确；本分析不隐含批准一个额外蒸馏loss。
准备稿将R作用于第10层q/v两个真实LoRA target，避免hidden输入纠正与投影输出纠正坐标不一致。
最终Writer仍输出全部38-target；只在有对应R输出的target定义局部标签。
即便在学生自己的h上查询R，也不能假设这些h都在教师已学会的分布内；这种传递覆盖仍需实测，不能被同坐标形式消除。

一般平方误差只给出三角界

```text
||S-y||_2 <= ||T-y||_2 + ||S-T||_2,
```

不保证蒸馏优于真实标签，更不是闭环成功界。必须分别观察教师能力、传递误差和学生闭环。
不能把弱教师准确复制称为改进，也不能为降低传递误差保留其错误。

另有一个可以精确定义的局部判别。固定授权训练查询，收集同target的实际输入X及R输出Y，
令`X=U Sigma V^T`为薄SVD、rank(X)=s，考察`min_rank(M)<=r ||Y-MX||_F^2`。
在非零奇异子空间上，最优残差是

```text
||Y(I - VV^T)||_F^2 + sum_(j>r) sigma_j(YV)^2.
```

第一项是该有限查询上单个线性算子不能复现的部分，第二项是指定rank的额外代价。
这比仅检查LoRA参数范数明确，但依然只属于固定局部接口：深层各target共同改变h，训练/部署状态也不同，
因此它不是全模型不可表示性证明，更不能单凭这个数增加rank或认定Compiler已失败。
若一个condition的查询数不超过输入维度且X列满秩，第一项可机械地等于零，不能据此称非线性作用已经可迁移编译。
不同video有不同目标LoRA，不能将其查询混为同一个固定M来制造残差。真正使用此判别时需明确样本量、有效秩和独立查询。
与旧Native Correction不同，Y应来自已具行为证据的合法教学读出；它不是privileged cotangent标签或任意专家参数。

`(O_Q phi, 0, O_V phi)`，两个输出共享phi。后者改变了纠正的耦合约束，既不是只改模块名，也不存在已证实的
函数类包含关系。没有证据表明有益教学纠正恰被旧耦合排除，故这个代数差异本身不能解释旧阴性或保证新学习有效。

却不能凭这一点宣布过去存在有害冲突。当前C/P也没有获得任务角色、运动阶段或跨初态规则的语义保证。

## 10. 独立推进的传递审查：信用等价、计算差别与下一裁决

### 10.1 当前LoRA本来就收到执行条件下的选择与作用信用

固定一个target，吸收固定scale，记`delta_y=sum_i b_i (a_i^T h)`、`g=d loss/d delta_y`。
其局部精确导数是

```text
d loss/d b_i = g (a_i^T h),
d loss/d a_i = h (b_i^T g).
```

如果a_i、b_i由视频特征m产生，那么m同时获得“该执行特征是否应触发”和“触发后输出是否有益”的链式信用。
多query累积没有抹掉这种依赖。以上是该target的偏导；完整反传还包含h对较早LoRA/参数的依赖，现有FM保留该路径。
所以“Writer先生成参数，就无法给视频具体执行状态的信用”是错误命题；不能据它设计Reader或更换训练loss。

进一步，给定相同的可学习K(m)、V(m)，无归一化线性读出满足

```text
R_lin(h,m) = V(m) [K(m)^T h] = B(m) A(m) h,
B=V, A=K^T.
```

只要合法rank、初始化、scale、实际计算位置和完整学习图一致，先生成BA与在线按相同K/V读取在实数数学中
前向、对m的梯度、对query的梯度都相同。训练期保留memory与部署前把它编译掉，不会自身产生优化优势。
正常kernel/浮点差异不是本命题的科学变量。若再改变K/V生成器、使用不同优化参数、归一化或损失，
差别应归于这些实际变化，不能归于“现在是读出，所以信用更直接”。

这也排除了一个廉价但无意义的替代实验：把已有A/B重新命名为Key/Value，训练同一个函数，期待它解决视频利用。

### 10.2 准备稿实际改变的是哪些特征运算

现有Compiler在执行h未知时，把C/P读取成固定的层/rank slots，再生成参数。执行时通过A与h的内积激活相应作用。
准备稿则在每次真实flow计算中，用h形成query，重新从完整C/P选择内容，并用`GELU(W_h LN(h))`调制该内容。
不同执行状态因而可以读取不同教学位置；但同一特性增加了编译难度。

| 运算 | 现有完整LoRA | 候选Reader |
| --- | --- | --- |
| 教学内容在哪一步收缩 | 先收缩到固定层/rank slots与A/B | 保存C/P，得到执行h后再读 |
| 单target对给定h的直接作用 | 固定BA对h线性；全策略仍非线性 | softmax选择、LN及GELU乘法造成额外非线性 |
| 谁得到query级信用 | A/B及上游Writer都有 | query/key/value及教学encoder都有 |
| 源模型作用位置 | 全部38 targets | 只第10层q/v两个targets |
| 能否立即作为EMBER部署 | 能 | 不能；还依赖执行时教学memory |

另核对原C0实际run_contract的`model.camera_view`与`observer.camera_view`均为`agentview`，
`video_program.py`按一相机生成256个patch；执行policy才使用双相机。本文初稿将教学侧误写为512/双相机，现更正。
候选须保持同一单相机输入，否则会在读出比较里混入未经登记的相机变量；此前没有按错误文字派发或执行。

两种函数类因此没有已经证明的包含关系：Reader放宽局部计算，却减少适配位置。
正结果不能唯一归因softmax或证明旧C/P已有足够知识，因为encoder也共同重学；负结果也不是“所有合法视频知识不存在”。
但阴性必须降低这套具体联合读出及其后继编译投入的优先级，不能用这些边界保护它反复加层重试。

H_read应准确表述为：**在本预算中，先在真实执行query上学习非线性教学内容选择，比现有提前参数编译更容易
获得可跨video/init使用的有效控制函数。** 这是关于参数化与有限学习的预测，不是缺梯度定理。
其竞争解释包括：教学表示/任务支持没有形成可迁移内容，或原有提前编译已足够而新增在线计算没有实际优势。

### 10.3 “可用教师”与“一套LoRA可承接”是两个可失败命题

softmax读出不能一般地精确写成一个固定单target矩阵。最小反例：标量query h，keys/values均为{-1,+1}，
读出为`R(h)=tanh(h)`。在h={-2,-1,1,2}上不存在一个标量M使`Mh=R(h)`；在±1上完全拟合也会在±2失配。
这反驳自动局部编译的保证，**不反驳深层完整38-target LoRA的表达能力**，也不构成增加rank的依据。

同坐标局部损失也不是充分传递合同。设后续执行图F在某激活附近的Jacobian为J，局部误差e的动作影响为
`F(y+e)-F(y)=J e+O(||e||^2)`；它依赖`e^T J^T J e`而非只依赖`||e||^2`。
大误差可能落在后续函数的零空间，小误差也可能被放大。因此不能仅凭同坐标或局部L2更小选择蒸馏方案。
J还随执行状态、flow time及学生较早层适配而变；这里不授权再开Jacobian/去噪位置探针。

后继若有强教师，传递方案须同时明确：

- 最终完整LoRA在自己的真实执行路径上接受主FM，不能只在教师路径拟合局部hidden。
- 局部教师标签是候选学习偏置，不能硬性钉住其它层如何表示同一有效行为；是否采用须另有机制依据。
- 用最终LoRA闭环验证有益教学能力和保持，不能把Reader成绩、局部误差或参数可压缩性代入最终成绩。

本轮因此不提前选定局部L2/KD为下一训练目标，不把“Teacher→LoRA”画成已经接通的解决方案。
先读出仍是可检验候选，而非所有方法的必要课程；有更充分依据的直接完整LoRA方法可替代它。

### 11.2 精确算术下的双零不动子空间

这是本架构与首帧广播共同产生的特殊性质，不是所有VLA的训练问题。
`ProcedureReadBlock`的H及相邻E读取输出投影均为零初始化；S0初始`I_t=I_0`。
在这些读出仍为零时，每个有效时间位置得到相同输入。时间RoPE只进入Q/K：
即便每行attention权重不同，相同Value的归一化加权和仍相同。
因果mask、逐位置RMS/FFN和残差也保持这一性质，故精确算术下`P_t=p_0`。

Compiler对Procedure Value中心化，随后用无bias的零初始化矩阵W产生调制。记读取结果为r、上游cotangent为g：

```text
P_t = p_0  =>  P_t - mean_t(P) = 0  =>  r = 0,
(gamma,beta) = W RMS(r),                 W_init = 0,
dL/dW = g RMS(r)^T = 0,
dL/dr = J_RMS(r)^T W^T g = 0.
```

主项与额外项都只经同一完整LoRA监督、没有独立Procedure目标时，该分支的读出与Action Meta不能由这条路径启动。
零Adam动量及对零权重的weight decay也不会自行打破它；Core/Text/VL路径仍可正常学习。
完整视频的`I_t`原本可以变化，使r非零；第一次调制更新后，梯度就可能进入Procedure/Action Meta。
“可训练参数总数相同”因而不足以证明首帧与全视频拥有相同的优化可达路径。

实际BF16实现并不是精确算术系统。本批105/210/315/420四个S0 checkpoint中，
modulation、两层H读出、两层E读出及72个Action Meta B张量仍全部为零；525/630都已非零。
这与450步才首次记录Action Meta梯度一致。我们没有识别第450步破坏对称性的具体数值事件，
不据此追逐bitwise一致、扩dtype、改变kernel或展开精度实验。

实际Compiler的合成CPU检验得到：常量P与零W时，W/P梯度均为0，Core梯度非零；
仅令P变化，W梯度非零而P仍为0；更新一次W后，P梯度也非零。
它验证双零接口的代数，不替代真实学习干预，更不证明该机制解释全部闭环差额。

以“目标物入篮”为例，所需的是目标角色、目的关系及操作后状态如何变化，不能把教师某时刻的绝对位置或手臂轨迹
直接当成新初态的动作。这是期望学习的功能，不是声称当前E/P已编码这些语义。实际E由图文task-span与语言查询patch
共同形成，允许任务共同语义；H是在公开noise/tau1下的原生响应，不是教师动作。P重读完整H、相邻E并因果处理时间，
提供学习变化与关系的算子，但没有已被验证的物体绑定、阶段识别或跨初态对应。

主FM要求同一视频生成的LoRA服务同task其它episode的当前观测，使复制单条轨迹不能一般满足所有查询。
但它也允许依赖共同任务语义的有限训练解。二者都不是新发现的缺梯度或视频无用定理；早期普通FM正例限制了后一种外推。
真正要改善的是：教学产生的条件作用在不同执行状态下帮助正确操作，并同时保住已有成功。
同task两视频生成相近作用可以是正确抽象，不能为了更大特征或LoRA差异奖励演示细节。

### 12.2 Reader同时改变了内容选择与状态调制

当前LoRA的`BAh`及其上游已接收query级信用，§10的等价结论保持。候选将教学表示M=(C,P)保留到执行h到来后读取；
教师时间位置只是可查询的地址，不应与机器人当前执行步数逐帧硬对齐。它可能利用当前h选择与自身状态有关的教学关系，
但这个跨初态联系仍须由联合FM学成，不能由attention形式担保。

对设计§2的实际算子，令`s(h)=GELU(W_h LN(h))`、`u(h,M)=W_c c(h,C)+W_p p(h,C,P)`，
则每个target的残差为`R_m(h,M)=W_om [s(h) * u(h,M)]`。固定memory时，其局部精确导数为

```text
partial R_m / partial h
  = W_om [diag(u) J_s + diag(s) J_u].
```

第一项是执行状态对内容作用的调制，即使内容读取不随h变化也可存在；第二项才包含随执行query改变的教学内容选择。
候选同时有这两项，并从原38处适配改为2处。因此涨分只能先支持这套联合参数化，不能唯一证明动态检索或Compiler病因。
R_L的同接口参照有助于区分一般执行参数化收益与视频条件的额外收益，但也不是纯参数量匹配的动态信息消融。
不据这个分解增设gate/attention/层位探针，先沿既有有界候选的整体能力预测裁决。

固定h时，教学memory的局部信用为`J_(R_m,M)=W_om diag(s) J_(u,M)`。
零输出head使初始化时这条上游信用为零；输出head自身的梯度为`g_m [s*u]^T`，非退化输入下可以先学习。
这说明工程应验证后续上游活动，而非要求第一步全非零；非零仍不等于学到了有益操作知识。

### 12.3 方法选择保持两个可失败命题

当前保留Reader作为有限投入候选，理由是上述具体的条件作用学习差别，而非断言原Writer缺状态、缺梯度或只能做静态控制。
其第一命题是合法视频联合读出能获得跨正确视频/初态的实质能力，且不靠大范围丢失旧能力取得净分；
第二命题是这份能力能由最终一次生成的完整LoRA承接。两项均未验证，S0结果没有替其中任何一项背书。

未来Reader若无益，降低这条路线优先级；若仅胜C0而不胜匹配R_L，不建立视频教师；若有益，才具体设计传递。
完整LoRA可以经其它层实现同一行为，因此不先把教师两个局部残差钉成唯一正确内部表示，也不提前选择局部L2/KD目标。
最终仍由单LoRA真实闭环、同task换视频、能力保持/覆盖及共同协议强MT-BC裁决；当前screen的投资线不是科研目标。
已核对coverage的train24包含当前diagnostic-held8全部任务，155与120不构成配对缺口，也不触发现在补训baseline。

这一分析收紧解释，不改变工程科学范围。实际协调身份与派发状态只看progress；
不恢复S0、Cplus、有限回报或flow位置分支，不联系旧会话。

### 12.4 执行query究竟包含什么，修正如何进入真实动作

接管后进一步只读核对`pi05_processing.py`、`writer/function_credit.py`及当前固定LeRobot实现的
`embed_suffix`、`denoise_step`、原生attention与mask；没有增加模型forward或实验。
执行端8维state按冻结Source统计归一化并离散为`Task: ..., State: ...; Action:`中的token；
图像与这些token形成真实prefix。教学prefix则明确没有state，H仍来自公开noise/tau1。
因此教学H与执行h具有不同输入语义，不能把前者解释为教师真实动作，也不能要求两者逐位置直接对应。
执行中使用机器人自己的state是原policy合法输入，不是向部署Writer泄漏教师state。

真实FM调用`NativeFlowPrediction`：缓存冻结prefix KV，再以随机tau和带噪动作调用原生`denoise_step`。
Reader的层9输入h已消费当前视觉、任务/state token及动作/flow条件；它不是裸图像或只有噪声的query。
本候选在此之前没有执行adapter，因此给定同一个FM输入，进入层9前的h由Source决定。
闭环采样的后续flow步则会间接依赖Reader，因为前一步修正已改变下一步的动作latent。
完整38-target Writer还能改变更早层和action输入，所以它与Reader的局部h并不天然同分布；
这给§5中“学生h上查询教师仍可能超出支持”的限制提供了实际执行依据。

原生attention为8个query head共享1个KV head、head width256。q残差经过原生RoPE后改变该动作位置
读取prefix和suffix的权重；v残差修改动作suffix的Value，经GQA重复后可影响其它动作位置。
prefix不能读取action suffix，而50个action位置在同一attention块中可相互读取，不能将其误写成
只看先前action的自回归序列。第10层的残差仍经过原生输出投影、AdaRMS gate、后续层和动作输出头，
再经10步flow、前5个实际动作及环境状态变化形成闭环效果。
因此某个reader输出或某条梯度的非零既不是独立控制通道，也不能直接解释为抓取／放置语义。

这次核对确认的是既定作用链和解释边界：教师时间地址、50个预测动作位置、flow时间与环境执行时间
是不同的轴；“当前状态读取教学”不意味着按教师进度播放轨迹。它不引入新的层位、去噪或梯度探针，
也不改变已冻结的工程接口与后继投资规则。

## 13. 完整链的数学对象：过程特征、执行作用与实际学习必须相容

Owner进一步明确，实质进步是在推进过程中更清楚这三段怎样共同成立，而非仅完成新架构或停止无效投入；
不要求此刻完成一套推导。以下是主讨论结合既有证据与源码形成的初步认识，随实际推进修订，不作实验前置关卡。
其中结构性质与功能条件分别陈述；没有新增模型计算，也没有证明模型已经学会这些条件。

### 13.1 “运动过程特征”应保留什么

设教学条件`z=(L,V)`，中间表示`m=E_psi(z)`，生成器输出完整LoRA `w=C_omega(m)`，实际动作流场为`v_w(x)`。
`x`包含执行者自己的图像/state、语言、动作latent与flow time；不能把它换成教师的绝对位置或视频时间。
有用过程至少涉及：对什么对象/关系操作、在什么当前条件下适用、希望造成什么状态变化、哪些变化为后续操作创造条件。
这些是功能职责，不要求显式阶段标签、手工对象图或某个特定token对应一个动作。

例如“物体入篮”，教师手向右运动不直接给出新初态下机器人向右的指令；需要转移的是对目标物建立抓持、在持物条件下
改变物体相对容器的关系、完成放置等条件作用。当前E的同一语言位置不是已验证的跨帧物体对应，H也不是教师动作。
相邻E读入P使状态变化可参与计算，却没有单独保证目标绑定、接触前提或执行方向已学成。

更精确的功能标准可用合格参数集合表达。对条件z及其合法跨episode查询分布，令
`W_z(epsilon)={w: R_z(w)<=epsilon}`，其中R是明确的监督风险，不能直接称成功率。
若`E(z)=E(z')`，确定性Compiler只能给出同一w；要同时达到这两个风险要求，必须有
`W_z(epsilon) ∩ W_z'(epsilon) != empty`。这是必要条件，不是现有特征违反条件的证据。
执行policy仍读取L和当前状态，因此不同任务完全可能共享一个合格w；不能反向要求每个任务/视频有不同表示或LoRA。

同一操作在不同演示初态下也不要求embedding逐元素相等。真正应保持的是所生成策略在相关执行条件上的功能，
例如`d_mu(w,w')=E_(x~mu)||v_w(x)-v_w'(x)||²`；mu必须写清来源和覆盖，不能用一个小面板冒充全状态空间。
这个标准把“保留过程、忽略轨迹细节”落到可消费的功能上，但没有提供一个现成充分的表示损失。

### 13.2 中间特征必须生成条件作用，不能只生成看起来合理的参数

每个target实际作用是`delta y_l=s_l B_l(m) A_l(m) h_l(x;w)`，s_l为固定LoRA scale。
其中`A_l h_l`给出当前状态下哪些作用被激活，B_l决定向该原生投影输出写什么；两者共同依赖教学。
rank坐标可以可逆变换，`B S^-1 · S A=BA`，所以某一行A或列B不具有唯一“抓取阶段”语义。
过程组织也可分布在多个target和source非线性中，一套固定LoRA不等于一段固定动作轨迹。

在一个明确的参考参数和执行query处，对小参数扰动有

```text
delta v(x) = sum_l D_l(x) s_l delta(B_l A_l) h_l(x) + higher-order terms,
D_l(x) = derivative of final flow velocity with respect to target-l output.
```

D_l包含实际attention、gate、后续层及输出头的续算；多层共同更新带来的交互属于高阶项，有限步必须看真实前向。
因此特征的好坏取决于它能否生成适用于新x的这些作用，不能只看视频重建、特征可分性或A/B距离。
同理，教师Reader的局部作用即使有益，学生还必须在自己的h与D下实现有效作用；§5/§10的传递限制仍在。

### 13.3 现有FactorHead给出的一个具体学习机制

源码`FactorHead`实际为无bias的`Linear(256,216)→GELU→Linear(216,d)`，末层零初始化；
Compiler给每个target的r个slot，B模板为零，A模板为非零合法identity因子。
对共享B-head家族f，令`Xi_(z,l)`为r×216的末层前slot特征，末层权重为`U_f`，则

```text
B_l(z) = U_f Xi_(z,l)^T,
delta y_l(z,x) = U_f phi_(z,l,x),
phi_(z,l,x) = s_l Xi_(z,l)^T A_l(z) h_l(x;w).
```

这不是新增近似：固定当前上游量时，它就是该head的真实局部计算。它揭示中间视频特征最终必须与执行状态形成
一个有用的联合特征phi；“视频里能读出过程”与“phi能把对应作用施加到合适执行状态”不是同一命题。

在identity初点U_f=0，令g_q为真实FM对对应target输出的cotangent，q包含条件、query、共享该head的target及执行token位置，
权重a_q包含实际task和两组query权重。对该head的精确偏导为

```text
grad_U L = sum_q a_q g_q phi_q^T.
```

此时经U向该slot/encoder回传的偏导为零，A分支也因B=0没有这一功能信用；输出head先获得更新，随后上游才可学习。
这不是当前Reader修复了的缺梯度：它的输出也零初始化，只是联合特征改为
`phi_R(z,x)=GELU(W_h LN(h)) * [W_c c(h,C)+W_p p(h,C,P)]`，在同样的`U_m phi_R`之后接受真实FM。

若仅为解释使用一次SGD且冻结此步的上游特征，则
`delta y_i=-eta sum_q a_q g_q <phi_q,phi_i>`。
这表明一条训练query会怎样影响另一状态/教学条件，取决于联合特征联系以及作用方向，而不只取决于“梯度非零”。
它不是实际AdamW轨迹的等式：实际Adam矩统计、裁剪、权重衰减与随后上游更新均须按原训练计算解释。
同一家族还跨层共享head，求和不能漏掉其它层；不能由本式宣布梯度冲突、归一化、head共享或训练时钟是已识别根因。

### 13.4 架构与训练配套的具体责任

跨episode主FM让同一个m/w服务其它初态，给的是“怎样在这些状态下完成操作”的信用，而非复制教师轨迹的信用。
但它并未直接标注物体对应、操作前提或过程语义，也允许有限训练任务上的语言/静态解；§3的识别边界不变。
增加视频敏感性loss、要求每条视频产生不同参数，或者直接拟合privileged纠正，都不能由上述推导自然推出。
旧共享获取反例也禁止把“局部目标存在且可微”当作它能由合法视频学出的保证。

由此，后续方法推导要共同回答三个具体问题，而非分别给三个模块起名字：

1. 合法视频中哪些对象/状态变化能改变所需执行作用，表示怎样保留这种联系并跨演示初态使用？
2. 这些联系经实际Compiler形成什么`A h→B`作用，source的哪些真实计算消费它，哪些功能仍由source提供？
3. 已登记标签产生的梯度怎样训练这个联合特征和作用；哪些替代解也能降低损失，现有训练支持与已有行为证据怎样约束它们？

当前Reader是对联合特征phi的一次有界改变，仍沿用未获语义保证的C/P，并减少到两个target；
它没有单独解决过程表示，也没有解决最终编译。后续结果只能在对应范围更新上述三段联系的证据。
本节的新增认识是实际FactorHead与Reader都在学习“教学×执行状态”的联合作用特征，且初始信用有同样的零head边界；
两者的差别必须落实到联合特征如何形成及怎样被有限学习利用，不能用“直接读出”四字宣称理论优势。
这收紧后续方法解释，不激活新探针、head扫描、蒸馏或替代架构，也不把这份推导当作模型已达到预期功能的实证。

## 14. 从可达下界到实际学习：常量能力、条件作用与保持怎样联系

Reader撤回后继续研究的数学问题。下文是从实际FactorHead及已有行为证据出发的推导，
不是“公共底座＋残差”新提案，也不以旧方法未完全覆盖某种组合为启动理由。
本节没有新增模型forward、更新或环境episode；历史最近似实现另由当前执行者只读核对。

### 14.1 全局能表示，不等于当前更新能到达

令`w_z=G_theta(z)`表示38个实际增量算子的集合，而非具有非唯一坐标的裸A/B距离。
Owner的下界约束是：若生成函数类含共同LoRA解`w_z=w_shared`，其理想最优能力不能因多了合法视频而更差。
实际一步则由当前`J_z=partial w_z / partial theta`及优化器状态决定。
在若干条件上都施加同一个小算子变化`d`，需要存在一个`delta theta`使每个`J_z delta theta=d`。
“某处存在共同解”没有保证这组局部方程在当前参数点可解，更没有保证真实梯度选择这个方向。
这里讨论同rank共同解/切向变化的条件，不宣称当前共享head含任意自由rank16 LoRA。

一个只用于区分命题的精确反例：`G_(u,a,b)(z)=u(az+b)`，两种条件`z=+1,-1`等权，目标都为1。
它包含常量最优解`u=b=1,a=0`，损失为

```text
L = 1/4 sum_(z=+-1) [u(az+b)-1]^2
  = 1/2 [(ua)^2 + (ub-1)^2].
```

在合法零输出点`u=0,a=1,b=0`，三个梯度全部为零，而损失为1/2。
所以“包含共同解→有限梯度学习不弱于共同解”在数学上不成立。
这不是EMBER的实测失败机制：真实Writer已经有非零梯度和行为获取，当前B还在多个共同节点超过直接A；
不能把这个反例包装成新的零初始化bug、S0重跑理由或共享底座课程。

### 14.2 视频特征的学习联系必须经过真实控制计算

§13.3的`phi_(z,l,x)=s_l Xi_(z,l)^T A_l(z) h_l(x;w)`是教学与执行状态的联合特征。
为了进一步接到最终flow，令`D_(i,l)`为条件/query i处，最终flow对target-l输出的Jacobian。
下式的l、m索引具体的target及其执行token/horizon位置；phi取该位置的向量，D对该位置的输出向量求导。
一个50-position查询不能省略位置间的交叉项，也不能把下式内积直接换成整张feature矩阵的Frobenius内积。
只取共享B-head末层`U_f`这一参数块的偏导，在当前参数点固定其它参数，则

```text
delta v_i = sum_(l in family f) D_(i,l) delta U_f phi_(i,l) + higher-order terms.
```

链式法则中的`D`已经包含后续原生层续算，不能再把同一次传播作为独立项重复相加。
对这一个参数块的一步普通SGD，平方损失取`1/2 ||v_j-Y_j||^2`、误差`e_j=v_j-Y_j`，有局部式

```text
delta v_i = -eta sum_j a_j K^f_(i,j) e_j + higher-order terms,
K^f_(i,j) = sum_(l,m in family f)
           <phi_(i,l),phi_(j,m)> D_(i,l) D_(j,m)^T.
```

这比只看视频embedding、rank-slot Gram或LoRA cosine多了两个必要对象：执行状态诱导的实际激活，
以及原生attention/gate/后续层怎样把写入转成动作。同一个head跨层、跨执行位置使用时，`l != m`的项也必须保留。
两个教学特征相似，并不意味着更新在两个执行条件产生相同方向的有益动作；参数变化较小也不保证目标选择不变。
source权重冻结没有把`h`或`D`冻结：自身观测、latent、flow time及其它生成LoRA会改变它们。

实际训练是AdamW、多个参数块共同更新和有限步幅，不能把上式当其精确轨迹或成功率公式。
对已发生的实际位移，局部关系仍是`delta v_i=J^v_i delta theta+高阶项`；
用什么优化器不改变“教学特征必须通过执行计算产生合适作用”这一责任，但会改变实际位移。
没有据此注册大规模Jacobian、核谱、梯度cosine或正交损失诊断；这些量不能代替闭环裁决。

### 14.3 共同路径能改变什么，不能保证什么

作为结构分析，假设写成真正算子相加`w(z)=w_0(beta)+r_psi(z)`且两组参数独立。
改变beta时，共同算子的切向变化在各z相同；这可使同rank直接参数路径不必依赖条件编码器当前的局部Jacobian。
但它没有保证共同更新最优、视频残差有益，也没有保证共同更新在不同执行状态产生兼容的控制。
即使固定w_0，r的变化仍可破坏完整策略已有成功；“底座权重没变”不等于“底座能力被保留”。

这里必须区别两种真实计算：

```text
因子相加：(B0 + Bv)(A0 + Av)
        = B0 A0 + B0 Av + Bv A0 + Bv Av；
算子相加：B0 A0 + Bv Av。
```

前者的base更新还通过交叉项改变视频条件作用，不能当成独立公共算子路径。
后者可以在rollout前通过B横向拼接、A纵向拼接得到唯一LoRA；若两项scale不同，必须同时配平scale。
其名义rank为两部分rank之和，不能偷偷称与旧rank16完全相同；也不因此规定EMBER必须用此参数化。

在视频残差为零、相同beta/queries且编码器不依赖beta的一个参数点，公共分支的未裁剪FM偏导与直接训练相同beta的偏导一致。
真实optimizer步还受公共/残差梯度共同决定的global clip、各自Adam状态影响；残差开始改变策略后，
公共分支所见误差与执行激活也改变。因此不能由首步相同偏导推出“保住整条MT-BC训练轨迹”。
这正是需要由学习机制与实际行为承担的缺口，不是只增加一条路径便自动解决的问题。

## 15. 可预测的过程知识与有用的更新：补足学习对象的定义

这是在§13–14及旧[可识别性分析§3](video_information_identifiability.md#3-为什么跨episode-fm允许视频无关解却不证明视频无用)
之上的局部数学分析，不重新提出“FM允许静态解”作为根因，也不登记新架构、辅助loss或曲率探针。
核心区别是：**真实动作产生的逐位置纠正、合法视频能预测的纠正，以及在新执行状态上值得实施的纠正，不是同一个对象。**

### 15.1 给过程特征一个与实际动作相连的局部标准

在明确参考LoRA坐标`u0`处，令`q`为合法跨episode训练查询，`e_q=v_(u0)(q)-Y_q`，
`J_q=partial v_u(q)/partial u|_(u0)`。u是实际LoRA因子或其允许方向的坐标，不是任意全矩阵参数。
它允许冻结source，但不能把source续算和执行激活从J里删去。对小位移d，线性化FM风险为

```text
R_z^lin(d) = R_z(0) + g_z^T d + 1/2 d^T F_z d,
g_z = E_(q|z)[J_q^T e_q],       F_z = E_(q|z)[J_q^T J_q].
```

z只表示合法语言/视频条件；上式的期望标签来自授权训练查询，不是部署输入。
这是当前点的Gauss–Newton二次模型，不是非线性FM或成功率的精确表达，也不是现行AdamW更新公式。

若Writer只保留中间特征m，记`g_bar_m=E[g_z|m]`、`F_bar_m=E[F_z|m]`。
在有限二阶矩、可测选择与可达坐标的条件下，一个最小范数最优局部位移是

```text
d*(m) = - F_bar_m^dagger g_bar_m.
```

dagger为伪逆；由平方误差的J构造，g_bar位于F_bar的值域。零空间方向对这一查询分布的一阶动作没有影响，
不能据此认为它们对其它执行状态也安全。这里的最优只针对允许的线性化坐标，没有越过rank/参数化限制。
无约束二次模型的d*还可能超出小扰动适用范围；若限制步长，最优解和下节等式须按该约束重写，不能直接部署此d*。
不计划显式估计大F或在部署求逆；公式用来定义“应该从视频获得什么”，不是求解器提案。

因此，好的过程特征无须还原教师每一步的动作或每个梯度坐标；它须保留足以预测**有用修正方向及其执行适用性**的信息。
g关联“应改变什么”，F关联这些参数方向在自己的执行状态上会改变哪些动作、改变多大。
F汇总登记查询分布上的敏感度，不是显式的阶段/状态门；具体状态下的作用仍由`J_q d`及实际policy续算实现。
两者由对象/关系、接触前提、状态变化与source的控制知识共同决定。只读出“发生过抓取”而不能判断适用状态，
或能定位状态却写不出有益动作，均不足以满足这个功能标准。

### 15.2 视频增量的精确定义，及为什么它没有证明实际增益

令m0是语言表示，m1=(m0,视频特征)，并假设两者都允许实现上述最优局部位移。条件期望与配平方给出

```text
E[R_z^lin(d*(m0)) - R_z^lin(d*(m1))]
  = 1/2 E[(d*(m0)-d*(m1))^T F_bar_(m1) (d*(m0)-d*(m1))] >= 0.
```

视频的潜在作用在于改变与执行有关的最优修正；仅让embedding/LoRA不同而落在无用方向上，右端仍为零。
但这只是嵌套信息、充分函数类和理想优化下的风险关系。实际encoder不一定保留m0，有限学习不一定得到d*，
新任务分布也不一定匹配训练条件；不能把右端当已测量的EMBER收益，更不能故意削弱语言参照制造差值。

如果把有限benchmark的exact language当作已知task的完整查表键，理想g/F可已由语言确定，视频增量可以为零。
这与旧可识别性结论一致。EMBER追求的是有限共享模型在未见task上借助教学获得执行知识，
不是从`I(task;video|language)`推出一个虚假的信息下界。所需归纳偏置和有限学习优势仍需具体依据。

### 15.3 真实cotangent标签不自动等于最适合RGB学习的目标

旧Native Correction/LocalField的真标签并非错误量：若同次forward的输出cotangent为C、原生输入为X，
其矩阵梯度就是`G=C X^T`（将采样权重/scale吸收进C）。但其噪声、坐标与部署任务需分开。
给定完整合法条件z，X若确定且可用，则

```text
E[G|z] = E[C|z] X^T.
```

所以不能因actions未输入就断言此目标不可学习，也不能因局部标签随机就说先收缩必然更好。
无限容量下，精确局部条件均值可以给出同一平均矩阵梯度；有限共享网络的局部/矩阵/功能误差权重却不同。
例如`(C_hat-C)X^T=0`允许很大的局部C误差，但不改变该矩阵更新；反过来，X和后续J会放大某些小误差。
视频自身的teacher状态与query/learner实际到达状态不同，也会改变哪些方向值得学习。

把梯度当标签的平方回归还有精确分解

```text
E[||G_hat(z)-G||^2]
  = E[||G_hat(z)-E[G|z]||^2] + E[||G-E[G|z]||^2].
```

第二项是相对于该输入的信息残差；目前没有测定它占旧失败的多少，不能据公式宣布RGB信息不足。
而即便第一项为零，也只得平均梯度，不自动得到15.1的功能最优位移，更不保证闭环保持。
这使旧LocalField失败的含义更准确：它否定了那套标签/坐标/共享模型/预算足以获取能力的预测；
没有否定所有可预测过程知识，也没有支持“再换一种梯度回归就会成功”。

### 15.4 “学习优化过程”必须检查实际梯度，而非名称

[HyperNet Fields原文§3](https://arxiv.org/html/2412.17040v2)给出条件/优化时刻到权重的映射H，
以当前预测权重的一步任务梯度作为相邻时刻目标，并固定初始锚点；推理取末端权重。
它提供一种训练路径约束，不能由外部图像实验推导EMBER的过程获取已被解决。
以下是主讨论对这类目标的链式法则分析；论文文字没有消除所有detach实现歧义，官方实现细节另行核对。

记`w_t=H_theta(z,t)`、`g_t=grad_w L(w_t)`、`J_t=partial w_t/partial theta`，
`r=w_(t+1)-w_t+eta*g_t`。三种实现有不同梯度：

```text
整个目标stop(w_t-eta*g_t)：  grad_theta (1/2||r||²) = J_(t+1)^T r;
只stop(g_t)：               grad_theta (1/2||r||²) = (J_(t+1)-J_t)^T r;
两者都不断图：              grad_theta (1/2||r||²) =
                            (J_(t+1)-J_t+eta Hessian(L)_t J_t)^T r.
```

第一种在两端输出与Jacobian相同的特例下只是主任务梯度的eta倍，不凭“梯度监督”得到新的知识。
多时刻约束可能改变训练路径，但不增加合法输入中原本没有的信息；跨episode条件化、坐标尺度、初始锚点、
Adam矩状态与可预测性都需要单独解释。实际部署仍不得读取task actions或运行task-local优化。
旧LocalField已在收缩前监督真实cotangent并让预测本身组成LoRA；仅说“直接监督更新”不构成新的核心机制。
当前只核对这两类完整学习合同的真实差异，不为公式安排新GPU、曲率/梯度扫描或逐模块课程。

### 16.1 一套固定LoRA怎样根据新初态选择不同操作

j/k为两个未被mask的key位置，R为该位置的原生RoPE旋转，tilde-k为已经旋转的key，则精确有

```text
log(alpha_ij / alpha_ik) = q_tilde_i^T (k_tilde_j-k_tilde_k) / sqrt(d),
delta log(alpha_ij / alpha_ik)
  = [R_i s B_Q(z) A_Q(z) h_i]^T (k_tilde_j-k_tilde_k) / sqrt(d).
```

式中B_Q取该head对应输出行，d=256，h是实际input-layernorm后的投影输入。复读本环境固定
`lerobot/policies/pi05/modeling_pi05.py:compute_layer_complete`及`transformers/models/gemma/modeling_gemma.py:eager_attention_forward`，
确认Q/K投影后施加RoPE、scaled dot product及softmax；没有另加Q/K归一化或logit softcap后仍套用此式。
这里z来自教学，但h和key来自机器人自己的当前观测、state与动作latent。固定B/A不固定这个相对读取偏置。
实际完整LoRA还会通过前层改变h及suffix K/V，不能将这一单层固定输入恒等式当成整网有限更新的分解。
八个query heads共享一个KV head，跨头/位置效应继续按真实GQA与后续层传播。

一个仅说明机制的构造：对于“放入抽屉并关上”，若执行h已包含可区分的“未开/已开/已持物”等状态特征，
并且原生keys/values保留相关对象和作用，则同一A可在这些状态激活不同系数，同一B把它们变成不同查询偏置。
新初态中抽屉已开时，生成参数无需重新观看教学，也无需按教师第几帧执行；机器人自己的特征可以触发抓持而非重复开抽屉。
这是带两个关键前提的功能可达性例子，不是当前h已解码这些谓词、prefix已充分或网络学会此规则的实测证明。
旧操作语义标签审计已发现接触不等于抓持，不能把这些说明用语直接变成未经审计的训练标签。

因此，所需教学特征应帮助确定“哪个对象/关系、什么适用条件、什么期望变化”在控制计算中的连接。
仅编码教师手向右移动、视频时间或抽屉最后关闭，不足以指定另一初态的上述规则。
同时，不要求显式阶段token或形式规划器；可用规则也可能分布在多个target和source非线性里。

### 16.2 功能监督何时会训练这种选择

对一个head令`o_i=sum_j alpha_ij v_j`，`b_i=partial loss/partial o_i`，则固定其它输入时

```text
partial loss / partial logit_ij = alpha_ij b_i^T (v_j-o_i),
partial loss / partial q_tilde_i
  = sum_j alpha_ij [b_i^T(v_j-o_i)] k_tilde_j / sqrt(d).
```

b包含output projection、gate、后续层与最终真实FM的信用；它不是对象标签。
损失只在相关Value对最终误差有不同作用时，才沿这个通路奖励改变读取比例。
两块区域外观可分、注意力落在正确物体、或Q梯度非零，都不独立证明学成了操作规则。
若所有可见Value在b方向上的投影相同，该head此次query的Q信用为零。若只是j/k两者投影相同，
只能说保持二者总注意力质量的相互重分配没有一阶收益，不能说两个raw logit梯度各自为零。
这些是局部计算条件，尚未测定它们是否限制EMBER。

对suffix Value，梯度还从允许读取它的其它action位置汇聚；共享KV时须累加query heads。
V-LoRA可以改变计划中多个动作位置交换的内容，action-in/out改变latent表示与速度读出；
不能把Q专称“找物”、V专称“运动”并由名称分配唯一职责。旧BBQ路径干预中Q有作用、删除Q却未恢复，也反对这种简单分工。

跨episode FM提供的训练压力应使教学特征预测上述**在不同自身状态下仍有用的选择与写入**；
是否学成取决于特征、Value/下游计算及共享条件映射一起变化。Reader、真实梯度标签或额外局部语义loss均不能跳过这条联系。
后续§17补足这个解释中的实际学习关系；不把“先证明每个状态谓词可读出”排成新的诊断课程。

## 17. 一个完整的解释模型：动作信用怎样教会教学特征的使用

本节是2026-09-26夜间主讨论的理论接续，不是新架构、active design或模型计算结果。
旧[有序控制理论](temporal_control_compilation_theory.md)已经提出角色／变化／前置关系→状态条件LoRA→联合FM；
旧SemanticPath也完整实施过。因此新增认识不能只是重述这条链。本节具体说明其中的学习关系，
给出成立条件和反例，并据此裁决哪些近似改法仍没有投入依据。

### 17.1 视频提供规则的证据，执行侧提供当前适用状态

以“把物体放入抽屉并关上”为说明例子。合法视频可能显示：哪个部件打开、哪个物体随手移动、
物体与抽屉的关系怎样改变、最后哪个部件关闭。exact language提供对象角色和目标的语义约束。
需要从这些观察推断的是可复用的关系，例如“待操作部件”“待搬运对象”“目标关系”，以及操作在什么状态适用。
它们不等于teacher时刻、绝对运动轨迹或从文件名读取的task身份。

但“先打开、后放入”是一次观测顺序，单凭它不能证明打开是放入的必要条件，更不能唯一确定失败后的纠正动作。
不同反馈策略可以在整条教师轨迹上相同，在轨迹外不同。合法教学必须与source已有控制知识、
授权meta任务的动作监督共同解释；不能假定一条action-hidden视频自身已经给出了完整控制器。

记`z=(L,V)`，教学特征`m=E_psi(z)`；`x=(自身图像,state,带噪动作,flow time)`。
一个便于解释的规则写成`(角色绑定, 当前适用条件, 期望状态变化)`。
这不是要求增加显式规划器、对象检测器或谓词标签，而是给分布式特征的预期作用一个可核对的含义：

- 教学侧m应帮助确定操作的对象／关系及作用；教师所在位置不应变成新初始化中的固定运动目标。
- 执行侧h(x)应使同一套参数在“部件已开／未开”“物体已持有／未持有”等不同状态下产生不同作用。
- 这些谓词只是说明用语。没有证据表明当前h已经线性编码它们；多个条件的合取也不会由一次线性投影凭空产生。
  所需非线性可能来自source及前面已适配的层，其存在和可学性仍是前提。

例如，在仅作说明的可行状态集合内，“未开且尚未持物”可触发打开，“已开且尚未持物”可触发抓取，
“已持物且目标可达”可触发放置，“已放入且门仍开”可触发关闭。它不是覆盖任意初态的完整抽屉控制律：
手持物而门关闭、遮挡、滑落等情形还需要其他规则。列出这几个词不等于解决了这些情形。

### 17.2 从规则到完整LoRA：给出可达性构造，但不把前提藏起来

在一个目标层，假设当前h中确实存在足以区分两个适用状态的方向`a_1(z),a_2(z)`。
令`p_i(x,z)=a_i(z)^T h(x)`，`b_i(z)`是与相应作用有关的输出方向，则

```text
Delta y(x,z) = b_1(z) p_1(x,z) + b_2(z) p_2(x,z)
             = [b_1(z), b_2(z)] [a_1(z)^T; a_2(z)^T] h(x).
```

这是一个rank至多2的真实低秩作用，scale可吸收进B。教学只在开始时确定A/B；随后p随机器人自己的h变化。
若新初态中第一项适用性为零、第二项非零，就可以跳过第一项而执行第二项，不需按视频时间播放。
将同样的计算分布到38个target，得到的仍是一套完整LoRA，而不是多adapter或运行时教学Reader。

这里的b不是“向右移动”的物理动作标签；在Q中它先改变读取，在suffix V中改变动作位置的内容，
还须经后续原生层和flow生成才到实际动作。a也不自动是逻辑谓词。构造只证明：**若所需状态方向和有效作用方向
已经存在且可由教学确定，固定低秩参数能够承载相应反馈规则。** 它没有证明当前rank、特征、共享head或训练足以做到。
不能把假设存在的方向作为部署字典或新增固定技能基底；ProcessPullback等旧结果已反对据这种分解直接收窄出口。

对实际多个target、位置和head，令`g_l=partial L_FM/partial y_l`为完整下游反传的adjoint，
省略scale和样本权重，则教学特征收到的精确链式信用含有

```text
partial L_FM / partial m
  = sum_l (partial B_l / partial m)^T : [g_l (A_l h_l)^T]
        + (partial A_l / partial m)^T : [(B_l^T g_l) h_l^T].
```

冒号表示与对应矩阵梯度收缩，l同时含实际调用位置的求和。前层LoRA对h的影响已通过反传adjoint计入，
不是固定所有h后又把间接项遗漏。第一项学习怎样写入，第二项学习在哪些当前激活上写入；两者最终都由真实动作误差决定。
零B会暂时使A侧信用为零，这是已知合法identity学习顺序，不是再次定位到的工程错误。
有了非零梯度也只说明存在更新，尚未说明不同任务的更新会形成同一种可迁移解释。

### 17.3 一个能算清方向的例子：动作误差怎样教“绑定谁”

考虑局部解释模型中的两个竞争绑定。`k_1(x),k_2(x)`表示在自身执行query x上，两种绑定经过真实控制计算产生的
**FM输出修正**，不是两块图像的embedding；完整模型中可由可达LoRA方向的功能Jacobian在当前点定义。
暂时固定这两个函数与其他作用，只让教学产生标量`c=sigmoid(ell(z))`，预测为

```text
v_hat(x,z) = v_ref(x,z) + c k_1(x) + (1-c) k_2(x).
e = v_hat - Y,             L = (1/2) E_{query|z} ||e||^2,
partial L / partial ell = c(1-c) E[(k_1-k_2)^T e].
```

若条件平均的理想修正确实为k_1，残余标签噪声与`k_1-k_2`条件正交，则

```text
partial L / partial ell = -c(1-c)^2 E ||k_1(x)-k_2(x)||^2.
```

因此在`0<c<1`且两种绑定有不同功能作用时，梯度下降会增加正确绑定的权重。
这给出了动作标签→实际功能差→教学绑定的具体学习联系：同一视频服务另一episode的多种自身状态，
“抓目标物”与“抓干扰物”若在这些状态需要不同输出，误差可以反向教视频特征区分它们。
不需要把query动作塞进Writer输入，也不需要把teacher动作当作视频条件。

这个例子还给出三个严格限制：

1. 若两种绑定在被监督query上的功能作用相同，该信用为零，即使视觉位置、注意力或对象分类完全可分。
   应区别“在功能上没有可区分作用”与“整体梯度为零”；其他通路仍可有很大梯度。
2. 若k_1不是所需修正、残余误差来自其他操作，梯度方向由上面的相关项决定，不保证奖励语义上正确的绑定。
   真实模型还共同学习k、特征和生成器，不能把这个固定函数例子的收敛性移植过去。
3. 例子并未建立**动态视频的必要增量**：ell也可能由语言或静态外观学成。
   视频中观察到的变化若有用，必须改善这种功能选择或作用的估计；“成功绑定对象”本身不足以兑现Owner目标。

同理，可以把竞争项理解为两种操作作用或两种状态适用性，但不能凭替换名称宣称网络已形成这些语义。
多个合理动作模式下应使用真实FM条件目标，不把所有专家动作先取均值再当成唯一物理动作。
若参考函数在某个状态已经正确，所需修正可能为零；FM应当允许该处的教学修正消失。
这与视频在其他状态有必要作用不冲突。强迫每个状态都有明显视频响应，反而可能损害已有能力。

### 17.4 有限共享学习需要什么：自身状态差异与跨任务语义差异不是同一件事

上例固定一个condition解释信用方向，尚未解释为何新的教学也能获得正确LoRA。
为写清这个差别，在一个**局部可达、固定特征**的子模型内，用m(z)表征教学，D(z,x)表示合法LoRA坐标到
FM输出的功能Jacobian，设坐标位移`d(z)=Theta m(z)`。D允许依赖执行语言与状态，不假设所有task共享同一D。
这只分析该可达子模型；当前生成器并不因此获得任意Theta，更不能据此承诺全局收敛。

```text
v_hat = v_ref + D(z,x) Theta m(z),
Phi(z,x) = m(z)^T kron D(z,x),
Gamma_train = E_train[Phi^T Phi]
            = E_train[(m m^T) kron (D^T D)].
```

这里采用列优先vec(Theta)，任务与query权重包含在期望中。平方FM在此子模型的学习由联合功能特征Phi约束。
它同时要求：同一条件下的自身状态区分应如何作用，和不同教学间的特征区分应如何共享这种作用。
更多同task episode主要增加第一类采样与估计精度，不能自动增加第二类独立映射；
更多task也不自动增加有用的独立关系，不能用task数替代这条联合关系。

一个明确的反例：取`m=[1,b]`、自身状态特征`h=[1,p]`，四个可达函数特征为`1,b,p,bp`。
设正确修正是bp，训练只见到`(b,p)=(0,0),(1,1)`。即使视频把b识别得完全正确，
`f=b`、`f=p`和`f=bp`在所有这些训练样本上都完全正确；换到`(1,0)`或`(0,1)`时它们不同。
复制更多相同关系的跨episode样本并不消除这个歧义。这个二值例子只证明一种有限支持的非可识别性，
**不是说LIBERO或当前sampler就具有这种关系**，也不是建议补这四个格子的实验。

更一般地，两个系数解相差d_theta，若`d_theta`在`Gamma_train`的零空间中，它们在该训练分布上不可区分。
对新任务／新状态分布定义同样的`Gamma_new`，要从训练函数相同推得新分布函数也相同，必要且充分的是

```text
ker(Gamma_train) subset ker(Gamma_new).
```

这是此有限维子模型中的函数可识别性条件，不是充分学习保证。若还有有限常数kappa使
`Gamma_new <= kappa Gamma_train`（半正定序），则两解的期望平方功能差满足
`E_new ||Phi d_theta||^2 <= kappa E_train ||Phi d_theta||^2`。
即使没有精确零方向，kappa很大也会放大有限估计误差。没有测定EMBER的Gamma或kappa，
不把它们写成已发现的病因，也不据此派曲率测量、白化、任务重排或更多数据实验。

这些式子仍省略了真实有限学习中的表示变化、非线性、optimizer状态和闭环分布变化。
旧73/75任务扩展及C11关系支持干预的负例已经排除“补任务数量／某些关系就够”的简单版本；
private Writer、freeAB与lookahead结果也不支持由这个式子直接认定参数生成或预条件是统一瓶颈。
旧C11本来就有目标关系行空间的可识别性论证；这里换成实际功能联合特征是明确其适用条件，不能冒称首次发现支持问题。
在本子模型内，`m'=R m, Theta'=Theta R^{-1}`可保持函数不变，所以单个中间坐标是否像一个语义标签并非必要标准。
这只是函数的重参数化性质，不表示不同坐标下optimizer的有限学习轨迹相同。

### 17.5 跨episode主项实际上鼓励视频保留什么、舍弃什么

继续采用上一节的局部线性功能模型，再明确增加条件：固定分析任务T，参考LoRA不随teacher改变，
故D与r=`Y-v_ref`只随执行query变化；教学m与该query在给定T后独立。T只是分析训练分布的索引，
不是允许Writer读取task ID。该独立性不能直接套到排除teacher造成相关的有限池或自身episode辅助项。
定义`mu_T=E[m|T]`、`Sigma_T=Cov(m|T)`、`F_T=E[D^T D|T]`，则有精确分解

```text
R_T(Theta)
 = (1/2) E_query ||D Theta mu_T - r||^2
 + (1/2) tr(F_T Theta Sigma_T Theta^T),

partial R_T / partial Theta
 = F_T Theta (mu_T mu_T^T + Sigma_T) - beta_T mu_T^T,
beta_T = E_query[D^T r | T].
```

推导只需将m写成mu加零均值项，独立性使交叉项为零。特别在`Theta=0`处，标签驱动项是
`-beta_T mu_T^T`：动作监督把该task需要的功能修正与教学中跨视频共同存在的特征联系起来。
视频间波动是否有代价，则由`F_T`和实际读出Theta决定，不是裸embedding方差决定。
位于功能零空间的变化不因此受罚；有效的不同非线性策略也不能由这个局部模型一概要求相同。

这个分解说明一个具体的配套关系：如果视频编码把可复用的对象作用／关系变化稳定地表达出来，
主FM可以把它与跨初态所需的修正配对；如果编码主要随示范者路径、时长、初始位置波动，
这些波动没有相应query标签支持时，传播到实际功能反而增加该局部风险。
encoder收到的`(partial m/partial psi)^T Theta^T D^T e`也必须经已经形成的功能读出，
才能将这个压力变成特征更新。共同可微提供了路径，没有给出“先识别语义、再自动学控制”的收敛保证或课程。

这也解释为什么“同task换视频，LoRA必须明显不同”不是正确目标：可迁移过程知识可以跨正确教学保持，
但在不同操作关系之间仍产生不同的有用控制作用。语言也可能预测mu，所以这里仍未证明视频相对语言有新增能力；
关键是有限学习器能否从视频获得在新任务上更好的功能映射。

这是对既有跨episode目标的局部展开，**不是新增的一致性正则**。findings§128已经核定两teacher平均FM的期望
仍等于单teacherFM，CV-CSD/DJNFR等旧近邻也不支持据此开多teacher改法。
mu仅是分析期望，不是部署时平均frames、features或多套LoRA的操作；本节不改变集合编码与唯一LoRA合同。

### 17.6 接到实际执行，并明确FM尚未担保的部分

本节的Y是当前实现真正使用的`noise-actions`；带噪输入为`tau*noise+(1-tau)*actions`。
`writer/function_credit.py`将真实7维、完整动作horizon的误差传给同一套LoRA，
`writer/supervised.py`同版本重放Writer。已登记的辅助teaching项也回到这套LoRA，不把它误说成所有当前训练只有跨episode主项。
本节跨episode推导针对主项；辅助项的采样依赖及权重不能自动满足相同独立性条件。

部署在冻结输入观测的一次replan中，实际10步Euler为`a_(j+1)=a_j+dt*v_w(a_j,tau_j)`，`dt=-1/10`。
固定同一初始noise时，在可微位置令`S_j=partial a_j/partial w`，则

```text
S_0 = 0,
S_(j+1) = (I + dt partial_a v_j) S_j + dt partial_w v_j.
```

最终还经过真实action维度选择、反归一化，执行前5个actions，再读新观测并replan。
所以LoRA的作用不是某一次FM query的数值；它沿实际生成轨迹影响动作，又通过环境和后续反馈影响能否完成任务。
这里仅核对现有`modeling_pi05.py:forward/sample_actions`并作链式推导，没有模型运行，
不恢复已撤回的flow位置实验，也不把通用采样性质改称EMBER失败解释。

跨episode监督能鼓励同一视频在不同自身状态下产生正确控制，但它只约束被采样状态与flow点上的误差。
闭环能力还要求训练所得作用在实际访问状态附近有效，且纠正不会把原本成功的路径推离可恢复区域。
这不是靠公共adapter保持不变或LoRA范数小即可保证。当前C0相对语言的27 gained／28 lost，
以及历史共享更新改变未采样条件的目标选择，都要求用完整成功集合检验保持；不能只看新获得能力。
上述实际作用链只是说明为什么需要这个行为判断，不构成新增保护loss或模仿所有旧输出的理由。

后续若继续理论工作，必须形成对完整方法有不同预测的解释并用既有证据裁决，不能只再列风险与公式。

## 18. 获取与保持的竞争解释：可以裁决什么，不能据此自动选什么

本节消费主讨论的第二段自主理论接续，沿用已验收证据，没有新模型／环境计算或文献扩展。
结论是：**共享更新损失部分已有能力有直接证据；“完整视频控制知识已经就绪，只剩解码／保持”没有相同强度的证据。**
也不能反向认定encoder必然缺信息。把这两个宽泛叙述直接当作互斥根因，会再次产生无法被负结果结束的修补循环。

### 18.1 先固定“已获得”指什么

必须区分以下四件事：合法视频包含线索；表示保留可利用线索；已训练的共享映射能一次生成有益完整LoRA；
后续训练保持这种能力。即使假设存在任意复杂的decoder可从raw video或唯一语言得到答案，也不等于现有模型已经学会控制。
从当前表示重新用动作标签训练一个decoder，即使成功，也首先说明这些表示可被该学习过程利用，
不能无条件倒推重学习前已经存在完整控制知识。

反过来，“缺知识”也不能定义为没有某个可读语义坐标：§17的可逆重参数化保持函数却改变坐标含义。
真正的已获得能力，应有冻结、合法输入、共享映射及实际执行的功能见证，并注明任务／初态／视频范围。
完整任务目标不要求每个模块先有独立教师或诊断通过；最终Writer本身就可以提供这种见证。

两个解释若要讨论具体位置，可先采用如下有限局部模型。r(z)表示理想的可迁移操作关系，n(z)表示其他教学变化；
z仍只有合法语言和视频。r不是新标签、特权条件或当前已经恢复的语义。记

```text
m_t(z) = S_t r(z) + N_t n(z),
d_t(z) = M_t m_t(z),
v_t(x,z) approximately v_ref(x,z) + D(x,z) d_t(z).
```

d是合法完整LoRA的局部坐标位移，D是它对实际FM输出的功能Jacobian；S/N/M只是解释模型的矩阵，
不是新的LoRA A/B结构，也不是新固定技能字典。完整部署仍由实际38-target LoRA和source反馈执行。

- **获取不足的具体模型A：** S丢失了所需关系方向，或只在已见任务上将关系同场景／对象签名相联系；
  在明确限定的共享decoder类和学习范围内，M无法从现有m恢复新任务需要的作用。
  训练FM仍可下降，n仍可造成强视频敏感，且部分task仍能学成。这个模型不声称所有视频信息都不存在。
- **保持／编译失配的具体模型R：** 较早的S/M组合曾在指定范围产生正确作用；后续共享更新改变M，
  或S改变而M未配套，从而损失原作用。固定S、仅M改变就是一个完整的充分机制；
  它与“source权重冻结”完全相容，也不要求所有任务一起退化。

在一个标量关系方向上，A可取`S=0,M=1`，R可取`S=1,M=0`，两者当前都输出零修正；
R较早取`M=1`时则曾经能用这个关系。再加入相同的n通路，两者也可同时具有非零视频响应和其他梯度。
这是输出不足以定位内部原因的构造，不是两者能复制全部EMBER训练轨迹／梯度的证明。
它提示：当前行为差、特征可分或某个梯度非零，都不能单独判定A或R。

真实联合模型的一阶参数作用可以按既定切分写成

```text
delta w(z) = J_{C,omega}(m) delta omega
           + J_{C,m}(m) J_{E,psi}(z) delta psi + higher-order terms.
```

固定E的真实输出映射干预能说明第一条路径足以产生某项变化；整体继续训练则混合了两条路径。
这种切分并不使两类科学问题互斥：某些能力尚未获得，同时其他已获得能力被后续更新损失，是允许且符合现有现象的情况。

### 18.2 现有证据怎样约束这两个完整模型

以下是对已经看过的证据作回顾性约束，不是新的事前预测或重验结果。

| 已验收事实 | 能支持／削弱什么 | 仍不能推出什么 |
| --- | --- | --- |
| 旧v5.2普通FM、A900的Core/P交叉和冻结后续内容有过有限实际正作用 | 削弱“合法视频根本不能被这种整体路径使用”“FM没有动作信用”的强A版本 | 不证明当前表示已具备完整、稳定、超过匹配语言参照的过程知识；不同协议不能拼成时间遗忘曲线 |
| 真G较source有有限闭环收益，合法NativeCorrection／LocalField获取不足 | 单LoRA执行侧存在有用纠正；获取这个纠正的共享映射仍未兑现 | 真G用了动作信息，不是固定RGB表示加一个更好Compiler的对照；不能据此宣布答案已经藏在E里 |
| SemanticPath与实际空间Q/K监督均有完整学习和负结果 | 削弱“只要显式路径／落到正确区域就会学出控制关系”的简单A修复 | 不证明所有语义学习无效，也不证明问题一定转移到Compiler |
| 旧联合Video Functional、VL版本及固定E的native reader未建立强功能教师 | 下调“放松成执行条件读出，就能释放现成控制能力”的简单R修复 | reader负结果不能证明所有decoder都失败；旧reader没有相应闭环结果，不能将学生分数算成reader分数 |
| C600 private Writer／freeAB为16／14（各32） | 本窗口不支持直接A/B明显优于完整Writer，削弱输出参数化必然卡死的解释 | 两臂都使用task-local动作更新，private Writer也改变表示；涨分不是更新前已学会合法视频知识的证据 |
| 旧共享D替换可在读取／Compiler保持时改变抓取对象；D学习可提高train而降低validation | 输出映射的共享改变足以改变其他条件的实际控制；保持风险并非只是假想 | 不证明D处处有害、E已充分，或缩头／冻结共同底座就能修复；同一D也帮助过其他条件 |
| H54缩头、任务lookahead没有超过各自普通更新参照 | 下调相应步幅／局部更新修正的充分性预期 | 不能扩大成所有优化方法无效；更不能继续以同一几何叙述反复改配方 |

尤其须区分两种成功集合差异。当前C0与独立语言B的27 gained／28 lost是**方法间交换**，不是时间上的遗忘。
它说明方法并不等价，但没有证明C曾经把这28个条件学会后又忘掉。
同一D的1050→1260则确有时间上的行为损失：held123→91，保留63／得28／失60，同时seen31→36（findings§135）。
这支持部分已得能力未保持，但仍不能将其唯一归因于E、Compiler或梯度冲突。
正常的小幅能力交换仍按Owner当轮标准判断，不从这项分析新设“零丢失”硬门槛。

### 18.3 哪种改变才能给出不同预测，以及为什么当前不能自动派一轮

如果A被具体限定为“固定E在规定共享decoder类中缺少所需功能区别”，而R被具体限定为
“同一E已保留这些区别，规定的合法共享学习算法能恢复其完整LoRA作用”，那么下面的**完整方法改变**才有相反预测：
固定现有教学E、source、授权meta数据和信息墙，改变共享Compiler的学习，部署仍只生成一套完整LoRA。
A预测不能建立所缺的跨task有益视频作用；这个强R预测能够恢复，并同时改善绝对能力与保持。

但要使这成为有信息量的实验，必须事前给出具体decoder类、学习算法、范围、预算，以及为何它会改变旧D／DJNFR／
直接出口／Reader等最近完整负例的失败预测。当前没有这样的新增依据，因此这只是判别逻辑，**不是待执行合同**。
若允许每次失败都说“换个更强decoder或再训久一点”，强R就没有可失败内容。
若新Compiler重新从动作监督学习了额外控制规律，成功也只说明固定E可用，不能将新增学习全部算成旧知识的恢复。

反方向“固定Compiler，再给E加语义监督”也不是天然只检验A：它可能增加关系信息，也可能仅重新对齐原有接口，
因此R同样可能受益。完整端到端涨分有价值，但单凭涨分不能区分这两个解释；
不能将旧空间边际／状态路径／LocalField换成另一个标签名就取得启动依据。

同样，直接交换early E与late Compiler可能破坏正常共适应：在可逆接口例子中，`m'=R m, C'(m')=C(R^{-1}m')`保持完整函数，
交叉搭配仍会失效。这个代数例子只说明交换需要额外解释；不是新对齐工程或跨checkpoint拼接部署方案。
成功回放某个旧完整checkpoint能证明它当时有能力，不能自动回答新方法怎样兼得新增能力与保持。

这些限制不会要求先排除所有解释才能换架构。一个有独立机制依据的完整新方法仍可直接作有界检验；
它不必以强Reader、每个语义谓词、oracle标签或一串模块诊断作为前置课程。
需要的是对合法视频如何形成可迁移控制作用的实质变化，以及与最近完整失败图不同的可失败预测。

### 18.4 本轮投入裁决与这条理论线的终点

1. **不以“现成视频知识只差读取／保持”为下一路线的默认前提。** 它需要的合法、共享、可迁移功能见证尚未建立到
   所声称的程度。特权纠正、task-local适配与表征可分性都不能补上这个前提。
2. **保留能力保持为同时目标，但不让它替代知识获取。** 当前有真实时间损失与共享映射干预证据；
   减少这些损失也未必创造超过语言／强MT-BC的新视频作用。共同底座、缩步、冻结或预条件不由此自动成为候选。
3. **也不将主线反转成encoder修复。** 合法完整图已有正例，语义路径、动作辅助和直接cotangent消费也已有负例。
   新方法应重新组织完整的功能学习关系，而不是把尚未定位的责任迁到另一个模块。

本轮没有产生足以启动的新完整候选，因而没有编造运行预算、派发实现或新增GPU。
最少缺的依据已明确：若坚持“恢复现成知识”解释，需相称的实际功能见证；
若直接提出新方法，需说明其具体学习机制为何改变最近失败预测。这是各自主张的证据责任，不是要求先运行两套诊断。

这次比较主要收紧了可诚实主张的范围，没有得到新的实证根因或验证修复。
继续从同一批证据反复展开“可能缺语义／可能优化不好”已不会改变投入裁决，故**本条理论延长线到此收束，不再自排同类公式／报告任务**。
整体EMBER目标未完成，自主研究授权仍有效；Reader撤回、S0不重跑、唯一指定执行者及全部新增data1等约束继续有效。
