# EMBER concept

EMBER研究能否把exact task language与action-hidden正确教学视频，编译为冻结π0.5 source的一套完整task-conditioned LoRA，
使机器人从未见初始化闭环完成任务。编译期允许有预算的真实实践、任务内学习及多轮LoRA修订，最终固定唯一LoRA后适应过程退出。
离线教学只有指定视频和语言，不读teacher episode动作/state等配套标签；自身交互的动作、观测、物理状态、接触、奖励、成功与终止可用于学习。
语言说明目标与关注对象，视频应帮助学习怎样完成任务。有交互结果与旧零交互结果分开计量。
人从他人教学迁移到自己身体的能力是科学动机；LIBERO结果本身不证明跨身体泛化。

**方法边界：不接受先准备动作轨迹数据，再微调得到最终LoRA。** 轨迹来自视频恢复、合成、搜索或真实实践，
数据生成器是否可学习，以及采集／微调是否交错，均不改变这一排除条件。最终留下LoRA不足以把数据构造称为参数编译。
共享Writer可以用合法动作和功能监督训练；面对新教学时，须由学到的编译机制生成或修订LoRA，
自身经验服务这条编译联系，不能成为末端策略微调的替代路径。具体编译算子由当前设计选择，未指定单网络或单次前向。
观看、实践、重读与参数修订不预设固定轮数；实际次数由证据与资源预算产生，不以两轮、三轮或轮数菜单代替开放循环。
在相近的新初态闭环能力下，优先更少教学读取、实践与计算；实际重读量是调整效率的结果，不是需完成的配额。
Owner最新允许把既定MT更新合并成冻结基底，再生成唯一38-target任务残差LoRA；原source只读保留，
部署不叠第二套动态adapter。优先后继是rank8，rank4据能力/成本再判断，不作8/4/128三臂扫描；
确定性非零随机A/B0使残差初始策略保持MT。该授权覆盖此前完整rank128-only取舍，读取meta rank32不随之改变。
当前八条rank128教师照原合同完成；尚无低rank计算，输出维数多也不等于已证实过拟合或rank8容量足够。
专家的阶段安排与停止线只帮助分配投入；主讨论须自主分析、调整并接续，不以新许可请求代替持续推进。
完整能力和计算效率共同约束方法选择。架构应支持有用的GPU批量计算、跨条件并行和明确的计算复用，
训练组织须解释真实交互与共享学习如何交替；不能把长期串行等待固定成方法的必要代价。
低利用率须由实际计算、搬运、仿真与等待分解解释；最终看端到端吞吐及达到相近能力的总成本，不以空占或额外无益计算改善指标。

本文保留科学对象、信息流与证据标准。稳定要求以[Owner要求](current_owner_requirements.md)为准；
当前授权及active design只看[progress](../progress.md)，已完成实例的配置、曲线与结论由封存设计和报告保存。

## 可达能力、学习过程与部署效果是三层问题

旧零交互Writer输出为`G_phi(language, video)`；后继编译器可以结合视频、语言、控制起点与自身实践，生成或修订最终LoRA。
观看与实践可以循环多轮，但不能经由准备动作轨迹后拟合策略来替代编译；最终同一教学condition的一套固定LoRA覆盖所有新的评测初态。
从教学读取到最终参数的整个适应算法替代旧Writer，应有完整的内部状态、更新与结束规则；可以包含不同学习形式和显式过程。
教学须提供实际有用的操作知识，经实践反馈改变有针对性的尝试、学习及最终能力。仅有视频输入而收益主要来自额外任务内训练，
不满足这一科学对象。早期完整循环可用少量机制相关的公平证据辨认贡献，不把全部对照设为开工前提或把核心问题全部推迟到末尾。
所需视频表示必须有实际获取和学习路径：物理状态标签不自动包含操作必要性或保持条件，视觉路径也不直接等于控制命令。
Owner提出的固定LoRA退化解是
`G_phi(language, video) = theta_shared`：如果模型类能表示这一常量映射，同rank共享LoRA的可达策略就在其解空间中。
这是理想可达能力的下界参照，不是对有限训练轨迹的保证，也不推出先训练公共底座的课程。
研究问题是端到端学习怎样实现并超过这一解；不能把rank差异或当前实现限制当作研究结论。

在已执行的(A₀+S,B₀+M)方案中，A₀/B₀是跨任务共同学习的执行参数和native读取参照，S/M是当前教学形成的适配。
Writer承担学习如何从教学生成适配的元学习，具体控制在冻结source与唯一完整LoRA中执行；编译后Writer退出。
该方案采用完整FM共同训练，不额外约束A₀/B₀的独立无视频能力，也不预设因子间知识互斥；公共分数作为诊断。
这个取舍不证明公共目标永远无效；增加它仍须有独立部署需求或完整能力收益依据。具体读取、编译、信用与边界见
[条件读写完整架构](designs/conditional_read_write_architecture.md)；实施与运行状态由progress登记。

性能是正确条件下的闭环能力；特异性用于解释教学内容的有益作用；稳定性描述能力如何在训练和条件变化中保持。
最终性能目标是利用教学视频获得可迁移执行知识，使EMBER超过如实训练、如实选点的强MT-BC。
第一阶段先让最终固定LoRA的完整任务表现明显超过强MT；不要求先胜同预算的充分语言适应，具体方法仍须说明视频怎样参与能力学习。
语言/单帧/无序参照用于辨识知识来源和学习机制，其差额不替代这个目标，也不要求先完成所有对照才能研究利用方法。
MT-BC在此是最终性能参照，不是待诊断的技术故障；某次未完成任务不能被命名为EMBER应去解决的“MT-BC失败问题”。
方法推导首先解释EMBER如何从教学获得能力，再由匹配比较判断其优势，不以先诊断MT-BC为前提。
视频输入引起Proxy、LoRA或动作变化，最多证明影响存在。正确视频和另一正确视频都获得能力，且相对于合法语言/static参照
有增量，才更接近“Writer利用了教学内容”的主张；仅wrong下降或时间重排敏感不够。

下面三点是2026-09-23讨论形成的解释框架，**不是已经验证的根因或新实验授权**：

1. **生成参数的学习几何。** 写`theta_i=G_phi(z_i)`，`J_i=dG_phi(z_i)/dphi`，
   `g_j=dL_j/dtheta_j`；普通SGD的一阶输出位移为`delta theta_i ≈ -eta sum_j alpha_j J_i J_j^T g_j`。
   因而任务间功能迁移依赖生成器建立的条件联系；Adam、裁剪和有限步幅还须按真实更新核验。
   这个公式不证明梯度冲突、某个头受限或改归一化有效。当前私有Writer与自由A/B的局部比较未显示后者明显占优，不能沿用旧模型的容量诊断。
2. **辅助目标改变了什么。** 实际flow输入`x_tau=(1-tau)*a+tau*epsilon`，目标`epsilon-a`。
   tau=1时速度MSE等于`epsilon-v(epsilon,1,condition)`对真实动作的MSE；它从纯噪声端点强调条件预测，
   但条件也含执行观测和语言，不保证教学视频被利用。第二组从mean50改成mean5，使其中每个执行前缀位置的名义系数增大10倍；
   这不是实测梯度10倍，也不是10步flow最终动作误差。端点、horizon和episode配对是不同变量，不混称标准FM或单一辅助机制。
3. **学习条件映射需要任务关系。** 同task跨episode查询有助于阻断逐帧复制，但同task固定语言和多条视频也允许已见任务识别。
   更多episode不等于更多独立任务映射；训练支持、视觉表征、共享参数和损失一起决定是否学出可迁移操作关系。
   这不等于视频无信息或理论上必然无用。检验数据原因应固定诊断目标，再控制训练支持与总监督预算。

固定四臂只能分辨直接参数优化、语言条件生成、完整视频路径和目标组合的整体差异；不能单独定位具体模块或数据根因。
后继须预先区分竞争解释，再以针对性干预检验功能预测及闭环收益，而非把四条曲线本身称为根因答案。

## 信息如何成为执行能力

```text
exact task language + action-hidden、内部有序的正确教学RGB视频
  → stride5及真实末帧；每条视频独立编码，保留时序与视角身份
  → 教学读取与已有模型知识：任务相关视觉内容、过程关系和候选操作
  → 当前完整LoRA/原生Action Expert参与行为提案与真实实践
  → 自身动作/状态/接触/奖励等反馈参与教学重读与编译机制的修订
  → 将教学知识编译为同一套38-target完整A/B LoRA；不转为轨迹准备后的策略微调
  → 适应结束后固定唯一完整LoRA；在新的初态由登记的冻结基底闭环执行
```

语言负责目标与关注对象，视频提供实际操作及其后果，执行观测确定机器人目前应做什么。
教学读取、实践反馈与参数编译的具体分工由完整设计选择；第五轮起“发现行为再微调LoRA”的路线已被Owner排除，source基础权重冻结。
已有动作知识应有明确计算作用，不能以无真实prefix、假动作query或无意义forward代替。H是条件化动作计算响应，
并非恢复出的teacher action或真实环境后果；应充分考虑完整horizon的价值，不把固定probe读法当硬约束。
Video time、action horizon、flow time和layer depth分别解释。

source基础视觉/语言权重保持冻结。Owner于2026-10-10进一步明确，本轮Gemma与action expert可以分别用fresh meta LoRA
学习教学特征；这些共享读取参数在新condition固定，并在最终部署时退出。最终执行的Gemma仍为原冻结source，
只安装一套完整任务LoRA。读取适配与最终执行参数分开，动作侧编译失败不直接证明前缀表示不足；
仍须解释真实特征怎样经Writer形成有用控制，而不能把新增meta LoRA本身当成机制改进证据。

操作内容、顺序与条件作用可以由不同结构表达；Core、Procedure、memory token和具体decoder都是候选实现。
模块须职责清楚、能复制加深并自然扩参；选择由完整相关历史及实际行为决定，不把某次局部诊断变成永久结构限制。
共享参数和结构依赖提供学习偏置，不保证视频必要性、迁移或能力保持。

Owner已明确允许在发现问题后更深入推导修正，并更大胆地重构架构。原生特征接口、动态表示、
读写方式及公共/条件分工均须接受实际机制证据检验，不能因继承关系把修正限制为原结构内的小补丁。
主讨论负责提出完整替代原理及其可失败预测，再以有界干预与闭环能力判断；现有数据和部署科学目标保持。

Owner于2026-10-10进一步要求，完整架构及训练方法从实际问题和数学推导共同产生，并完成实现与有界验证。
现有框架本身可以撤换；第一性原理体现为实际特征、可计算关系和学习职责自洽，不意味着一个公式能保证学会。
例如可以让共享模型学习功能修订，再由真实policy计算关系写回参数；是否采用及如何训练由active design登记，
不能把这类分工、某个导数形式或更少模块直接写成已证实的机制优势。修正应继承完整历史，有计划地解决不足。

## 信息墙与共同学习

Teacher episode的action、state/proprio、reward、terminal、task ID、filename、pose和特权policy outcome不进入教学条件。
适应期可用自身交互的观测、动作、环境状态及奖励等反馈，亦可据此学习；信息合法性由来源区分。
预算、重置及停止规则须登记，最终评估初态不参与该condition适应；最终actor只保留既定执行输入，不再运行适应辅助模块。
一套最终生成LoRA覆盖所有38个执行目标，
不挑视频、不平均最终LoRA、不融合checkpoint，也不部署第二expert adapter。
两相机是同一时点的同步观测，不是K=2；如声称dynamic K，必须训练覆盖各cardinality，并只在集合阶段做置换不变聚合。

既有共享Writer主监督使用同task、跨episode的真实执行FM；新的共享训练与编译修订组织可在上述方法边界内选择，
明确初始化、冻结/更新参数、标签来源、梯度消费者与实际部署作用，不把训练共享Writer的监督混同于新condition的末端轨迹微调。
合法训练任务的动作等标签可以用于共享能力或评价学习；validation离线标签、最终评测反馈不用于更新。
自身实践中的完整成功、有效局部行为与失败须按功能区分；其反馈可参与编译理解和修订，不能筛成动作训练集后直接微调最终LoRA。
任务内参数副本与共享训练状态分开，不能把held适应混成未经登记的跨任务训练。参数更新后依赖它的缓存也须按真实计算失效。

## 怎样判断

首先看single-checkpoint strict paired400的正确视频绝对能力，再看相邻成功保持、任务广度、四suite、获取/丢失与churn。
性能接受标准服从Owner最新要求，历史门槛只约束对应封存实验；loss、参数几何和内部时序margin不替代闭环。
正式K1每task每轮使用全部50条teacher各一次，state–video映射与policy RNG跨checkpoint固定。

同task换视频检验条件覆盖；选定并冻结checkpoint后，以严格配对的wrong／no-video／shuffled／reversed controls检查视频作用。
顺序干预须重排真实frames后完整forward，不能用hidden扰动代替。输入敏感、顺序敏感和正确教学带来有益增量分别判断；
source不是learned language-only/static prior。开发诊断及其反馈范围须另有明确登记，Test默认封闭。
连续有信息量节点没有改善时，应综合证据裁决实际检验的假设，不靠无依据的小扫或无限续训延长。
