## 一、目标和约束

输入exact task language及一条或多条同任务、action-hidden、内部有序的正确教学视频，rollout前一次生成冻结π0.5 source policy的一套完整task-conditioned LoRA，从未见初始化闭环执行。当前研究K=1，stride=5；不是按教学时间回放动作，执行policy仍读取自身当前观测。

当前优先目标是：正确视频内容和有序过程带来可重复的闭环执行增量，并能跨同任务视频、初始化、相邻single checkpoints和固定validation任务保持。暂不要求长期145/400目标，但正确条件应有实际收益；只让错误条件变差、辅助预测更准或LoRA更敏感均不算完成。

固定LIBERO train24/validation8/test8。source从generic `lerobot/pi05_base`和排除目标重合后的source71训练得到，source及normalization冻结。当前共享Writer梯度只来自train24；额外经审计non-held meta tasks可以讨论，但不能使用held梯度。

部署Writer不读teacher actions、state/proprio、reward、terminal、task ID、filename、pose或policy outcome。当前输出唯一覆盖Action Expert 38 targets的完整A/B LoRA，不部署第二expert、任务字典或多LoRA平均；rollout中不重新编译、不做task-local优化。当前生成rank16，但rank、memory、decoder等属于可讨论的方法选择；若建议改变已登记边界，请明确说明代价，不能默默改变研究问题。最终Test仍封存。

当前teacher videos为demo0–15、主执行动作监督为另一episode的demo16–41；train动作留出为42–45、闭环训练诊断视频为46–49。训练视频与主动作query跨episode。train96使用24任务×4个未见初始化；validation严格400为8任务×50初始化，每任务50条合法teacher videos各使用一次。对照配对state/video映射和环境、policy随机性；各研究内训练对照按实际曝光核验。不同研究间只有明确匹配的比较才可作单变量归因。

本阶段配对source参照为train15/96、validation47/400，不能默认它在目标任务已有很强的共同执行能力。评测同时保留per-task/per-suite、breadth、保留/新增/丢失、churn及相邻/换视频成功集合重合；低总分、差额CI跨零与充分证伪是不同判断，也请审视统计效能。当前训练不加入wrong/shuffle/reverse惩罚；最终内容与顺序controls在选点冻结后执行。这些后继均未获得selected checkpoint，因此尚无最终sealed因果资格。

## 二、最后一次专家意见及实际落实

最后收敛方案是：完整时间×任务token表示E，同时服务于执行状态条件化功能辅助头T和完整LoRA Compiler。辅助头通过冻结source的执行query读E，预测完整真实动作FM残差，不再强迫Value时间中心化；执行query可以改变动作修正的方向与幅度。

梯度为：视频表示/读取侧Meta接收`∇L_LoRA + ∇L_aux`；辅助头接收`∇L_aux`；Compiler/native D接收`(1−ρ)∇L_LoRA + ρ∇L_distill`，ρ按登记日程由0至1/4，蒸馏不回传表示。source冻结，Writer/Meta/Compiler共同fresh学习；合法identity初始化保留。

专家原文明确承认：辅助头仍可能借助近似常量的视频读出，主要学习执行状态条件化的共同修正；直接功能信用只提供可能的教学学习路径，不保证视频依赖。辅助头弱不证明E无信息，辅助头强而LoRA弱也不直接证明rank容量不足。

这套方案已经实现并运行。后续并非只改了一个参数，而是依次核验了读出学习、去蒸馏、teacher图文适配、去辅助监督、局部同episode动作配对及冻结视频预训练先验。实现接通和梯度检查通过，只能证明相应计算合同成立，不能证明科学机制成立。

当前在途模型的数据流为：exact language和RGB真实图文prefix → 带读取侧VL/Action Meta的原生完整50-H响应，以及冻结视频先验 → task-token条件化的有序过程表示 → target/rank Compiler → 跨任务共享native D → 唯一完整A/B。完整H是Action Expert内部响应，并非已经得到的正确动作轨迹；当前长程处理为过去单向。冻结source在自己的执行观测上使用这套LoRA，teacher侧不读取动作或state。

### B. 功能读出与学习信用的后续核验

- 固定main200的E，单独训练动作残差reader 64epochs：留出FM由.149662降至.140251，但原LoRA学生约.110025，24/24任务均优于reader。说明reader能学，尚未形成更强功能教师。
- 改为原生中层残差读出，固定同一E，训练32epochs：held .139792，与上述动作头无可信差异，仍24/24任务落后学生。两种具体读出均弱；不能据此直接认定E充分或完全无信息。
- 去蒸馏、保留辅助真实FM，fresh200：train correct/other 100步42/38、200步55/55，训练获取优于原方案；validation分别57/61、72/67，没有可信迁移或保持改善。

## 五、当前在途实验，暂不作科学结论

最近核实官方数据生产时序：`obs[i]`及其proprio为执行`actions[i]`后的观测，而旧主FM从同索引动作开始。当前唯一Writer已改为`obs[i] → actions[i+1:]`，去除无未来标签的最后query，保留完整teacher末帧；source及normalization不动。

这是具体监督一致性修正，不是已经定位全部失败根因。旧强模型的存在限制其普遍解释力；新旧合法query支持不同，不能把历史分数充当逐query配对的因果对照。

保持D项模型，fresh有序/静态100、200步比较正在执行。两臂100步检查点与400条件/25,600queries匹配已核验；动作留出FM为.1146888600/.1146933126，差额95%CI[−.000189566,+.000201983]，尚无可信差异。截至本摘要，200步及本轮闭环结果未完成；请勿预判为成功或失败。既定训练/配对评测将收尾，这次咨询不要求启动其它新实验。
