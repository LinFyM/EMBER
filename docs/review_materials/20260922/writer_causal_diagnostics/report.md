## D2：主项、端点前缀辅助项与 AdamW 一步

`g_A = g_J - g_Q`。一事件 smoke 的 `g_Q + g_A - g_J` 最大残差为 `7.276e-12`。下表是七个互斥参数组汇总后的全 Writer

辅助梯度在所有四个窗口都具有实质范数，且与主项不是标量复制；全局方向是低到中等正相关。C600-B36 的局部组则有反向成分：
Text Meta、VL Meta、Action Meta、Procedure 的 cos 分别为 -.217、-.132、-.222、-.044。所有四个 J preclip norm 都小于

在 B36，FactorHeads 占最大梯度组：C600 的 `Q/A/J=.041790/.030630/.056373`，O1200 的

## 可成立的结论与不可成立的结论

1. D1 证明 Core 与 Procedure replacement 均能通过现有解码器改变内部 bundle、LoRA 和动作；尤其 Procedure replacement
在两份资产上产生更大动作变化。它没有给出正确视频在闭环上占优的证据。
2. D2 证明当前端点前缀辅助项在实际 Writer 参数空间中是非零、方向并不完全重合的梯度项，并与 AdamW memory/weight-decay
以及总更新方向共同作用。它没有分解或证明 `tau=1`、前五步、权重 1/3 各自的必要性。
3. D3 的 18-step 小面板显示 J/Q/M 都能相对 C600 初始状态新增成功；J 仅在总成功多一条，Q 在 breadth 更高，且 success
sets 不同。样本太小、仅训练侧、无相邻节点，不能据此宣布辅助项整体有益、选择 J/Q/M 或改变正式 cross-episode 配对对照。
4. 本轮不恢复视频内容或顺序特异性的主张，也不定位历史性能下降的唯一根因。没有自动授权纯主 FM、改 LR、换 seed/rank/head、
新的 fresh 训练或 Test/FT/RL/外部比较。
