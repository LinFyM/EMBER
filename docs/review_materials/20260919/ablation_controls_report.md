# 固定1500：同视频教学与匹配消融的视频特异性

两组都在真实顺序破坏后下降，但没有证据表明同视频教学增强了这些control下的视频增量。以correct为参照，wrong／shuffle／reverse的两组差值之差为+16／+9／−9条，三个任务簇区间均跨零；换other作为参照也一样。正确能力165对147的优势仍成立于这个固定窗口，不能把它进一步解释成已识别的顺序机制。

主组selected1500在controls前已经冻结；消融也使用预先固定的1500，不另选点。本次新增消融wrong／shuffled／reversed各400，共1200条；correct147、other155复用原完整面板。共同source50仅计算一次，经source、normalization、环境及逐行RNG核对后复用，不虚构消融Writer的no-video前向。

所有validation面板均8任务×50初始化；每个读视频臂整轮使用全部50条合法teacher各一次，source臂不读视频。两组task／state／policy RNG／video ordinal以及真实RGB变换一致。打乱／倒放后完整重新生成。所有worker正常退出，400行及manifest证据核对通过。

## 视频增量的差值之差

## 可以与不能得出的结论

同视频监督在固定correct上提高能力，匹配消融并未消除顺序敏感性；本轮不支持把全部顺序效应归因于同视频辅助项。逆序下同视频组反而较消融高27条，而correct高18条，因此其correct−reverse gap更小；更大或更小的破坏降幅本身都不能作为方法优劣标准。

两个实验同样保留有序Procedure、完整H／相邻视觉读取及21＋7功能监督。当前没有“去掉全部辅助项”、learned language-only或静态视觉参照，不能分解这些未操纵因素。zero-LoRA为冻结source，与这些参照不同。

效应在任务间不均匀，三个任务在固定1500仍为零；错视频在部分任务反而有利。证据仅对应一个训练seed、八个验证task簇。区间跨零不证明两组等价；多节点／control区间未作多重比较校正。这些结果没有进入当前训练、架构修改或选点。2100和双相机没有继承本点的视频因果资格。
