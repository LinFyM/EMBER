# 同视频教学与匹配跨episode前缀监督：原1500窗口

两臂的原1500更新及全部登记面板已完成。同视频教学组在三个correct节点分别多成功24、38、18条；
固定1500换成同任务另一视频后多10条，但差值区间跨零。本轮支持教学episode对应关系的正向作用，
尚未证明收益对视频映射和训练预算都稳定。Owner追加的1500→2100仍在运行，另行报告。

## 配对合同

两臂使用相同source、完整Writer/三Meta、agentview、seed7、四任务逻辑更新、21个跨episode主query、
7个tau=1前五步辅助query、辅助权重1/3、学习率和1500更新预算。唯一科学变量为辅助标签episode：
主臂来自所看教学视频，消融臂来自同task另一episode。两项误差均经实际部署LoRA更新完整生成链。

每臂6000条件、126000主query＋42000辅助query，15个完整checkpoint；全部实际采样与登记事件一致。
6000个主条件、主RNG和辅助噪声流两臂一致；辅助动作对应所登记episode。source可训练参数为0。
主训练版本`39c3919c`，消融`bd497edc`，CPU/模型源码相同；条件配对关系由各自配置显式声明。

所有validation面板为400条，八task各50条合法teacher videos整轮各一次；train为登记的24×4有限面板。
逐行task、state、language、env/policy RNG、teacher映射、source、checkpoint和completion核对通过。
消融不另选checkpoint；other固定在已冻结的主1500。本报告读出时未执行消融wrong/order controls、Test或RL。
Owner随后授权的[固定1500视频特异性检查](ablation_controls_registration.json)另行登记，尚不纳入以下已完成结果。

## 学习和解释边界

冻结train held-action FM（0/900/1200/1500）同视频为 .146830/.104706/.100551/.098260，
跨episode为 .146830/.105001/.100298/.098404；输入固定、模型冻结且无梯度，不用于选点。
两臂末尾该FM很接近，不能用这个surrogate替代闭环差距。
更新计算时间分别24,360.39秒和24,638.06秒，不包含物化、评测和等待。

本匹配消融隔离辅助监督的episode对应关系，提供“收益不完全由等量额外动作监督解释”的证据。
它没有单独识别完整H/相邻视觉读取的作用，也没有与“完全去掉辅助query”比较。
换视频优势区间跨零、只有一个seed且三个任务仍零成功，因此保留有限正向结论。
主1500的[视频controls](controls_report.md)支持该点的有益顺序敏感性，其效应并不均匀；
这不能进一步证明同视频教学导致了全部顺序效应，须等待Owner新追加的消融匹配wrong/order面板。

继续训练两臂有明确价值：观察同视频组能否恢复并保持、跨episode组是否继续追近，而不是因某个中间高点提前选优。
追加节点遵守[续训登记](continuation_registration.json)，原1500冻结选择保持不变。
