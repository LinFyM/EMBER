## 1. 当前取舍及信心

我倾向于研究**共享训练的经验条件参数编译器**：教学视频与本 condition 的真实试做共同形成最终完整 A/B；
新 condition 使用学成的编译规则生成参数，不把任何恢复、合成或采集的动作当标签微调最终 LoRA。
作为第一个完整候选，先由固定强 MT 试做，再编译一次。固定试做策略是隔离学习问题和控制成本的选择，
不是 Owner 规定的一轮限制，更不是证明以后不需要视频引导的探索。

这接近 findings§403 和第四轮专家提出、尚未实施的元编译器。不能改名后称全新原理，也不能把它与
旧 self-read 混为同一实验。我对“真实经历值得进入编译”的判断为中等信心；对下面具体网络和训练组织能
超过强 MT 为中低信心。核心不足仍是跨任务学会有用修订，尚未被某个新模块解决。

与第四轮建议相比，我暂不把独立效果逆模型、显式操作程序、强功能教师或多轮参数递推设为首版必要部件。

若新专家给出可核实的学习理由，应该重新比较，不能把“简单”本身当作充分依据。

## 3. 三个不能靠模块名称消除的学习问题

**后果证据不自带正确性。** 设环境真实状态为 s、执行动作为 a、下一状态为 s'，任务为 g。
在状态已包含相关物理因素、任务不改变动力学的条件下，

\[
p(s'\mid s,a,g)=p(s'\mid s,a).
\]

准确解释 s→s' 可以学习动力学或接触模式，但没有单独给出“为 g 应怎样做”。预测自己会卡住也可以完全准确。
真实经历之所以可能有用，是它与教学过程一起显示当前控制的实际覆盖、失配和不确定性；正确修订仍须由
跨任务的功能监督学会。部分可观测或动力学未知时，经历还有状态辨识价值；不能把上述有条件等式泛化成经历无信息。

**增加输入不等于增加必须学习的关系。** 原有风险是
\(\mathbb E\mathcal L_{FM}(\pi_{W+G_\phi(V,L)};Q)\)，接入经历后只是把 G 改为 G(V,L,E)。
如果在有限训练任务上，语言/视频已经足以拟合相同成功 query，忽略 E 仍可能取得同样风险。
非零梯度、注意力对齐或换经历后参数变化，都不能证明有益使用。
反过来，也不能由 exact language 原则上说明任务，就认定视频或经历在有限样本学习中没有价值。
需要的是未见初态和未参与共享训练任务上的控制增量，不能删弱语言或制造无关损坏来强迫增量出现。

**失败作为输入不等于失败访态获得正确监督。** 成功示范 FM 在 query 状态上教正确动作；它不会因为 Writer
读到一次失败，就突然覆盖那个失败状态的恢复动作。它可以训练条件修订，但“跨初态完整恢复已学成”超出这项证据。
后继若需要真实结果信用，必须让 non-held 编译后策略的实际结果训练共享编译规则，并承担已有共享 RL 的信用和成本问题。
不能把旧0更新基线分析当作已经改善控制，也不能退回 held 新 condition 的轨迹微调。

## 4. 可供交叉验证的完整计算候选

### 4.1 两类输入及实际特征

教学为 V={I_t^1,I_t^2} 与 exact language L，stride=5。读取冻结 source 的真实图文 prefix 特征
\(Z_t=P_{frozen}(I_t^1,I_t^2,L)\)，保留相机与空间位置；不为使用 action backbone 构造假的 teacher state 或动作 query。
prefix-only 读取在新实现中仍须由实际接口验证，不能把旧固定 probe forward 改名当成已经实现。

每帧可学习空间槽从 Z_t 读取内容，再用带真实时间信息的时序网络联合编码。具体可写为

\[
S_t=\operatorname{Attn}(Q_s,Z_tW_K,Z_tW_V),\qquad
P=\operatorname{Temporal}_\phi([S_t,S_{t+1},S_{t+1}-S_t,e_t]_{t}).
\]

前后内容与变化同时保留，避免把“需要保持但当前没变化”的状态删掉。空间槽、时序深度和宽度需要吞吐与完整功能依据，
不能把 attention 槽预称为物体、动作阶段或物理坐标。此处没有逐帧动作恢复器，也没有将估计轨迹用作最终策略标签。
首个候选用 K=1；若最终选择 few-shot，须逐视频保序编码后集合聚合，不能先生成多个 LoRA 再合并。

固定强 MT 在独立适应初态上真实执行，记录

\[
E=\{(o_i,p_i,a^{exec}_{i:i+4},o_{i+5},p_{i+5},b_i)\}_i.
\]

其中动作只包含真正执行的前5步；b_i 可包含 Owner 已开放、实际采得的自身 reward/success/contact 等结果反馈，
须区分真实环境证据与预测。教师配套动作/state 依旧不可读。这里只选择首版所用证据，不收回其它合法自身信息的许可。
把前后 RGB 特征、proprio、动作序列和结果编码为自身转移 token x_i；序列保留 episode/reset 边界。
从实际 MT rollout 留下的 native hidden 可作为额外行为特征，但不是免费、正确的动作教师，也不是首版必须新算的分支。

### 4.2 对应是编译证据，不是外部执行程序

自身转移查询完整有序教学：

\[
c_i=\sum_j\operatorname{softmax}_j(q(x_i)^\top k(P_j)/\sqrt d)\,v(P_j),
\qquad m_i=F_\phi(x_i,c_i,x_i\odot c_i).
\]

x_i 与 c_i 先映射到相同维度；乘积只是可学习的交互特征，不宣称它就是物理误差。
这里希望学习的是“在这种自身行为与后果下，教学中的哪些操作内容对参数修订有用”。
没有逐帧同一初态假设；没有把注意力峰强行解释为正确阶段；也没有在最终 rollout 保留这个对应器。

每个 target ℓ、rank 槽 k 的参数查询 u_ℓk 联合读取 P 和 {m_i}。参数槽之间交换信息，随后由按 target 维度匹配的
非线性输出头生成一行 A 和一列 B：

\[
a_{\ell k}=a^b_{\ell k}+f^A_{\ell,\phi}(u_{\ell k}),\quad
b_{\ell k}=b^b_{\ell k}+f^B_{\ell,\phi}(u_{\ell k}),\quad
\Delta W_\ell=s_\ell\sum_k b_{\ell k}a_{\ell k}^{\top}.
\]

38 targets 沿现有接口：18组 Q、18组 V，以及 action_in/action_out；各头必须匹配真实矩阵维度。
首版 rank128 可直接承接强 MT 的已知函数，但不是永久 rank 约束，也不由此开启 rank 扫描。
共享 Writer fresh，输出末层零初始化使起点等于固定 MT 因子。MT 常量与生成修订在 rollout 前合为一套 A/B，
source/prefix 冻结，最终没有第二 adapter、视频读取器或外部过程控制器。

该头撤下“条件 A 修订只能位于 teacher X 行空间”的特定约束；不保证无限容量。
若头仍经低维线性瓶颈，它仍有自己的范围限制；完整 P/Q 的历史也禁止把“更自由”当作主要成功机制。
同样，\((B_b+\Delta B)(A_b+\Delta A)\)包含两项一次交叉项及\(\Delta B\Delta A\)，
不是独立功能的无干扰相加。保持须看完整控制。

### 4.3 最终执行中的实际作用

在每个 projection，当前自身输入产生 h_ℓ，执行

\[
y_\ell=W_\ell h_\ell+s_\ell\sum_k b_{\ell k}(a_{\ell k}^{\top}h_\ell).
\]

a 的作用是选择实际自身 hidden 上的方向，b 将这一标量改变为该层输出修订；其它层、attention 与 FM 去噪共同把它变为动作。
固定参数仍产生状态相关行为，不能因为参数槽从整段教学生成，就认为部署在按教学时钟播放轨迹。
反过来，最终观测若不能分辨两种需要不同动作的历史，固定 LoRA 本身不能凭空增加输入记忆。
这也是复杂阶段程序不能直接宣称可被压缩的边界。

## 5. 训练怎样教会这条联系

### 5.1 一个训练事件

从现有合法 non-held allowlist 抽 task g、action-hidden 教学 V 和独立 MT 试做 E；另抽同 task、不同成功 episode 的 query Q。
现有 MT 试做记录只有在来源、行为版本、允许信息及独立性满足本事件时才可复用；不能用历史零交互评测行冒充已登记的新适应数据。
固定 MT 的经验分布不随 Writer 改变，可在共享训练中复用；更换成当前生成策略试做将引入数据刷新和分布变化，不能无成本继承。

共享参数 φ 生成 λ=G_φ(V,L,E)，使用真实 π0.5+λ 的 FM：

\[
a_\tau=(1-\tau)a^Q+\tau\epsilon,\quad
\mathcal L_{FM}=\mathbb E\Vert v_{W+\lambda}(o^Q,p^Q,L,a_\tau,\tau)-(\epsilon-a^Q)\Vert^2.
\]

沿实际消费者使用既有维度/padding mask与归一化。query 动作只作共享训练标签，不进 Writer 条件；
E 中的动作说明 MT 实际做过什么，不能因为它出现在输入里，就把失败动作当正确 BC 标签。
梯度通过实际生成 LoRA 返回参数头、对应器和教学/经历编码；环境和已采集 E 不可微、stop-gradient，source 冻结。
这学习给定经历后的编译，**没有训练最优探索策略**。

### 5.2 信用具体落在哪些特征上

令\(\delta_\ell=\partial\mathcal L/\partial y_\ell\)。对一列/行因子（已吸收向量方向约定）：

\[
\frac{\partial\mathcal L}{\partial a_{\ell k}}
=s_\ell(b_{\ell k}^{\top}\delta_\ell)h_\ell,\qquad
\frac{\partial\mathcal L}{\partial b_{\ell k}}
=s_\ell(a_{\ell k}^{\top}h_\ell)\delta_\ell.
\]

因此 u_ℓk 收到两头 Jacobian 对上述信用的回传。教学/经历特征被训练为生成：在真实 query 的 h 上能起作用的 A 方向，
以及能降低该 query 动作误差的 B 输出方向。δ 已包含实际下游非线性和其它 target 的作用；完整梯度还须对所有 token、
层、query 与训练采样求和，不能把这两式当作完整闭环控制的局部充分条件。

这说明哪里存在真实学习信号，并不证明网络会辨识出对象角色、必要顺序或新任务的正确更新。
T/C 已有这类功能信用；新增可检验假说是，真实自身证据能让共享函数在新条件上形成更有用的参数，而不是“终于接上梯度”。

### 5.3 完整结果信用与边界

FM 先获得完整可执行学习；若证据支持继续，按现有默认合同在单个监督 checkpoint 后启动独立共享 RL，fresh RL optimizer，默认不混 FM。
其目标是 non-held 上\(J(\phi)=\mathbb E R(\pi_{W+G_\phi(V,L,E)})\)：E 是适应经历，R 来自编译后独立初态，
梯度最终训练共享 φ。实际 score/去噪路径与方差处理必须另写可执行合同，本文不把一个期望公式当作已实现的 RL 算法。
若专家建议联训 FM/RL，应明确比较现有分段合同、旧 RL 阴性和新学习事件，并登记改变；不能默认沿用第四轮的混合式子。

部署时共享 φ 冻结，只运行学成的生成过程。自身奖励可以作为 E 的反馈，但不在新 condition 上把轨迹拟合进 λ，
也不凭奖励“挑中一套”未被学习规则规定的参数。未来多轮版须用对应多轮训练事件承担信用与成本，不能自动升级。

## 6. 最小证据应当改变哪项判断

这不是逐模块 Gate。首批应尽快完成“教学＋真实经历→完整 LoRA→独立初态执行”的整个事件，
先在有限合法训练任务上确认确有学习和能力，再用训练内部留出任务判断能否迁移；不读取固定 Test。
训练内部开发读出只供首批方向判断，不替代正式 single-checkpoint paired400 选择。
不能把对几条 trial 的记忆、局部函数变强和不同初态下的独立正例拼成完整资格。

最关键的竞争解释与对应比较是：

| 观察 | 支持/削弱什么 | 下一步取舍 |
| --- | --- | --- |
| 全方法在独立初态提高，并能在未参与共享训练的任务迁移 | 共享编译有实际学习，值得扩大完整评价 | 再确认相邻能力、强 MT 差额及教学贡献 |
| 只在训练任务或已见经历改善 | 记忆/支持不足仍更有解释力 | 不因训练 loss 好看自动扩大正式矩阵 |
| 有经历与匹配训练的无经历编译器相近 | 真实经历没有承担提出的功能，或训练没有学会使用 | 降低“接入试做即可改进编译”的投入；不靠堆轮数保护它 |
| 只在删视频时变差，而正确教学不优于公平静态/语言参照 | 可能是分布破坏或依赖形式输入 | 不据此宣称教学知识有效 |
| 有完整视频增量，但绝对控制仍弱且新增集中少数任务 | 局部机制尚不能解释总体不足 | 按完整性能和覆盖决定是否继续，不无限补内部探针 |

首批重点保持全方法、强 MT 和一个匹配训练的无经历编译器；视频贡献选择与主张对应的少量公平比较，
无需开工前把全部 controls 配齐。无经历比较须从训练阶段就匹配其输入，不能只在测试时删掉 E；
static/language 比较同样不能靠破坏强参照制造优势。正式选点仍用登记的 qualification 与 paired400；
shuffled/reversed 只在选点冻结后按旧规则使用。

即使最终暂不超过同预算充分语言适应，第一阶段超过强 MT 的成绩仍按 Owner 要求诚实评价；
但没有视频条件增量，不能把任务内学习或共有能力的提升写成 EMBER 机制已经成立。

## 7. 规模和时间不能靠“只试一次”略去

固定 MT 的一条训练 trial 可以供多个合法教学配对复用，但这不增加独立 meta-task 数。
首批应继承唯一冻结的合法任务 allowlist/权重，不将更大任务池同时悄悄作为第二主要干预。
“完整新编译器＋新增任务规模”的收益若不隔离，就不能归因真实经历；大规模覆盖可在后续依据缺口选择。

validation8 的 K=1 正式一轮有400个不同 task-video conditions。若每 condition 一次独立、最长 suite horizon 的试做，
按每 suite 两 task、每 task50个 condition，适应最多
\(100(220+280+300+520)=132000\)环境动作步，另计 settling；最终 paired400 还有一整轮执行。
同样的适应不得按“只8次任务级试做”估算。不同视频 control 是否共享同一合法固定 MT 试做，须在配对合同中明确，
如有复用须如实计成本，不得跨 condition 合并 LoRA 或读最终评测反馈。

首批 wall-clock 由真实 trial 采集、编译/FM吞吐、正式读出三项估算：
\(T\approx N_E/\rho_E+N_U/\rho_U+N_R/\rho_R\)，其中ρ是所用拓扑下实测的整批有效吞吐，再计排队/资源瓶颈。
旧 self-read450 总计约17.09GPUh只能说明旧图成本量级，不能当新网络的工时承诺。
当前没有新实现的吞吐证据；因此不编造精确小时数，也不登记“先跑再补预算”。最终方案首批合同必须在启动前
给出基于实际消费者的 wall-clock 预期、硬预算与失败分支，由实验 session负责资源与工程闭环。

## 8. 与专家交叉验证时的裁决问题

1. 新 condition 的参数到底由什么计算获得？只要仍是准备动作后拟合最终策略，直接越界；不讨论换名称能否保留。
2. 视频的具体内容怎样进入自身控制函数，而不是只识别任务？中间表示的语义假设、标签和真实消费者分别是什么？
3. 自身经验改变哪项推断？训练为什么可能学会这种改变，什么结果会显示它被忽略或只是重复已有信息？
4. 最近似历史方案的特征、算子、标签、梯度和部署有何实际区别？未实施组合不能记成失败，已有阴性也不能因改名清零。
5. 参数固定后，每一步自身输入如何调用所需功能？外部过程、特权状态或额外记忆能否真的退出？
6. 第一个有界完整实验区分什么，正式400个 condition 的独立成本是多少？哪种结果应改变主假设而非继续堆模块？

最终取舍应以这些机制与证据为依据；不是将两份意见拼成更大的系统，也不是以“专家也这样说”代替验证。
收到答复后保留一致点、真正分歧与可判别预测，再收敛唯一推进方案。

## 9. 外部依据的适用范围

[Watch, Try, Learn §3](https://arxiv.org/html/1906.03352#S3)展示固定首策略采集试做，再学习读取示范、试做及奖励的后续策略；
其独立正确示范监督与固定采集分布有启发。它不是新任务轨迹拟合，但最终仍为上下文条件策略，不能证明单固定 LoRA 编译已解决。

[Doc-to-LoRA §3](https://arxiv.org/html/2602.15902#S3)用共享 hypernetwork 将上下文变成 LoRA，并以已有上下文功能监督参数化学生。
可借鉴的是跨条件学习参数生成，而非部署时准备问答再微调。其底座已有可用上下文功能，训练有约320万独立上下文；
这些条件与 EMBER 的动作隐藏视频、有限任务池和未建立强视频控制教师不同。论文支持可行原理，不提供本项目的成功保证。
