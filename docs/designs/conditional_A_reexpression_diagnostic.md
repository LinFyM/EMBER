## 2. 为什么尚不选择刚提出的额外图文Value支路

对原T的单个target，省略condition下标。实际地址、覆盖与输出是

```
k_t = normalize(A X_t),              R_t = I - K_t K_t^T / 50,
M_T = sum_t (V_t K_t^T / 50) R_(t+1) ... R_(T-1),
M_T A h = sum_t V_t omega_t(h),
omega_t(h) = K_t^T R_(t+1) ... R_(T-1) A h / 50.
```

X/H来自合法RGB/L在共同学习公共LoRA下的原生读取；h来自机器人自身输入及完整LoRA的执行。
V_t由H的内容与相邻变化学习产生，既不是观察动作，也不是已识别的物理阶段。
这个分解把两件事分开：V决定写入方向，omega决定该方向在自身hidden上怎样被调用。
它是固定层输入下的精确等式；不同LoRA还会改变后续hidden和十步flow，不能直接当作整条policy的线性式。

若公共参数和读取X/H固定，只给V接入额外原生图文特征Z及其变化，则

```
delta(M_T A h) = sum_t delta V_t(Z,H) omega_t(h).
```

它确实增加内容依赖，却不改变这个子图的调用核。若两个自身状态的A h相同而需要不同线性作用，
此处无论V如何读取Z都不能区分它们；若教学变化根本不区分两种所需控制，更多确定性读出也不会自动补出信息。
整个非线性policy可能经其它层区分这些状态，所以这不是全方法不可能定理。

即便采用同一个query读取相邻两帧的视觉patch，令r=sum_j p_j v_j、p=softmax(q^T k_j)，
固定q时的一阶变化仍为

```
delta r = sum_j p_j delta v_j + sum_j p_j (v_j-r) q^T delta k_j.
```

式中包含内容和匹配改变，也会响应视角、光照、背景及机器人运动；它不自动等于物体位移或逆动力学。
真实动作FM可以学习筛选它们，但“另有图文路径”本身没有证明筛选更可学或可迁移。
SemanticPath、LocalField、同视频教学等旧完整方法已经有图文/变化/真实消费者；Context又已有全视频H上下文。
因此仅把这些信息接到T上，不足以说明为什么旧负预测会改变。**额外图文Value目前仍未选定，不派发其实现/训练。**

## 3. 条件A究竟新增了什么

当前每个target实际为A=A0+S、B=B0+M(A)，输出W=B A。S既改变执行读取，又改变M的key、覆盖和显式S X输入。
若只把当前S关掉，M也须重新编译；不能把这个动作解释为只删除一项B S。

对固定native X/c/d、在S=0附近，记M0=M(A0)，有

```
W(S) - W(0) = (B0+M0) S + J_M[S] A0 + O(||S||^2).
```

第一项直接改变输入读取，第二项改变原A0上的写出。这两条路径都可能有益，不能由更多自由度直接推出更好学习。
令P0=A0^+ A0是原输入行空间投影，则对任意固定的实际B，精确有

```
B(A0+S)(I-P0) = B S(I-P0).
```

所以S在原行空间之外才可能提供原A0未读取的线性方向。但因子在外部的能量，不等于这些方向承载了新的有用信息；
真实输入可能高度相关。旧§94已经测过外部能量及S的非零作用，本轮不把它们重新当作新发现。
action_in的A0是128×32，若列满秩，其输入空间本来已覆盖32维，不能对所有38处套用“新增方向”解释。

## 4. 在真实输入分布上，怎样检验这种新增是否必要

把一条教学的实际native输入排成X[d,n]，Z0=A0 X。对当前已生成S/B，求一个只用于分析的线性系数

```
C = S X Z0^+,
B_tilde = B (I+C),                  A_tilde = A0,
E = B(A0+S) - B_tilde A0 = B(S-C A0).
```

在教学输入上，C最小化||S X-C Z0||_F；由于随后左乘同一固定B，所得投影同时最小化对应B S X的拟合残差。
精确残差为E X=B S X(I-Z0^+ Z0)。保留I项而不是只求总B的最小范数解，可保留原B在未被教学Z0激发方向上的作用。
这里只使用既有合法native输入和已生成因子；没有动作/奖励进入C，也没有迭代优化。
这是一份条件内的解析重表达，不是已经学会的跨视频编译器，不能从可拟合跳到可学习。

更关键的是执行分布。以Sigma_T=XX^T/n记教学二阶矩，
epsilon_T^2=tr(E Sigma_T E^T)为平均局部输出误差。对处于其支撑内的自身hidden h，

```
||E h||^2 <= epsilon_T^2 * h^T Sigma_T^+ h.
```

若h有支撑外分量，必须另保留E h_perp。即使形式上满秩，小特征值方向也能使右侧很大。
这个不等式说明：很小的teacher误差并不保证真实state、随机动作latent和各flow time上的小误差。
新增图文Value也没有自动修复这项调用条件。下一项证据必须接到真实执行消费者，不能只继续报因子norm或重构百分比。

跨层、attention和十步积分还会放大或抵消局部改变；不能用上述局部界直接保证最终动作，更不能保证闭环成功。
因此下面同时读取真实执行query、生成动作和小型配对闭环；这些是同一个重表达干预的消费者，不是另开新方法矩阵。
