# 操作语义与实际参数作用：推导和数据实施

Owner 2026-09-13明确要求仔细推导、实施并按结果调整。本文不恢复任何旧训练。
§4的CPU标签实施已完成关闭；完整Writer结构仍待下述可识别性检查收敛，本文不是训练启动合同。

## 1. 从已有结果可以推出什么

双相机的冻结source局部动作知识存在，却没有经当前共享Writer获得稳定迁移；旧辅助FM、蒸馏、
Meta校准和native地址已经失败。相对几何检索也未优于同信息的绝对几何。
因此不再把下一投入建立在更准局部动作头、坐标中心化或给A/B重新命名上。

仍未检验的监督关系是：把**视频中实际发生的对象／部件变化**，与**生成参数在执行现场的真实作用**直接联系。
已有主FM提供最终动作信用，但没有给过程表示或某个实际参数作用指定可跨任务共享的操作语义。
这只是有区别的研究假设，不是现有失败的唯一根因。

## 2. 拟议机制及必须避免的伪证明

对某个执行线性层，LoRA更新为 `Δy = Σr b_r (a_rᵀh)`。h依赖机器人的当前观测，
因而参数不变也能产生状态依赖。新监督若采用，必须约束这里实际参与执行的 `a_rᵀh`，
而不是额外训练一个与A/B无关的分类头。B保持自由，不重新限制在旧native Y span。

例如少量rank可以被赋予接触适用性；视频读取端学习对象／部件、接触观测和过去区间内的变化，
编译端由这些证据生成完整38-target A/B，执行端用训练query自身几何标签监督实际A响应。
动作主FM仍负责这些响应是否被B转为有益动作，部署没有标签、state教师、第二adapter或在线读取。
操作语义应成为进入编译器的必要内容，不能保留未说明的静态任务旁路，再把辅助loss下降称为视频收益。

这尚有三个实质风险，不能用公式掩盖：

- action-in的输入是带噪动作，不能给所有38层的A强加当前物体条件。须先选有合法执行观测内容的具体层／token，
  并登记有限的语义rank与其余容量；不能按闭环分数搜索层位。
- 接触不是抓稳、支撑或必要前置条件；位移不是意图或成功。只监督能由数据核实的物理事实。
- 同task固定语义仍可充当任务索引；逐时刻变化排除常数拟合，但不排除时间模板和跨任务记忆。
  未来训练比较必须具有预登记的non-held内部task留出及匹配信息参照，不能仅依赖训练内拟合。

### 2.1 实际A监督也存在明确反例

即使 `sigmoid(a_rᵀh)` 完全预测接触，取 `b_r=0` 时该rank对行为严格没有贡献；
其余rank仍可独自承担原FM。更一般地，两个rank可以输出相反更新而抵消，语义准确仍不等于有益更新。
因此“监督实际A”比无关辅助头多了一条结构联系，却没有自动建立有益传递。
不能在标签恢复成功后直接追加这项BCE并以其下降作为完整机制通过。

另一个反例是冻结source的h已经含task language：同一个共享A可能对所有task预测接触，
从而语义loss不需要教学视频。逐时刻变化可以排除task常数标签，但不能排除这个共享读取解。
本候选要成立，必须说明由**这条视频的对象变化**决定的可迁移更新是什么，并用真实LoRA行为比较检验；
既不能强行破坏无视频参照以造增量，也不能把反例解读为视频方法普遍不可能。

## 3. 后续裁决的逻辑

本次实现首先排除“现有状态可以直接当作可靠通用语义标签”的未经检验假设。
数据可用只解除数据阻碍，不是启动完整Writer的充分正证据。若数据支持，下一步须完成：
具体RGB绑定出口、实际A响应所在接口、语义容量与动作信用兼容性，以及有界闭环比较；
若这些仍退化为辅助头或同task索引，则停止该提案。不会在两种结果之后都默认再换读取器。

独立frame_set持续资格仍待Owner明确。本次不变更该口径，也不使用最终shuffle/reverse controls。
有益视频增量、跨视频／初态／相邻保持及validation迁移仍是整体目标。

## 4. 当前登记的实施：训练侧物理标签可行性

- 固定train24；每task既有action训练池demo16–19与动作诊断池42–45，共192episode。
  两池分别报告，不在诊断池产生梯度；不读validation/test、reward、terminal或动作数值。
- 只读存储state和官方BDDL对象关注列表、XML几何；CPU `mj_forward`，无仿真推进、渲染、GPU或模型训练。
- stride5。恢复obs[i]对应的下一存储state，并按已验证的2ms运动学缓存合同回退一个积分子步。
  保留全部合法帧i+1<N；变化只用已观察的相邻stride5帧，不读取未来作为视频当前特征。
- 每个对象保留其各body和site，不把抽屉／门平均成根部平移。site-only区域通过其owning body登记接触范围，
  明确它不是“落在该区域内”的谓词；world body不泛化为整个世界。
- Panda左右指collision geom采用本地官方命名；只将MuJoCo contact中dist<=0的几何相交记为contact。
  分别记录左指／右指／双指同对象接触。无接触力、稳定抓持或支撑推断。
- 保存对象部件position、rotation与相邻帧平移／相对旋转量，接触及对象schema、帧索引和完成记录。
  只检查shape、finite、时间对应、对象映射及接触覆盖，不新增hash或精度追查。
- 报告各task／suite／episode池接触正负数、发生转换的episode数、部件变化分布及site-only映射。
  不从结果选择对象、阈值、方向、task或episode，不以覆盖数阈值声称机制通过。
- 新增空间预算512MiB（含约217MiB短期frozen worktree）；执行前已查/data1独立quota约991.9GiB/1TiB，
  实际analysis约37GiB、workspace临时约13GiB，共享容量充足。复用资产，无复制数据或模型。
- 一次性入口由clean pushed commit冻结；结束后将源保留在Git、原件留在runs/analysis，退役活动入口。

这些是正确的几何所属关系，却没有区域内／上方／支撑的谓词语义，不能直接作为该区域的操作适用性标签。
映射未静默修改，全部原schema保留。

**按结果调整：**保留左右指接触与各部件变化作为物理观测，撤去“通用接触阶段→语义rank”的直接实施依据。
不能把OOI平均、region所属body或双指proxy包装成通用操作规则，也不根据本表挑task或调contact阈值。
当前数据实现关闭，无active Writer design；下一设计仍须解决§2.1的零B／共享A反例，明确可执行效果的传递关系。
这一步完成了真实标签实现并排除了过强语义解释，尚未获得RGB理解、唯一LoRA收益或跨任务泛化的新正证据。

## 6. 从语义读出转向实际物理后果：当前有界诊断

本节在结果产生前登记；§4标签恢复保持已关闭。当前只激活以下CPU动作干预，不启动Writer或RL。

### 6.1 为什么这与最近历史有区别

旧phase decoder模仿expert/source去噪动作差，privileged effect和functional sketch约束隐藏响应、动作或参数几何；
它们没有直接监督对象／部件的局部物理变化。不能把本提案说成首次使用真实物理后果：
旧OCPB v18（026e756）和MDCO（419fa84）已用最终±LoRA在模拟器里的success／BDDL progress／效率给scalar credit，
MDCO最终20/250对source21、shared43，Goal/Long0。原件为`7aa0bed:docs/research_history.md`§3.59–75，
phase／effect区别见同快照§3.26–29、3.50–52及`ecp_fixed_effect_realizer_card_20260824.md`。

拟议新增的是对象身份明确的dense效果：同一个执行前状态s，最终动作a造成的部件变化F_s(a)，
与合法expert动作a*在同一当前模拟器中的F_s(a*)比较。损失若真正经过动作，则不能由B=0的独立语义头掩盖；
但source自身满足目标或同task记忆仍是可能解，视频收益仍须由闭环及合法controls裁决。
物理指标也可能不充分：抓取前的动作短期不移动物体，完全由它训练会失去接近行为，所以不能取代主FM。

文献给出了经物理算子反传状态误差的学习范例（[ILD](https://arxiv.org/abs/2206.04873)）；
[PhysReal2Sim](https://data.ciirc.cvut.cz/public/projects/2022Real2SimPhysics/)依赖重建和近似物理，
[ORION](https://link.springer.com/article/10.1007/s10514-026-10253-8)在执行时匹配图并优化动作。
这些工作支持研究动作后果这个接口，不能证明当前LIBERO梯度质量，也不能替代EMBER的一次完整LoRA出口；
本项不安装它们的模型、改用其执行器或恢复在线规划。

### 6.2 可实现的范围及决定性限制

现有Panda `format_action`对夹爪命令使用sign；小的连续扰动几乎处处不改变开合，不能依赖普通局部导数学习这部分。
因此只检验六个连续运动通道的局部效果近似，同时独立报告两种离散夹爪命令的真实变化，保留主FM。
不训练世界模型，不用其预测误差冒充因果证据；所有分支从同一个存储状态、控制器和夹爪命令历史开始真实短段执行。

一次探索smoke已用task0/demo16的20/40/60位置重放各5动作，CPU入口可运行；EEF差约.45–1.19mm，
不宣称精确复现旧采集轨迹。接下来的F_s以**当前模拟器的基准重放**为参照，原始存储终态只作偏差报告。
夹爪隐藏command由过去真实动作通过原format_action恢复；每个分支清空MuJoCo未存储的warmstart，
恢复同一qpos/qvel与控制器，防止前一分支的状态影响后一分支。

### 6.3 固定样本、干预和评分

- 仅固定train24、action训练池demo16–19。每episode取可执行完整5动作的前1/4、1/2、3/4位置，向下取stride5；
  共288个初始条件，不按接触、动作或结果选位置。不用42–45、validation或test；无梯度、选checkpoint或完整闭环。
- 从obs[p]之后的states[p+1]恢复，执行actions[p+1:p+6]；当前环境OSC_POSE／20Hz、原XML及canonical assets。
  没有渲染、GPU或dummy settling；这是存储中途状态的短段动作干预，不能冒充official episode评测。
- 每条件17分支：真实动作基准；六个运动通道各±ε；另一个固定组合方向的±ε；全段夹爪分别固定−1／+1。
  ε固定.1原环境动作单位，运动扰动对段内5动作同样施加，再clip至原控制范围。
  组合方向固定`[1,-1,1,-1,1,-1]/sqrt(6)`，不参与拟合，不改方向或幅度挽救结果。
- 保留§4同一官方OOI各body/site；每对象内点等权、对象间等权。终态相对基准的position差除.05m，
  rotation取`Log(R_base^T R_variant)`除.5rad；两种单位来自原OSC控制缩放，保持两类各三维。
  site表示该点的物理变化，不升级为区域／支撑语义。没有force、success／reward或terminal作为评分。
- 用12个轴向分支中心差分形成J，预测两个未拟合组合分支的效果。比较`Jδ`预测与零变化预测的效果MSE，
  每episode三个位置等权、每task四episode等权、24task等权。所有零响应位置保留，同时报告响应能量，避免把零预测称为理解。
- 预登记局部近似可用前提：预测MSE／零变化MSE严格<.25（对应总RMS误差比<.5），
  零变化−预测的20,000次task-cluster bootstrap95%CI下界>0，至少两个suite有正差额。
  bootstrap seed20260917。三个条件同时成立才支持有限的连续动作局部效果度量；不能据此称其为完整物理教师。
- 无论结果如何，夹爪两分支只报告真实效果量及差异，不事后加入J、选择连续近似或调sign阈值。
  另外报告基准与存储终态的部件位置／旋转偏差，限定当前模拟器与原轨迹的对应范围。
- 预计24,480高层动作步，最多512MiB新增空间（含frozen tree），单CPU进程、一次有界执行。
  已live复核/data1独立quota约991.9GiB/1TiB和共享容量；复用现有资产，无下载或数据复制。

### 6.4 结果将怎样改变投入

若局部近似前提不通过，停止用这个J替代物理后果来加权FM的提案，不扫描ε、方向、样本或轨迹长度，
也不以“物理模型更复杂”默认投入可微模拟器或新世界模型。
若通过，可据真实响应能量和离散夹爪限制登记有界的主FM＋局部效果学习比较；仍需说明视频信息路径、
误差范围和query采样，不能把本项当作RGB获取、LoRA编译或validation迁移已通过。
完整方法仍只由配对single checkpoints的行为证据选择，当前没有新的训练启动合同。
