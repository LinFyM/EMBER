固定train24/validation8/test8、source、官方执行、stride5、action-hidden部署输入和单套完整LoRA合同保留。初轮梯度仅来自train24，teacher与query跨episode；不用held梯度、Test或最终视频controls。若后续确需其它non-held任务，先完成现有排除审计并单独登记，不扩大本轮数据作为默认补救。每次launch满足双节点live GPU、独立quota、峰值预算和真实吞吐约束。

## 纠正此前证据的用途

676条冻结/局部诊断、监督审计和原生动作结果均是保留的实测事实，但不构成根因分析完成。

- 冻结语言置零的54/52/40对normal51只能说明当前依赖，不能排除从头删除某些路径有益，不能据此宣布语言不是主要原因。
- free-C在task7局部有效只证明当前decoder的局部可达性，不证明正常Writer能学到该表示，不能排除架构可学习性是主因。
- 固定FM噪声的局部A/B求解拟合强、泛化弱，是该oracle的边界；不能移植成正式训练的噪声bug或纯FM失效证据。
- 两个Long回放定位了两个实例的后续执行失败，不解释全部新旧架构分差。
- v5.2/v6同类纯FM更强是必须解释的反证。完整配方不同，不能只按架构名字或峰值认定因果；旧最终controls不用于新设计选择。

## 需要回答的三个问题

1. **学习路径：** 当前语言/上下文条件和多阶段过程读取，是否让有效视频到策略修正更难学出来？区分额外纯语言、包含视觉信息的contextual task tokens、以及原生必需exact language。不能把三者统称语言码后一并删除再声称定位。
2. **参数共享：** 独立native因子映射是否造成当前能力获取、跨任务迁移或保持劣化？历史Target-Owned的负结果必须作为不同前端/配方下的反证，不能据此跳过当前受控比较，也不能把rank共享当新发明或默认修复。
3. **训练交互：** 在架构保持时，旧新数据采样/条件曝光/优化或目标差异能解释多少能力差距？同类FM曾更强，不能先宣布改loss/RL；也不能把架构作用与训练作用假定为互斥。

### 2. 区分过程获取与参数生成/共享

复用阶段1共同normal，单独改变输出共享，或单独改变过程读取中一个有明确旧强参照的接口；不同时换前端、头部和loss。具体过程对照先从源码写出信息和计算差异，不采用“去掉整套过程”后再猜是哪个模块。完整H、真实图文前缀、有序视频及原生动作响应仍作为共同证据，避免把输入削弱和学习路径改变混在一起。

### 3. 定位剩余的训练因素，并验证解决方案

先利用共同学习协议下的新旧架构结果：若差距主要随结构改变而改变，优先验证结构原因；若旧强架构在当前协议也显著变弱，追加同架构配方对照，并逐项分离条件/episode采样与optimizer聚合等因素。旧协议只移植满足当前数据墙的部分，不能用非法旧数据口径制造强参照。

若上述仍不足以解释学习/保持缺口，再选择有行为依据的一项目标或状态覆盖干预，保持架构固定进行探索训练；不是默认转RL或同时改loss与架构。局部动作MSE与恢复失败只为选择实验提供依据，不能提前给新目标背书。

对有明确收益的候选，固定方案后用独立教师/状态和必要的独立随机实现复核，检查新增成功是否伴随大规模能力丢失。相邻稳定与各suite表现共同判断，不挑一个峰值。有限实验不能证明唯一终极原因，但每项保留解释必须有区分证据，而非仅“与现象相容”。

## 共同证据合同

- 每项实验结果前登记支持/反对该解释各会出现什么结果，并登记若无信息量将改变哪项识别条件。运行数量、loss下降或有梯度不作为完成依据。
- 复用已有基线仅限实际架构、数据/条件序列、累计曝光和学习协议一致；不强行配对历史不同配方。新臂训练正常重采样FM time/noise，跨臂语义事件/RNG配对，不把噪声固定成局部oracle。
- fresh路径对照以已观察到获取及后续保持变化的累计曝光为依据。当前参考200/400对应51,200/102,400 queries、800/1,600 teacher条件；实际节点在launch前锁定。短smoke或早期负结果不能声称排除学习假设；也不因一臂弱就无限延长或扫LR/seed。
- 训练侧同时报告熟悉任务的独立episode动作指标、完整train24配对闭环、不同teacher鲁棒性；区分未见视频与未见任务。不因某个4状态task局部净增宣布整体修复。
- 关于未见任务迁移的结论必须来自预登记的validation8 strict paired400，single checkpoint、正确视频、相邻节点；80-row或train32/96不替代。这里是探索证据，不宣布正式资格，也不使用Test或最终视频因果controls。
- 报告每task/suite、breadth、retained/gained/lost、churn及相邻成功集合。对提升和下降均定位实际行为差异；仅在它能区分解释时补轨迹或局部probe。
- 有实质效应再做针对性复核，不常规展开多seed/多LR搜索。效应小或跨节点不一致时保持未识别，并选择能分开解释的下一项；不能强行给出“架构没问题”或“训练主因”。
