# 教学与真实实践如何形成跨初态的参数方向

2026-10-17，主讨论科学议案。

状态：Owner进一步指出“A可辨状态/预测后果，不代表B会正确操作”，要求推通教学到B及全失败实践的实际控制信用，先不开实验。当前首节据此补齐一个明确消费者：共享训练直接监督当前状态下的目标后果分布，任务内以当前完整LoRA实际造成的后果误差修订B。A的事实校准保留，但不再把“B重编译后交给FM”称为已经解决目标控制联系。本文是尚未验证的完整机制议案，不是active design/launch合同；旧d_e事件因果用途仍撤回。

## 当前完整方案：教学目标后果、实际执行响应与完整参数修订

### 1. 先明确选择及其最接近的反证

当前选择不是继续训练一个标量E给既有方向打分，而是学习最终参数本身怎样区分状态。对每个原生target，实际LoRA作用为

`Delta W_l h_l(s) = B_l A_l h_l(s) = sum_k b_lk [a_lk^T h_l(s)]`。

A的行决定在什么自身执行hidden上激活，B的列决定该激活怎样改变原生计算；B列是hidden/flow算子的方向，不直接等同末端位移。最终参数固定不代表输出固定：新初态的RGB/state使h改变，A h随之改变，同一B就可以产生不同修正。方法要教会的是这个实际状态条件函数，而不只是“这条实践走得更接近教学”。

这一想法有非常接近的历史。10月4日[role-coordinate](../designs/role_coordinate_credit_diagnostic.md)已经监督最终action_out的A h，保留经自身h到前37处的梯度，更新全部A/B生成头，并随A重算B。G的坐标误差下降，仍19/32低于普通F的21/32；task16原/换位两布局分别都为0/8、3/8，F/G成功集合相同。后续分解显示自身full50几何误差改善只有15.2%来自query之间的中心化差异，26.3%来自均值偏差、58.6%来自同query的tau/slot波动。故“直接监督A”“B随A重算”“有物理含义”均不是本次独有贡献，也没有已有成功保证。

上一版只具体化了A的学习，教学到B仍由自由读写头加FM/终点回报承担；Owner指出的缺口成立。当前保留A的实际响应校准，把B的主要任务内更新改为**教学所指定的目标后果与当前真实后果之间的误差**。目标后果模型有独立的成功继续标签，实际响应有自身动作后果标签，两者在同一物理量上相接。完整FM/回报继续约束跨初态能力，但不再独自承担教学到B的操作对应。以下同时说明其旧法等价边界、参考质量限制与不可识别情形，不承诺不会失败。

### 2. 教学怎样进入，不把程序预写进标签

Reader读取真实双RGB的stride5有序序列，保留实体外观、相对位置/旋转、关系变化、关节/可见夹爪线索及不确定性。训练侧用获准non-held的同步物理量监督这些事实；没有记录的接触、力或物体旋转不补造。teacher标签仅是训练target，不能作为Reader/Compiler条件。新condition只读合法视频，不读其动作、state、reward或任务ID。

这不是先把视频变成“抓—搬—放”程序。连续关系窗口及其顺序保留；哪组实体与变化对控制有用，由后述目标后果监督及完整控制学习约束。exact language仍进入执行policy；它可以用于教学实体/目标的关注，但不给参数生成器另接完整指令的task-key分支。实际经历中间接含语言信息不删除。这个结构只关掉一条直接捷径，不能保证视频动态内容已经被使用。

自身实践另有真实RGB、state、实际动作、物理后果及success。Reader的condition内校准状态包括匿名实体的外观原型/软对应，以及关系读出末层的小型仿射校准参数xi；以自身RGB的事实预测误差和共享先验约束更新xi，再重新读取教学，修正外观对应、几何读数和置信度。共享Reader权重不被held任务修改。所有实体采用同一匿名化/匹配规则，不从BDDL目标表指定正确对象或操作阶段；对应不能区分时保留分布。共享训练需经过同样的xi校准，不能假定自身视角的校准必然能迁移到教学帧。自身事实能校正“我看到了什么”，不能单独教会“应该做什么”。

多视频时每条独立保序编码，再在集合层聚合，不平均frames或最终LoRA；第一版可以只采用K=1。条件内校准形式、初始先验和集合模块都是本方案的共享训练对象，不能把尚未训练的模块当现成资产。

### 3. 真实实践给A的直接信号是什么

在真实自身状态s上，从当前完整LoRA的原生forward取h：有真实双RGB、8维state、原生prefix及完整flow条件，不以无state教师probe冒充执行状态。读取的`z={A_l h_l}`必须就是最终LoRA会实际消费的投影。辅助后果预测器只通过这些z取得状态信息，同时输入已实际执行的动作片段a和实际持续时间，预测当前物理事实及其实际变化：

`y_hat = f_psi(z(s), a)`，`L_fact = ||y_hat - y_actual||^2_mask`。

为防止外接大decoder能读出信息、实际线性B却无法利用，选用对状态投影线性的读出：`f_psi(z,a)=c_psi(a)+sum_l P_psi,l(a) zbar_l`。P可以对动作非线性，表达有限动作/接触响应；状态只由实际z进入。zbar只在同一当前观测的真实flow/动作槽内做固定汇聚，不跨物理时刻、不平均教学帧，不给未来槽伪造状态标签。由此z承载的是不同动作响应函数的系数，B也直接消费同一组投影；正确控制仍由功能学习对齐。这个限制改善消费者一致性，也限制后果模型容量，不能宣称足以拟合所有接触动力学。

y包括合法可取得的相对位置/旋转、关节和raw夹爪量及变化，有实际contact记录才包括contact。原始物理单位及尺度在non-held训练侧固定。f不能另读raw h、真实state或task ID来绕开z；真实state只作target。不同原生target的信息条件不同，action_in等仅见噪声/时间的输入不被强行要求读出物体状态。f汇聚有观测信息的实际投影，其余target仍接受完整功能学习；也不把50个动作槽当成50个已观察的未来物理状态。

仅预测位置或平均变化仍可能重演旧结果。因此训练和有信息量的实践采用**同一真实物理起点的不同实际动作后果**。保存起点、实际执行每个分支并计费，比较

`L_resp = ||[f(z_s,a_b)-f(z_s,a_c)] - [y(s,a_b)-y(s,a_c)]||^2_mask`。

这里预测的是有限动作片段的实际响应，不假定接触动力学局部线性。没有执行过的分支不给真标签。跨状态若使用同一对实际动作，可进一步比较响应的双重差；若基准动作不同，必须把真实动作条件保留，不能声称只隔离了状态效应。实际安排按预算/不确定性选择分支，不要求每个时刻全轴枚举。

共享训练对真实匹配动作的状态对也使用上述双重差误差，直接监督状态之间的响应差，不能只靠平均响应或同状态的tau/slot稳定性降低loss。这给出一个明确的可学习压力：若两个状态对同一对动作的响应差不同，而z相同，固定f就无法同时拟合它们；action-only预测也只能给相同差值。状态信息必须进入实际A h，或者保留为无法拟合的误差。例子是相同手部位移下，物体是否随动，以及当前物体相对容器的布置；这不自动推出该抓、该搬或该释放。task12旧expert/MT两条继续都已出现共同运动却一成一败，所以“随动已识别”不能被当作完整任务理解。

共享f以事实/响应损失训练，condition内固定其参数，防止所有误差只被辅助头吸收。A则进行任务内校准：

`A_plus = A - alpha * grad_A [L_fact + L_resp + prior(A,A_init)]`。

prior是共享训练学得/冻结的有限样本约束，不是用heldquery调强弱。当前B在这一校准步保持；梯度包含直接项`(dL/dz_l) h_l^T`，也可经当前真实h回到其它A。它不必先经过一个微小的最终动作改变或source动作Jacobian才得到监督；即使初始B=0，只要h含可辨信息，直接A项仍可学习。A/B不能同时零初始化。

旧H也可在其真实观测上用当前LoRA重算h，配原本实际执行的a/y训练条件后果；这是合法离策略的物理校准，不冒称当前policy的on-policy回报梯度。每次A改变后要重算当前实际读取，不能沿用旧A/h语义。

### 4. 教学到B的直接联系：先监督目标后果，再优化实际完整参数

**4.1 目标模型不再只接受FM余切。** 新增共享条件分布`p_phi(e | V,r_s,H_s)`，输出在当前真实状态s和自身历史下，教学任务所对应的下一段可观察关系变化e。r_s是当前自身合法物理事实及RGB对应；V仍是action-hidden有序教学。它不输出动作或LoRA，不读取参考身份、task ID、teacher state或完整指令索引；执行policy照常读取exact language。

其直接target来自获准non-held的实际成功行为：同task的另一条教学V，配独立episode中的当前状态s，以及从s实际继续并完成任务的控制过程；记录下一个原生replan周期真实发生的关系变化`e_star=r(s_next)-r(s)`，训练`-log p_phi(e_star | V,r_s,H_s)`。原生周期为执行前5动作；成功提前终止时只记录实际有效步数/时长和mask，不补造未来。只监督存在的字段，不从目标BDDL手写子目标，不将教师时钟当当前阶段。现有成功示范可给基础样本；关键新增覆盖是source/中间LoRA实际访态上的、确实成功的继续，其target仍是实际物理变化，不是参考Q或“必要步骤”。参考失败的继续不能伪标为正确目标，保留为无该正标签的事实数据。

标签含手—对象相对变化、真实关节/夹爪变化和对象间关系等，不能只用物体位移：抓取前物体不动仍可有明确接近动作的后果。多个有效继续保留为多模态分布，不将相反但都有效的变化平均成停住。模型对当前状态和H条件化，因此可以学到暂时远离终点的准备/恢复变化；无需手写“接近/抓取/释放”阶段，但也没有因此获得必要性或最优性证明。

在确有相同物理场景、且状态兼容性已审计的non-held任务对，可将同一自身状态配不同合法教学，以各自真实成功继续的后果作target，直接约束教学选择；该类配对是否足够尚未核实，不能当现有数据已强迫使用视频。即使没有直接L入口，静态场景/任务识别捷径仍须实际排除。不能制造held正确程序或用shuffled/reversed训练来补这个缺口。

这里明确新增了监督采集对象，而不是宣布已有一个可靠目标oracle。旧T50接手仅9/16成功、task29为0/4；旧成功示范也不等于学生失败访态覆盖。已有标签可复用，缺少的成功继续须在将来获准的non-held范围内实际取得；本文没有采集、调用专家或扩大任务。若这类覆盖不足，该方案在相应状态没有可靠目标先验，不能用“共享模型能泛化”略过。

**4.2 新condition直接以目标后果误差约束B。** 对当前实际状态s，固定目标分布p_phi，以及完成事实校准后的状态码`zbar_s=stopgrad({A_l h_l(s)})`。当前完整LoRA经官方十步flow、冻结action反归一化和前5执行截取生成真实动作`a_B=pi_(A,B)(o_s)`，后果模型取其中的关系变化输出`y_hat=f_psi_delta(zbar_s,a_B)`。它与p_phi使用完全相同的关系坐标、时长、单位及有效mask；f的当前事实输出仍只用于事实校准，不能混入后果向量。任务内目标是

`ell_phi(y;s,V,H) = -log p_phi(y | V,r_s,H_s)`，

`L_effect(B) = E_(s in actual H)[ell_phi(F_s(pi_(A,B)(o_s));s,V,H_s)]`。

F_s指真实环境的有限动作后果；不能以模型预测冒充F_s。f用于计算有根据的完整参数提案，实际同起点执行的提案后果用于比较目标误差、校准响应和后续更新。最终只能固定一套完整38/r8，不根据最终评测反馈选参数。

在局部模型可用处，生成提案的具体信用为

`grad_B ell = J_pi,B^T J_f,a^T grad_y ell_phi(y)`。

这条链的末端是明确受成功继续标签监督的物理目标误差，条件内J_f,a由自己的实际动作后果校准；它不是由独立query的g_Q反推一个自由评分。B更新时对p_phi、r_s、zbar_s和f参数停止梯度，只沿当前policy动作路径回传，防止通过改写目标/状态编码来降低loss。A仅由事实校准及登记的共享功能学习更新；完整参数改变后重算实际状态读取，再用真实后果校准，不能把过期模型解释当真值。

旧物理J的接触非线性和离散夹爪限制仍在。因此合同以**完整参数提案真实造成的后果**为准，不能仅凭模型梯度称方向正确。实际有限提案的目标误差差值还可通过已知参数提案密度的score直接教更新器；这不依赖未知flow动作密度，也不要求sign夹爪存在导数。它与模型梯度针对同一L_effect，前者提供真实反馈、后者减少盲目参数搜索。全部分支必须真实执行并计费；没有执行的反事实不补标签。信息获取实践不强制每个短步目标单调改善。

更新器从上述目标后果信用构造完整参数提案，不再保留一条直接V/H→任意B的平行生成分支；共享学习可训练初始化A、参数尺度/预条件和更新规则，不能凭一个不受后果信用约束的自由B头绕开此联系。没有自由动作轨迹优化、逆解a_star或动作伪标签数据集：被修改的是同一完整LoRA，动作只是该policy的实际输出，监督是其真实后果。共享训练中的参考动作只用于合法控制/标签来源；新condition不访问参考、离线动作或其继续结果。

**4.3 共享控制学习保留，但职责改变。** 在non-held任务中真实完成source→目标后果/响应驱动的适应循环，再对固定完整LoRA做跨episode动作FM及独立新初态实际R。FM训练共享A初值和更新器的跨状态控制能力，真实R约束局部目标达成是否变成整任务能力；phi只接受直接目标后果标签及其校准，psi只接受实际响应标签。共享语义读取亦由事实/目标后果监督更新，功能分支停止回传至该语义路径，防止通过共享encoder间接把目标改成容易优化的任意能量。

完整R仍通过已知密度的实际完整参数提案序列学习更新过程，源权重冻结；新condition采用同一提案语义，最终参数实际实践过，不临时换为未实践的均值。此信用可能高方差，不能称新的RL原理。即使共享R早期全部为零，成功继续标签和当前实际后果误差仍能训练目标模型/参数更新；若共享侧也没有成功标签或可靠目标先验，则不能从全零R创造正确目标。

**4.4 参考错配与旧法等价边界。** 参考的成功继续仅说明e_star属于至少一条已发生的成功路径，不说明它对当前LoRA有相同的后续价值。这里的迁移桥梁是让当前policy用自己的实际响应实现该具体变化，而不是把参考Q当当前Q；局部实现仍不保证后续均可实现，所以必须有真实学生访态覆盖、完整固定policy的新初态信用与能力保持。

若固定线性动力学`F_s(a)=J_s a`，目标正好为`e_star=J_s a_star`，平方后果损失确实等于`(a-a_star)^T J_s^T W J_s(a-a_star)`，即旧物理J加权动作误差。不能将这个特例包装成新原则。新增条件是：新教学中没有a_star，目标分布由合法教学/共享成功后果监督推断；自己的真实实践校准当前响应；B接受这项实际后果误差，而不是只在共享训练中换一个FM度量。旧J总体比例.29736未过.25、夹爪sign不可微的结果禁止复活原固定J近似或假称所有梯度可用。

### 5. 一个状态分离例子，以及新初态泛化的实际来源

以下只是两维算式，不是新实验。设某层两个状态的hidden为`h_1=(1,1)`、`h_2=(1,.5)`。若读取仅沿`a_old=(1,1)`，激活为2、1.5，一个B列不能对这两个状态给相反作用。若事实/功能共同学习得到`a_new=(-3,4)`，激活变成+1、-1，同一个B列v就能分别写入+v、-v。这里改变了参数函数对状态的区分，不是给同一个已有动作方向重新打分；rank1即能表达这个例子，真实方法仍完整rank8。

事实响应的双重差可以教模型这两个状态必须区分；B的用途由§4目标后果误差直接约束，并受独立功能/闭环信用检验。不能根据这个例子手写“随动就释放”：实际目标还依赖视频关系、相对容器布置及其它状态，目标后果监督须覆盖这些冲突。

再给出一个把B也接上的纯算式。设两个状态的实际响应为`y=kappa_s a`，kappa分别+1、-1，教学/共享目标模型在两状态都给出目标后果y*=+1。假设A已读出`z_s=kappa_s`，policy修正为`a=b z_s`，那么真实后果均为`y=b`，两状态的半平方误差之和为`(b-1)^2`。从b=0增大b，状态1产生正动作、状态2产生负动作，二者均向目标后果改进。

若先验误把第二状态kappa也预测为+1，就会给出错误的正动作方向；真实±动作分支即使最终任务全部R=0，仍可测出相反响应，校准后对同一目标的控制方向翻转。实践改变的是“用哪种控制实现同一个目标”，而不是从零回报创造目标。这个例子假设目标正确、状态可辨且响应在实际试做范围有效，不声称已经证明LIBERO有相同符号结构或整任务成功。

新初态上的作用来自共享状态读取先验、当前响应校准及固定B对状态激活的不同作用。B的更新同时约束已获得H中的多个状态；共享训练以整套适应后的LoRA在独立episode/初态上的结果教更新器保持这种作用。全失败时A仍有a→实际y的密集标签，B仍可获得目标后果与实际后果的差；目标信息来自合法教学和共享成功继续先验，不来自伪造的成功/正确动作标签。局部目标满足不等于新初态成功，Phi-N16的反证仍完整保留。

它也有明确限制：若h_1=h_2，任何线性A都不能区分；若需要的状态从最终RGB/state不可观察，编译期见过特权事实也不能让部署凭空观察；若共享先验从未覆盖相关响应模式、实践未提供区分信息，校准不能保证外推。局部A更新仍受已观察特征的张成空间约束，区别是其初始读取已在跨任务/状态事实上训练，并且更新目标是状态/响应而非固定source-H上的动作压力。native没有证明所有必要方向都缺失，本方案也不声称消除了信息和rank限制。

### 6. 从source到最终部署的完整过程

1. 读取合法视频，形成有序事实/实体对应分布，生成具有共享先验的非零A初值，置B=0；第一段真实实践严格是raw source的行为。
2. 用自身实际观测、动作后果和必要的真实分支校准视频读取及A。对未执行或不可观测的后果保持未知，不构造假成功、动作标签或“必要步骤”。
3. 共享目标模型根据重新读取的教学与实际当前状态给出目标后果分布；以当前响应形成完整B提案，再由真实后果误差驱动修订。新的A/B组成唯一source/r8 LoRA，实际执行它，再按新事实修订。轮数由登记预算/信息变化决定，不预设两轮或其它轮数菜单。
4. 完整生成的参数在实践中实际使用，预算结束后固定一套完整38-target/rank8 LoRA。新condition没有query动作标签；自身动作只是后果模型的输入，不作为模仿target，不准备轨迹再拟合policy。
5. 最终新初态评测只运行冻结source+这一套LoRA与exact language；Reader、f、状态校准、提案器、真实物理量和实践搜索全部退出，最终反馈不参与选择/梯度。

每轮B与A配套生成不是多LoRA平均或融合；共享初值不含MT基底。真实实践及重置均计费，适应初态与最终评测分开。共享学习中的独立终点R可训练提案过程，held最终R不能回流。

### 8. 当前判断与可失败预测

我选择将上述机制作为当前完整方案讨论：**教学/共享成功继续监督指定当前目标后果，自身实践识别执行响应，目标与实际后果之间的误差直接修订完整B，A将这种作用条件化到不同状态。** 不再把更准A自动等同正确B；当前新增主张是目标选择与执行响应分别得到可核实监督，并在同一真实后果目标上相接。FM/完整R负责跨初态与任务完成约束，不能独自替代前两条联系。

不能承诺“不会重演G/F”。当前至少改变了那条未解决联系的监督与消费者，但目标模型仍可能错误或忽略视频、响应模型可能失真、完整rank8可能无法实现所需状态函数。全失败实践只能在已有可用目标信息时校正实现方向；若两个目标/控制假说对合法V/H及全部已执行结果都相容，却要求相反选择，现有证据不能识别正确者。不能把R=0当作目标先验正确的证明，也不能将目标改成当前最容易做到的变化来制造进步。

它应当在相同教学/自身起点下对不同实际响应形成不同且有物理根据的A修订，并在独立初态获得完整控制收益。如果只降低响应误差而B作用/闭环不改善，就重现role/G/F边界；如果只改善实践不改善新初态，就重现Phi-N16边界；如果完整改写仍集中少数任务且丢失更广能力，就重现native边界。这些结果将否定相应机制投入，不靠继续调E/scale或将aux指标当成功来保留假说。

将来若进入实验，机制收益应相对同等教学/实践机会、保留完整功能学习的匹配参照判断，不能通过削弱普通FM参照制造优势。完整接受目标仍是固定单checkpoint strict paired400显著超过强MT，并有相邻保持、任务/suite覆盖与合理得失；教学内容和真实实践的贡献须在早期完整循环取得适量公平证据，不能仅因结构有两条输入就宣称成立，也不把全部controls变成开工前置条件。本文不据此新增执行授权或重开已停止的小实验。

方法的完整性在于输入、真标签、局部/共享参数、实际梯度消费者、冷启动、适应和退出路径均已明确；有效性仍需真实比较。此次没有新增模型/环境/GPU计算、标签采集、实现或实验派发，也没有将讨论稿登记为active design。原先d_e事件用途与M^T g_Q的限制仍成立；当前方案不依靠撤销那些反证来成立。

## 因果用途、全失败与当前控制器：撤回d_e作为完整方案依据

### 1. 动作随机化不等于事件随机化

`d_e=mean[(Y_be-Y_ce)(R_b-R_c)]`仍是实际分支组中的同向变化量。即使动作b被随机分配，也可能存在`b→Y_e`与`b→Z→R`两条路径；Y_e随动作改变，却不在通向任务结果的必要路径上。相同完整起点排除了部分起点混杂，没有将Y_e本身随机化，也未控制其它随动作同时改变的物理后果。不能由d_e取得事件的独立因果信用、必要前提或正确下一步。

有限样本全R=0使该target无信息，并不证明所有动作真实成功概率为0；reference的非零差别则是其继续策略下的证据。将两者分列避免了错标，但没有提供从reference用途到当前source/r8改进的学习桥梁。上一版把“已标明未知”当成完整方案已经补链，判断过早。撤回d_e→q→Phi作为核心操作奖励的方案，不再将其自动标签化称为解决办法。

### 2. EMBER需要的因果问题应直接落在完整LoRA上

无需先证明某个物理关系具有普遍因果必要性，才能研究它是否帮助编译。直接问题是：在相同合法教学、当前完整lambda及已获得真实H下，采用某项修订，是否改善固定policy在独立初态上的完整表现？对一个预先明确的修订delta，定义

`U_R(delta; lambda,V,H) = E_Q[R(pi_(lambda+delta)) - R(pi_lambda)]`。

Q为未参与该condition适应的初态，比较相同env/policy RNG；实际有限样本差是有噪声target，不是精确期望。两臂都执行当前完整source/r8 policy，只改变登记的参数修订，且不在最终执行中使用E/reference。这个对照针对该修订的实际控制效应，不能反向解释成视频窗口e在物理世界中普遍必要，也不能把单窗口效用直接相加成整套LoRA效用。

共享训练允许用non-held Q形成这类标签；新condition的最终评测Q保持封存，其结果不能训练/挑选LoRA。任务内若使用独立适应初态判断修订，仍属于计费实践，不冒充最终评测。旧d_e比较的是分支事件与成功的共变，U_R比较的是完整参数干预；两者不是同一监督。但如果所有受测当前LoRA都失败，U_R仍可能全零，本定义没有凭空消除稀疏回报。

### 3. 冷启动只能明确引入已有合法信息，不能制造标签

必须分开共享训练与新condition。共享训练已允许non-held同task、跨episode动作query，可在当前完整lambda上计算原生FM损失`L_Q(lambda)`，得到密集功能信用。对实际可执行修订delta，`U_F(delta)=L_Q(lambda)-L_Q(lambda+delta)`即使所有闭环R样本为0仍可能非零。它的标签来自合法动作/功能监督，不是从失败中恢复出的正确程序，也不是reference继续策略的Q值。原始动作query只生成训练target，不进入视频条件或新condition；不利用held离线动作。

这不是新增一种信息源：原G/F、FR及后继元FM已使用跨episode功能监督。若将它改写为显式utility target，只改变信用的训练方式，不能声称发现了此前没有的操作监督。L_Q下降也不等于闭环成功增加，尤其query访态与学生实际访态不同时。真实U_R必须约束完整方法的取舍；不能用U_F定义成功或覆盖其反证。

新condition从source开始全失败时，没有对应的真实U_F标签。非零修订只能来自共享训练已学得、在此条件下尚待验证的改进先验，以及自身实际动作后果。实践可直接纠正“对象未随手运动”“所选对象/关系绑定不符”“同一动作响应与预测不同”等事实；它不能仅凭这些事实把一个未知的目标用途变成已知。自身success一旦出现可提供额外任务信用，仍不能读取最终评测反馈。若两个控制假说对已观察的V/H与所有实际结果给出完全相同预测，却要求相反修订，现有信息不能确定选哪一个；需要能区分它们的合法实践，或承认当前共享先验/覆盖不足。这是可识别性限制，不是为全失败自动停止或另造审批门槛。

把reference价值改称势能也不补信息：若`r'_t=r_t+gamma*Phi(s_(t+1))-Phi(s_t)`，折扣总回报为`G'=G-Phi(s_0)+gamma^T Phi(s_T)`。固定起点、正确处理终点使末项为0时，完整路径policy-gradient回报没有新增动作排序；势能可以影响有限样本学习/critic优化，却没有新增识别目标的证据。保留非恒定末项或截断bootstrap确实可给全失败样本一个方向，但那是额外代理目标，其对当前LoRA的有效性仍须学习/检验，不能用“奖励塑形”名称消除reference错配。

### 4. 一个完整但有条件的功能信用计算

以下给出可计算的训练机制，目的是说明信息和实际参数消费者在哪里，而不是将其认定为已优于旧法的新架构。

令lambda表示当前全部38处rank8的实际A/B参数；source基础权重冻结，identity初始化不能令A/B同时为0。当前LoRA真实执行产生H和实际动作分支b。由实际采样分布及原生policy形成方向`d_b=P*grad_lambda log p_lambda(tau_b|H_start)`，P只表示明确的参数尺度/预条件；D由这些方向组成。视频Reader提供有序事实和带不确定性的对应，修订评分器同时读取这些内容、真实分支后果、当前LoRA及其原生响应。不能仅把reference控制器名称换成“当前能力”就当作已条件化当前policy。旧parent产生的分支不冒称当前on-policy样本；此处D作为候选参数方向使用，也不将学习评分的组合称为无偏任务回报梯度。

在共享训练的独立动作query上，计算

`g_Q = grad_lambda L_Q(lambda)`，`u_star = -D^T g_Q`。

u_star的每一维表示：沿这一条真实当前policy参数方向，独立query功能误差的一阶下降率。它有正有负，不作正部分事件奖励，不需要预写“应抓/应放”的程序。以`||u_hat(V,H,lambda,实际分支)-stopgrad(u_star)||^2`直接训练评分输出；事实Reader仍由事实标签约束，功能评分不再被称为已知操作语义。实际修订为`lambda_plus=lambda+eta*D*u_hat`，形状保持完整38/r8，所用实际动作不作为BC拟合target。

这个直接回归的梯度是`2*(u_hat-u_star)*grad_theta u_hat`，无需先经一个很小的实际修订再回传监督；但u_star本身仍由D与g_Q的重合决定，标签也可能很小或全零。不能以改变loss入口消除native可达性限制，也不能把数值尺度放大等同增加信息。

固定本次D，在局部平滑条件下有

`L_Q(lambda_plus)-L_Q(lambda) = -eta*u_star^T*u_hat + O(eta^2*||D*u_hat||^2)`。

若预测准确且步幅适当，一阶项为`-eta*||u_star||^2`；若预测误差使内积非正，或有限更新曲率/分布变化显著，则没有下降保证。对真实有限delta还应直接计算U_F，完整闭环则用实际U_R。这个推导仅针对规定query分布的功能目标，不是对未见任务成功率的定理。源identity附近factor方向的限制、访态不足及跨状态干扰都仍存在。

重要的是：u_star本质仍属于此前讨论过的`M^T g_Q`/native投影功能信用。直接监督可以改变训练条件、缩短上游优化路径，却不新增跨初态方向，也不自动排除任务识别捷径。把这个公式写清楚后，不能再声称它独自解决了此前针对M^T g_Q的质询。

### 5. 数值例子：为什么共同运动评分不够，什么才是跨状态约束

以下完全是两维局部算式，不是task12的新实验。设两个独立query状态相对于当前动作功能的正确变化为`(+1,-1)`；这些数在真正共享训练中来自合法动作query，不是由标签构造器手写“抓持/释放阶段”。当前输出置零，平方误差`L=1/2||prediction-target||^2`为1。当前真实H若提供两种参数方向，其在query上的作用分别为`J_Q d_1=(+1,+1)`及`J_Q d_2=(+1,-1)`，取系数.2：

| 实际参数修订的query效应 | 修订后误差 | 功能收益 |
|---|---:|---:|
| .2*d_1：两个状态都+.2 | 1.04 | -.04 |
| .2*d_2：一个+.2、另一个-.2 | .64 | +.36 |

两条实践分支完全可能都获得高共同运动匹配、且完整任务R样本仍全0。事件关联分不区分上述参数作用；独立query监督明确区分。目标是学会选择当前能形成这种状态区分的修订，而不是把某个分支动作记录后拟合回去。

反例同样关键：若当前D只有d_1，则任意系数c的误差为`1+c^2`，最佳是c=0。再准确的E也不能从这个方向写出所需相反作用。新真实访态/当前参数改变有机会提供新的方向，但“多实践”本身不保证出现它；更大的E、正步长或reference高分都不构成替代证明。若暂时不利的修订能让后续实践访问必要状态，逐步强制U_F>0还会错误禁止学习；完整编译路径的终点功能/回报信用必须保留，短步target不能变成每步验收硬门槛。整路径信用已有历史，亦不作为本次新原理。

### 6. 当前判断与剩余真实缺口

可成立的学习分工是：合法non-held事实监督教视频与自身过程表示；合法跨episode功能监督建立当前source/r8的改进先验；实际实践校正当前响应、提供新的真实访态；真正的用途由当前完整LoRA修订在独立初态的表现裁决。reference若用于提供合法功能标签，是有质量边界的训练教师，不能以其继续回报代替当前LoRA的结果。共享训练需覆盖真实source与实际中间LoRA的学习状态，而不是仅在reference成功状态上拟合一个价值头。

这说明冷启动的信息来源与reference错配应如何被处理，却尚未证明一个能跨初态奏效的完整方法：表示能否从合法V/H预测正确修订、当前方向能否表达该修订、有限功能收益能否传为真实控制以及是否迁移到held，仍是不同问题。理论条件应明确，不能借“评分准确”假定它们全部满足。

旧G/F已有关系和跨episode功能学习，关系更准未取得相应能力；FR上游/实际写入极弱，直接target可能改变其优化条件，但native首写64/144低于同教学Reader89说明真实写入成立仍不足；Phi-N16实践提高而新初态61/71/62对MT67进一步否定局部进展充分。T50的expert/MT差别不再承担新方案的当前LoRA用途标签。已有正例与容量证据保留，但容量不证明这条学习路径可达。

因此当前不将“直接回归u_star”包装为又一个已经选定的完整方案，更不因其可写成公式就恢复训练。撤回的是d_e事件用途核心及其完整性主张；事实/对应可作为观测学习保留。直接监督是一个可定义的优化假说，但本次尚未提出足以区别旧失败预测的具体学习条件/方向形成机制；不能只将旧元FM重命名为因果监督。这里没有要求先保证成功，而是承认上一版承诺的两处新增学习桥梁并未由该公式给出。后继需回应这个实际缺口，完整方案仍未闭合。遵守Owner先不开实验：本次仅科学推导与记录，无模型/环境/GPU计算、数据采集、实现、active design或派发。

## 标签自动构造与完整实例：不把操作程序写进target

### 1. 标签的三种身份必须分清

上一版将操作事实、对应和前提都写得接近“直接标签”，不够准确。可直接取得的是实际记录的物理量、执行动作及自身success；关系计算和跨过程匹配是可复算的派生target，但不等于正确操作语义。“抓住是抬起的必要条件”“先水平对齐再下降”不能从一条成功轨迹自动证明，也不设这种标签。E所谓前提判断，具体定义为给定实际H/分支时的事件到达及任务结果预测，接受真实继续结果的检验。

自动构造器不得读取BDDL的goal operands/predicates来指定目标实体或操作顺序，不读取语言动词生成阶段列表，不以teacher进度百分比指定阶段，也不把参考控制器动作转成新condition的拟合target。所有实体使用同一规则；训练侧物理ID只追踪实体及构造跨episode监督，输入重新匿名化。对目标对象的关注须由合法语言/RGB及所示变化形成，不能由特权目标表代做。

### 2. 一条可实现的自动构造规则

1. 对获准non-held episode使用stride5的真实帧及已有同步物理标签，枚举全部实体。逐时刻计算可观测的`p_i-p_j`、有标签时的相对旋转、相邻真实位移、关节量及raw两指qpos；有真实contact记录才加入contact。未知字段mask，不从body距离/共同运动伪造抓稳、接触力或摩擦。
2. 不预分“接近/抓/搬/放”。候选e为采样时钟上的连续窗口（含相邻窗口的连续合并），保存实际有序关系序列、变化量和有效mask。至少有可分辨动态变化的窗口作为动态候选，静止背景不能凭重复帧数获得操作信用；阈值/物理单位统一由合法训练侧冻结，不按task和held结果改。窗口并不宣称具有完整操作语义；多个窗口可以描述同一操作。
3. 教学窗口e与实际执行窗口w按合法物理实体对应、共同可见字段和真实内部顺序比较。用归一于固定物理单位的连续关系误差、变化误差及有记录的离散事实误差形成距离d；窗口内可做单调时间对齐，整个恢复过程允许空隙、回退和重新对应。输出软匹配`C(e,w)=exp(-d(e,w)/temperature)`及可观测性mask，而不是强制一个正确阶段。temperature/尺度只在训练侧冻结。多个近似匹配保留分布；无法区分的候选不能当独立确定标签。
4. 对同一真实学生起点的实际随机动作分支，记录后续当前LoRA和获准reference各自的完整继续；两种控制器分列。在未来实际窗口中自动计算每个e的匹配程度和首次/最佳出现时间，得到`Y_e^kappa=max_w C(e,w)*exp(-T_w/h)`；当前及未来窗口完整性不足则mask/censor。e本身包含关系保持过程，不另写“必须保持哪些关系”的task规则。真实任务R另存，不能从C阈值伪造成功。
5. q不再以“最先匹配到的片段就是正确下一步”为target。同一起点、同一指定继续控制器kappa的实际分支组中，计算`d_e = mean_(b<c)[(Y_be-Y_ce)*(R_b-R_c)]`，取有证据的正部分并归一为用途soft target，负/无信息分量不获正信用，全部无信息则mask/unknown。这个量只说明某种视频事实的达成差异与本组实际完成差异同向；多个同步变化的关系无法据此分清因果必要性，保留集合/不确定性，不能选成唯一真前提。所有分支R相同时本组没有这种用途标签，不能用更近距离伪造有用性。获准reference可提供此类用途证据，但须同reference的分支配对，不能混reference和当前LoRA的R；当前v仍只按当前控制器继续校准。

第3项是带有距离与对齐假设的自动对应target，确实继承关系匹配思想，不能包装成已经发现因果操作。新的硬证据在第4–5项的实际干预后果与独立任务结果。q也只是这些数据支持的用途判断，不叫正确程序。未匹配的恢复段保留gap，后续真实到达仍进入Y；不需要为gap手写“重抓”标签。完整方法若只有第1–3项学得好，仍可能重演G/F或Phi-N16。标签构造必须同时保留“部分动态匹配很好，但完整任务失败”的样本。

### 4. 这份数据怎样训练E、怎样影响实践

Reader从action-hidden RGB预测上述有序事实分布，监督是原始记录；跨过程读取预测候选对应C，监督是带mask的自动匹配；q接受同状态真实分支的用途soft target d，结果头预测当前控制器条件下的Y，监督来自真实后续。实际R参与用途target，并另外提供真实任务policy-gradient信用；不增加一个没有实际消费者的R辅助头。输入仅到当前H及已执行分支，未来继续只生成训练target，不能作为预测输入。物理/对应loss没有把success路径的动作交给Compiler，FM/新初态回报仍不改写E的这些target定义。

本例中，两种继续的早段共同运动都应得到相应事实匹配，不能为了讲恢复故事把MT早段改标失败。之后完整H中A—B的变化、手—A的保持/改变以及实际后果使未来事件预测分开；失败结果必须保留，不能只抽成功恢复。若未来真正同控制器的两分支都匹配共同运动（如Y=.9/.9），而任务R为1/0，该事件的d为0；若另一教学窗口的Y为.8/.2，则d=.6。这里的数值仅解释自动规则，不是把现有两种控制器数据混算成一个有效分支组。规则没有预先规定哪个窗口有用，也不证明正d的关系独立致因。同任务另一布局中的实际分支提供共享学习，操作复用范围仍受数据覆盖限制。

例如v使用平方误差时，直接信用是`grad_theta L_v = 2*(v-Y)*grad_theta v`；它不含native J_H、query J_Q或LoRA更新步长。即使某次参数修订很小，E仍能由真实后续target学习。这具体改变FR的上游监督条件，但不能保证Y是充分操作目标，也不能保证独立任务上预测准确；不能用“梯度更直接”代替能力结论。

新condition内，实践把真实的新关系变化和动作后果加入H，并重新计算当前匹配、未来到达和不确定性。比如新实践确实出现“手移动但对应物体不随动”，它就不能匹配teacher60→75的共同运动；这只是条件示例，不是上述MT轨迹的事实。也不能据此直接下发“重抓”命令。只有合法训练和当前实际分支表明某种改变能提高后续事件/任务结果，才给它较高信用。已观测到的事实直接更新，无需额外假装一个已知物理模式标签或必要前提。

### 5. LoRA信用的完整数值示例及跨初态限制

以下.8/.2是算式示意，不是新实验结果：假设当前LoRA在同一真实观测的gripper探索概率p(close)=.5，两个真实分支的预测事件信用分别为.8/.2，本次任务R均为0，独立对照baseline为.5。优势为+.3/-.3。对于关闭概率的logit z，实际Bernoulli score分别为+.5/-.5，因此平均信用为`g_z=[.3*.5+(-.3)*(-.5)]/2=.15`。这提高当前状态下关闭概率；若实际数据在另一个处境支持开启，符号自然相反，label builder没有“关闭正确”的规则。

完整参数梯度为`.15 * grad_lambda z(o)`（其余实际连续动作信用同样累积），更新全38处rank8 A/B；不是把分支动作复制成监督轨迹。共享正步长/动量规则决定实际步幅，条件内E权重保持冻结。当前原生网络决定哪些参数改变会改变这个真实观测的动作；跨episode FM通过更新后的完整policy教共享更新规则兼顾其它状态，实际独立新初态回报裁决完整能力。

若暂略动量，另一初态o'上的局部改变是`Delta z(o') approx .15 * grad_lambda z(o')^T P_psi grad_lambda z(o)`。这个内积既可能有用，也可能伤害另一个应开启的状态；事前没有理由保证为正确符号。于是当前机制和FR仍共享native特征/参数传播限制。自动标签更具体，不会自动把kernel变成跨初态有效控制器；若独立状态不改善，不能再以事件识别准确保护这一假设。

当前能够负责的差别是监督路径：E直接接受物理、带误差的对应及真实后续结果；LoRA始终消费实际动作信用；外层FM训练完整更新在其它状态上的作用。不能负责的说法是自动发现了唯一正确程序、必要前提或保证不重演G/F/FR。旧G/F已有关系瓶颈，本例的早段共同运动反例进一步说明该限制；FR/native阴性要求最终完整参数效果承担证明。0新model/env/GPU实验或实现，仅旧原件读取和上述算术分析。

## 当前完整议案：直接教操作对应与恢复用途，再学习完整参数修订

### 1. 必须改变的学习合同

仅扩大E输入没有补上核心监督。当前选择是让E成为有明确目标的操作对应/恢复评价器：合法训练任务的操作事实、真实干预和实际恢复，为它提供可逐项核对的标签；完整LoRA后的FM与新初态回报训练参数修订规则。后两者不再任意重定义E的语义输出。模型仍须学习，收益仍未获证；这不是宣称用标签即可消除一切黑箱，而是取消“任意能量只要偶尔减小query loss就算理解”的自由度。

完整链路为：`有序RGB教学 → 角色关系及操作事件分布 → 与自身经历的对应/前提判断 → 实际分支的操作进展与恢复信用 → 当前policy原生score → 全部38处rank8 LoRA修订 → 新的真实实践`。本议案按K=1定义，不暗称已支持动态K。共享训练另外在独立初态/episode消费最后完整LoRA；新condition没有动作轨迹拟合、reference执行或外部阶段控制器。所有实际分支及reset计入交互预算。

### 2. 直接标签是什么，来自哪里

所有下述teacher标签只来自已授权train/non-held allowlist，作为共享训练target，不进入教学条件。旧标签能够复用的部分复用；新干预/恢复标签目前并不齐备，不能把下述计划写成已有数据或已通过结果。不得扩用held离线标签。

| 学习对象 | 可观测target | 真实消费者与边界 |
|---|---|---|
| RGB中发生的操作事实 | 对象/手的相对位姿时序、关节/夹爪变化、真实可得的接触与共同运动；同一物体跨视角/帧对应 | 教学Reader的分布预测；被遮挡或原件未记录的量带unknown，不从静态几何伪造接触力/因果性 |
| 视频与自身操作的对应 | 不同episode的教学事件与实际恢复段中角色、关系变化、保持关系及次序的对应集合；恢复前先修复某前提、随后才接回教学事件的事实 | E的事件/角色对应输出；用训练侧物理身份作标签匹配，但不把身份、任务ID或正确步骤表输入Compiler |
| 当前条件下的操作用途 | 从同一真实学生状态执行不同真实动作后，同一指定继续控制器实际达到哪些教学事件、何时达到、是否保持、最后是否成功 | E的事件到达/恢复结果预测及成对差别；这是特定干预和继续策略的证据，不是“某关系普遍必要”或“失败即不可恢复” |

操作事件不是手写的“抓、拉、放”task脚本。它保留真实连续窗口中的关系变化/保持、参与实体和实际可得的接触/响应证据；窗口可重叠，多条匹配均允许。自动匹配只给候选对应，不认证操作充分性或必要前提。位姿近似但先后次序、接触建立或共同运动不同的过程可以得到不同target。连续相对关系用于跨布局匹配，类别/外观用于角色对应；仅由被动共同运动得到的是相关事实，只有实际动作干预提供相应局部响应证据。

同一学生状态的分支之后，可由训练侧获准reference作真实接续，观察它何时重新实现视频所示效果，以及先做了何种恢复。匹配用标签中的物理变化，不能把最近帧距离当正确用途；用途还须由实际事件到达及后续结果支持。该target表示“这条实际成功恢复接回了这些操作”，不是不可观测的唯一正确下一步或普遍因果必要性。恢复中可能先退开、松开或重抓，而视频未示范该段：监督为“恢复后可接回哪些教学事件/前提”，不是强迫该动作对应某个teacher帧，更不为held手工补一段正确动作。无法唯一对应时监督集合/不确定性；未成功恢复不制造一个正标签。

reference与当前LoRA继续的结果必须分列。reference能做到只证明该控制器的可达性，不能冒称当前source/r8的Q值。E的可执行性/事件到达预测须用当前LoRA真实继续的样本校准，条件包含当前真实H的控制响应；reference仅补充操作对应、恢复方式及可达性证据。单条0/1结果是监督样本，不是已知成功概率；全失败区域没有可靠成功排序时保留未知。

### 3. E的实际算子与梯度

Reader从stride5有序双相机native视觉特征预测匿名角色、完整关系/接触/响应事件序列及不确定性。exact language用于寻找目标/对象证据，执行policy仍读原指令；不另设整句语言/任务名到E或LoRA的索引通路。自身RGB、proprio、实际动作、可用环境/接触及reward保持真实，不为去任务信息而删除H。

跨过程读取比较每个视频事件与自身有序经历，输出：角色绑定分布、已实现/仍保持/待恢复事件分布，以及当前真实分支对这些事件的到达与保持预测。恢复评价只消费这些有物理/对应标签的字段、实际自身事实与已标定的控制能力；不留一条不受这些target约束的video hidden直通自由标量分支。完整过程仍进入这些预测，不能先压成旧m的几个端点距离。

直接训练项为`L_E = L_facts + L_correspondence + L_intervention-outcome`，分别用实际连续量误差/概率似然、合法多匹配target和真实事件/继续结果训练对应输出。实际权重按标签单位/采样口径冻结，不靠held结果选择。标签语义不变的共享E训练可随新合法训练经历继续；不将“冻结E语义”偷换成E永不训练。

具体评分采用上节定义的软对应到达target：`Y_e^kappa=max_w C(e,w)*exp(-T_w/h)`，而不预设已经有一个正确的二值“实现操作”判定器。保持事实来自实际窗口内的关系序列，不另写task必要条件。观测截断/字段不足按mask/censor处理，不冒充失败；低匹配值不证明语义不可达。reference与当前LoRA的Y_e各自学习、各自记账，部署评分使用当前LoRA的预测。实际success独立记录，不由对应分数替代。

分支采样前，由当前V/H得到候选教学窗口的用途分布q_e；它用上节同状态、同继续控制器实际分支的d_e soft target监督，不标唯一正确下一步，允许多解和未知。真实分支b执行后，E预测`v_be = E[Y_e | V,H,tau_b,当前控制响应]`，标量`Phi_b = sum_e q_e v_be`、`E_b=-Phi_b`。q有显式但受限的用途target，v由完整实际过程及后续到达target学习，能够评价经未匹配恢复段后接回教学效果的路径。它仍是一个受限、可能错误的操作评价器；对齐和用途统计都不认证充分操作语义。

内层用`A_b = (Phi_b - baseline_Phi) + (R_b - baseline_R)`，两项各在[0,1]单位；R是实际当前继续的任务success，不使用reference回报伪充。共同状态baseline须与本次动作独立（例如其他独立分支的leave-one-out）；实际success尚未揭晓时只积累事件信用，后来按真实轨迹补任务信用。该预测事件项是有偏的辅助学习目标，不冒称真实任务回报的无偏梯度或最优策略不变。若所有真实分支既无操作差异也无成功差异，没有可靠有用信号，不能由网络任意给分补出来。

这里仍使用真实回报教“是否有用”，因为几何本身不能回答任务用途。改变在于回报直接标记同状态干预的恢复用途，而操作是什么、对应哪里已有独立事实/对应target；不再要求末端FM经长链同时猜出全部语义。事件进展可能成为不充分的代理，因此完整闭环性能继续拥有否决权。

### 4. 实践具体修正什么

新condition冻结共享Reader/E参数，保留任务内的角色绑定、事件进度及控制响应信念。每次真实动作后，直接更新已发生/仍保持事实；对未知物理模式z，使用共享训练标定的`p(y | x,a,z)`更新`q(z | H)`，再以新H和信念重新计算视频对应及当前操作前提。只对具有不同实际响应预测的假设产生证据；当前环境已直接观测到的事实无需再假装推断。

示意：视频中手与一个物体共同移动，自身实践却只有手动、物体未动；这会降低“已经建立可带动联系”的判断。合法训练中“同类失败后恢复联系，再实现视频效果”的对应/恢复标签，教E此时应重新解释前提，而不是继续奖励手更靠近视频终点。这里只说明通用信号链，不声称旧原件已确诊该具体故障，也不向held提供物体/阶段答案。

物理响应不能凭空识别视频的任务意图：给定同一完整状态和实际动作，物理后果不因目标而变。实践更新的是视频所示操作与自身对象/控制能力的对应、当前适用条件和进展；任务用途来自合法训练的对应/完成证据，以及新condition自身真实任务回报。若两个解释作出同样预测且任务结果也无法区分，就保持歧义。这明确限制上一版“后果准确便帮助理解”的过强说法。

### 5. 怎样形成一套新初态有效的LoRA

每个新condition从source identity上的完整38-target/r8开始。当前LoRA在自身真实观测产生native动作；实际采样/执行分支后，以E操作信用和自身真实回报形成优势A。令`g = sum_i,b score_lambda(a_ib | o_i) * A_ib`，score使用实际已知采样密度；连续动作和离散夹爪各用正确score，不对hard sign伪求导。分支只用于真实policy-gradient信用，不作为期望动作target。

共享修订规则U_psi使用g、历次g/更新和已标定的操作信用，输出每个target的A/B分组正步长eta及0≤beta<1的动量系数：`m_plus = beta*m + (1-beta)*g`，`lambda_plus = lambda + eta*m_plus`。它不含可独立输出一套task LoRA的自由偏置或字典头。所有target可更新，始终保持38处rank8；identity使用固定合法A、B=0的非退化因子初始化，而非A/B同时为零。这是当前选定的因子更新，不混称为另一套全矩阵投影实现。

psi由同task跨episode动作FM和完整编译后的独立新初态真实回报训练。query只在最后完整LoRA的正常policy forward后提供loss；E语义输出对这两类外层梯度stop-gradient，避免psi/E合谋把标签解释变成有限query漏洞。FM仍然不可省略为“过去失败所以无用”，但其职责变为教同一个操作信用怎样写入参数、兼顾未访问状态，而不是充当操作语义标签。训练需要真实当前LoRA继续产生新H，不以重复固定source-H冒称反馈循环。

对固定已执行support，FM可微穿过实际更新链训练psi；这只是条件导数。涉及改变访态/采样分布的完整期望回报，须包含适应及query轨迹的实际score项，不能将停止环境导数的重放称为整环境精确梯度。成功状态保持与任务/初态覆盖在同一最终policy消费者衡量，不用内部距离或小FM下降替代。

若J_i是实际native动作对lambda的导数、s_ib是实际动作采样对其分布参数的score，则`g = sum_i,b J_i^T s_ib A_ib`。跨状态效应仍受`Delta f_Q approx J_Q P_psi J_H^T c`约束，c为相应的score×优势聚合，P_psi包含当前实际分组步长/动量。本次改变没有创造新迁移定理。作用预期来自三件可失败的改变：A有独立操作/干预标签；实际修订后不断取得新的H与native方向；psi只因同一完整更新在独立状态上有用而被保留。若正确局部信用在rank8/source特征内不能形成广泛控制，正步长/动量也不能凭空创造缺失方向，本方案仍失败。合法source/r8参考的高闭环性能只支持容量存在，不证明该优化路径可达。

教学/实践/修订在预先登记的真实交互预算内按反馈组织，不先规定固定轮数。新condition仅更新任务LoRA、局部优化状态及自身事实/信念；没有held离线FM或共享参数更新。最终按预注册规则冻结一套已经实际参与实践的LoRA，所有Reader/E、reference、搜索、阶段选择和任务内优化退出；新初态正常闭环只读原生观测与exact language。

## 前轮复核：关系权重、操作表示与跨初态信用

### 1. 线性E确实是条件化关系重加权，表达能力不能由名称扩大

原式`A_b=w_theta(V,H)^T m_b`相比固定Phi/DTW增加了依赖当前经历的选择和修订后功能目标，但仍是关系评分的条件化加权。w读取有序视频/H，不等于m保留了当前分支的有序过程。若两分支在全部m坐标上相同，则任何w都给同分；若`m_b1 >= m_b2`逐坐标成立，非负w不能反向排序。零贡献选项可忽略它们，不能补出缺失区别。该结论限定于当前视频评分项；后续H和真实任务回报可能提供额外区别，不据此证明整个循环永远不能区分。

位置、姿态、关节、夹爪及其时间变化可以描述接近、相对保持、物体搬运或关节运动等可见事实，但“哪些事实是完成任务的必要条件”“相同几何下是否建立有效接触”“怎样跨状态控制”不是这些字段自动给出的标签。把坐标换成物体相对坐标，只处理部分布局变化。即使完整几何轨迹已知，也不普遍识别接触力、摩擦或操作的因果必要性；更不能将几个端点距离称为充分操作表示。

例如，两条已执行路径可以有相同端点，却在过程中是否保持某个相对关系、是否先建立可带动物体的联系上不同。只有端点差值的m丢掉该区别；保留真实顺序和耦合变化才能让E有机会识别。这里是表示反例，不是声称已经在旧原件观察到某个具体接触故障，更不是为held任务手写程序。

### 2. M^T g_Q传递的是参数效用，不是操作语义标签

固定本次incoming、实际H、分支及native导数，令`Lambda_plus=R8(Lambda+eta M w+真实回报项)`，`g_Q=d_Lambda_plus L_Q`，将实际尺度/投影导数合并记为`P=D R8`。真实关系权重信用为

`d_w L_Q = eta M^T P^T g_Q`。

第k项是完整参数方向M_k与独立query误差方向的内积。它能教哪个已存在方向在当前query上有用；不能创造M中没有的方向，也不能将产生该方向的关系解释认证为正确。有限query上的梯度抵消、rank/投影损失及未覆盖状态的相反效应仍存在。对实际有限更新后的L_Q反传可以是精确的当前事件梯度；将其外推为未访问初态的闭环改善，才是尚未成立的推断。

进一步令`M=J_H^T C`，其中`C=sum_b s_b m_b^T`由真实扰动score和后果比较构成。若`J_Q`表示query中实际受监督policy输出对参数的导数，则局部函数变化为

`Delta f_Q approx eta J_Q P J_H^T C w`。

跨初态联系具体来自当前网络在实践状态与query状态的导数重合；物体相对坐标不保证该重合有效。FR原合同已经写出同类`J_new P J_H^T q`限制，所以新式没有新增跨状态迁移定理。真正改变的是C：在固定自身起点、实际随机动作及固定继续规则下，期望score-后果乘积估计所选扰动策略的局部关系响应；它不要求E凭空猜动作怎样改变物体，但仍只是有限采样、当前控制器附近的响应。

### 3. 跨episode、使用H与完整回报都不能单独排除任务捷径

反例：若训练任务t的合法视频经当前比较后均给同一类`m_t(H,b)`，则`w_theta(L,H)`或任务专属的条件评分可以在所有跨episode query上得到同样目标值。不同初态能约束记住一条世界坐标轨迹，却不能排除记住一套task controller。加入H可区分当前状态，仍可能得到“任务识别+通用纠错”；完整新初态回报也不会主动要求视频操作内容不可替代。

反过来，w不随视频变化不等于整个算法没用视频，因为M/m还可能实际消费视频中的关系值。正确视频表达同一种操作时，也可以合法地产生相同控制器。不能以强制视频敏感性、attention变化或视频分类准确率证明理解。

同task/同教学下真实失败位置、当前LoRA和实际响应的变化，可提供任务常量不能独自解释的监督；同类关系操作跨对象、布局与任务组合复用，可支持共享规则。两者需要真实覆盖，不是把更多同task episode叫作更多独立操作条件。即便这些条件齐备，任务与操作解释在训练分布上仍可能等价；未见task/组合的泛化与适量视频因果证据才能进一步区分。这里没有新增错误/打乱/倒放训练，也不改变原有controls顺序或固定split。

Phi-N16的实践66→77/72/80与独立query61/71/62对MT67，正好提示局部关系进步不能替代新初态控制。G/D175与相邻168对MT153等正例保留参数编译的可能性，但其MT起点、收益集中和能力交换不能给当前source/r8议案直接背书。不同方案的局部正例不能拼成端到端资格。

### 5. 本轮对E的具体收敛，而非再加一个预测模块

保留真实分支、当前完整policy导数和共享训练整个修订过程。E的完整输入应保留有序教学证据及其预测关系、当前真实H、分支实际执行过程中的关系/视觉变化及可用自身接触事实，而不是只收端点距离m。关系字段提供事实锚点，不假定它们已经是充分统计量；读取过程须能够比较哪些对象一起变化、哪些相对关系在移动中保持、实际先后顺序及当前控制功能。不得为held提供正确接触/阶段标签，未观测事实保持未知。

完整形式为`A_b=-E_theta(V,L,H,tau_b)`；E评价真实已执行段，不预测未执行动作后果，也不准备动作轨迹供BC。沿同一个`Gamma_b=J_H^T s_b`写完整参数。固定当前事件时，信用为

`d_theta L_Q = eta sum_b (Gamma_b^T P^T g_Q) d_theta A_b`。

原线性M^T g_Q是其受限特例。此改动消除已指出的端点/正权重表示硬限制；它本身没有解决可学性、task捷径或kernel迁移，输出更自由还可能增加投机空间，不能单靠更大网络论证优先级。

共享学习必须让评分对同一完整参数更新在独立状态上的实际后果负责，保留跨episode密集FM及完整编译后的新初态真实回报；这些消费者已有历史，不冒称新监督。真正要学习的条件差异是：同一教学在不同真实失败/当前LoRA下哪些已观察操作后果值得据此修改参数，并把这种取舍复用到非held数据中重复出现的关系操作。E在固定新condition内参数冻结而随H重读，实际响应随当前LoRA重新取得；不能把一份固定source-H重放说成完整实践学习。

所以当前可负责的假设是：实际干预提供动作到可见后果的局部联系，完整过程比较减少评分的明确歧义，跨状态功能与回报学习该联系何时有控制用途。尚不能负责的说法是：这些关系已充分、M^T g_Q已排除任务识别、现有数据已能识别操作理解、或该组合必然超过MT。没有新增实验、probe、模型forward、实现或launch合同；仅把完整方法的可表示、可学习、可迁移条件和已有反证说清。

## 当前议案：学习哪些教学关系值得据此修订参数

以下保留上一版线性评分的完整推导，解释为受限特例；本轮复核及完整过程评分的收敛见上节，不能将此线性特例继续称为充分操作模型。

### 1. 改变E的学习对象

E定义为视频条件的实践评分：它学习在当前经历下，应重视教学中的哪些对象关系、变化和操作片段，并评价真实分支实现了多少这些内容。它不预测任意候选动作的后果，也不从动作坐标直接生成自由余切。共享训练的目标是：用这个评分更新完整LoRA之后，策略在独立观测、不同初态上更有用。最终监督仍来自合法动作FM与真实回报；实质改变是这些监督对真实后果的取舍负责，并通过实际参数更新检验取舍，而非把新增物理预测loss当成E的语义监督。

保留source起点、完整38-target/r8和真实实践。撤下后果模型f，不以新增预测器补链。本议案承接Phi的内容依据与真实干预方式，但替换其固定DTW目标；承接功能修订的完整参数消费者，但替换其自由动作能量。新假设不是“这些模块分别有效，所以组合有效”，而是“可由独立状态的控制后果学习的教学关系权重，能够纠正固定视觉进度与自由余切各自没有解决的取舍”。

### 2. 视频、实践和E的具体表示

视频按stride5保留真实双相机帧与内部顺序。source图像patch经物理关系读取器Phi形成手、匿名物体及关节的相对位置、朝向、开合与变化，并保留有效性/置信信息。Phi只用获准non-held视频的实际关系标签学习；新condition只从RGB预测，不读其teacher state/action。当前已有Phi/关系接口说明标签与读取可获得，不意味着现有checkpoint或全部标签已获本议案执行资格；正式复用仍须按固定allowlist审计。

候选教学关系k来自真实帧/片段中的关系与变化，不手写held任务阶段或操作程序。自身侧使用实际RGB、proprio、动作、环境关系与反馈；对象对应根据通用类别/视觉线索及相对关系形成候选，E可学习选择对应，不能先用任务ID指定正确对象。每个候选比较给出`m_bk`：分支b相对共同起点，在实现该教学关系方面的变化。它使用对象相对的关系，而不是要求复制世界坐标、速度和全部手路径。

具体地，对教学片段的关系起止值`rho_V0,rho_V1`、自身同类关系的当前值`rho_0`及实际前五动作执行后的`rho_b`，比较项包括目标差的减少`d(rho_0,rho_V1)-d(rho_b,rho_V1)`，以及自身变化与教学变化的方向/类型一致性。距离沿已有平移、旋转、关节和夹爪的物理单位处理，实际执行mask与有效关系mask保留；比较的是被干预执行段的真实后果，不把未执行动作或预测当观测。H提供此前关系已实现/仍保持的证据，w决定当前应该读取哪个教学片段；后续完整继续策略的真实success另作任务信用。旧DTW的一条全轨迹距离不再决定所有项的权重。

学习读取器以有序V、当前真实H和当前执行的功能上下文产生`w_theta,k(V,H)`，选择哪些教学关系、对象对应和时间片段对当前修订有用。用有界、非负的关系权重及一个零贡献选项表达取舍；不把每帧都当成必须复现的目标。语言用于目标/对象查询，执行policy仍读exact language，不另设语言到参数的字典分支。教学顺序与H的episode/reset边界进入读取；不把跨重置状态连成一段虚构进程。

最小形式是`A_b^video = sum_k w_theta,k(V,H) m_bk = -E_theta(V,H,branch_b)`。这里E是分支的学习代价，不要求所有比较项都能积分为同一个状态势函数，也不宣称最优policy不变。m由实际教学关系和实际分支后果形成，w负责学习用途。对同一组分支，w在采样前的当前H上确定；分支自己的后果只进入自己的m，避免把相关对照分支混成独立baseline。新分支、实际新LoRA执行及反馈进入后继H，再重读视频并改w。不是每条视频或每次重读都必须改变w；相同有效操作可以得到同一控制器。

这个表示有明确边界：准确关系不等于有用目标，非负权重只能组合当前视频提供的候选关系，不能创造缺失的操作证据。Phi误读、对象对应错误、非必要路径或未展示的接触机制仍可能限制方法。保留关系G/F与GT替换阴性，不把感知校准本身列为修复主张。共享Phi由事实标签训练，E的关系选择由下述控制目标训练；两类消费者明确区分。

### 3. 实践实际提供了什么算子

当前完整LoRA在自身真实状态产生完整native10动作；对实际前五动作做有已知密度的连续扰动及夹爪模式采样，从相同起点观察真实分支后果。继续策略、起始history与环境条件配对，沿用已有真实分支机制，不恢复teacher动作或拟合它们。夹爪信用来自Bernoulli模式score，不能把hard sign当普通可微函数。分支采样只给局部探索目标的信用，不称未扰动整条闭环的精确梯度。

令`J_i=d a_i/d Lambda`为当前完整38处权重算子的原生导数，`s_ib=d_mu log q(a_ib|mu_i)`为真实采样的score。定义`Gamma_ib=J_i^T s_ib`。在相同episode/decision权重下，修订为

`Lambda_plus = R8[Lambda + eta sum_ib Gamma_ib (A_ib^true + A_ib^video)]`。

真实success/reward作为固定任务信用，视频部分由E提供；共同起点/独立baseline只减方差。R8与功能尺度须作用于完整算子，两侧空间可变，不回到固定A首步坐标；当前native首写已有相关消费者，但递推完整实现尚未完成。真实尺度/投影的导数必须被学习消费，不能把E影响归一化掉。多个自身状态共同构成更新，不能据一处局部动作变好就宣称完整策略改善。

暂略投影/尺度，对单个当前上下文可写成`Delta Lambda_video = eta M(V,H) w_theta(V,H)`，其中`M=sum_b Gamma_b m_b^T`。M是实际分支与当前policy导数共同形成的有限样本响应估计，不是另一个待学的f或已知的真实环境Jacobian。它说明实践在链路中的实质作用：给出哪些完整参数方向可能实现视频中的哪些关系。M不必显式物化为大矩阵，实际消费者可按分支评分聚合余切后做native VJP。

这不扩大给定J的像空间，还受实际探索方向和rank8约束。最新native64降低了盲目信任该写入空间的支持；本议案保留J作为可计算更新工具，不称它已经拥有完整控制能力。后继当前LoRA与新访态会改变J/M，但循环本身不提供成功保证。

### 4. E怎样被独立状态教会

在合法non-held任务上，实际取得当前source/中间LoRA的H和真实分支，用E形成Lambda_plus；随后在同task、跨episode的独立动作query上计算完整policy FM。query动作只是外层共享训练标签，不进入V/H条件，也不直接作为新condition的LoRA拟合目标。

令`g_Q=d_Lambda_plus L_FM(Q)`。暂略R8/尺度的导数，实际单事件信用为

`d_theta L_FM = eta sum_b [g_Q^T Gamma_b] d_theta A_b^video`

或在线性关系评分形式下为`eta [M^T g_Q]^T d_theta w_theta`。完整实现须带上实际投影与尺度的导数；此处简写只为展示消费者。若某个分支所推动的参数方向会降低其它状态的功能误差，梯度会提高该分支对应关系的评分；若会破坏其它状态，梯度会压低它。这样E学习的是“应据哪种真实后果修改整套策略”，不只是预测局部几何是否像视频。

外层FM仍是surrogate；旧native、关系G/F等已说明它不能单独认证闭环。因此共享训练还要实际运行完整编译链，并在未参加该链适应的新初态评价最终固定LoRA，用真实回报训练同一个E。可在真实分支评分上加入已知密度的随机提案：均值是E评分，给定抽到的评分及固定事实特征后，native写入不再直接依赖theta。完整回报用`(R_Q-b) sum_j d_theta log q_theta(score_j|V,H_j,branches_j)`给整条评分路径信用；抽样值在score项中固定，不能用重参数化代入logprob消掉均值梯度。采用同一编译/输出规则训练与部署，不训练末端却选择oracle最好点。

这一整路径回报原则已经在旧Experience/source修订出现过，不计为新贡献。它在本议案中训练的是视频关系评分的取舍，不是另一个高维端点生成器或独立候选排序器。固定当前incoming/H的FM梯度只覆盖该次实际修订，不能冒称已经穿过环境分布或所有历史更新；完整路径回报承担额外信用，仍有方差和有限任务覆盖问题。

FM与真实回报可交错训练，不规定新的固定阶段或轮数。共享训练必须消费当前E产生的新参数与真实H，包括失败、成功、早期与后期；不能只重放一份source-H后宣称学会实践循环。Phi事实监督、E功能/回报目标及全部task权重必须在未来完整合同中明确，未登记的held离线标签不得参与。

### 5. 全失败时与新condition的实际过程

共享学习中，即使当前实践分支全部未完成任务，独立合法动作query仍能给出`M^T g_Q`，因此E不必等首次终局成功才学习中间关系的用途。E不拟合“沿当前policy继续的成功概率”，所以不能因当前继续策略全失败就把所有中间关系强标成零价值；它学习使用这个关系评分能否教出更好的参数。全失败不等于所有m相同；手与物体的相对变化仍可能有区分。反之，若所有实际分支都没有可区分后果，或所有对应参数方向都不能改善query，E确实无法凭空获得有效信用，不能靠重命名reward消除此限制。

新condition从raw source的identity LoRA开始，先取得自身真实经历。共享Phi/E冻结于本次编译期，w随新H重新推断；它不需要在held上取得离线动作标签或把每个失败片段强标成零价值。实践提供当前真实响应M，已学E提供哪些教学关系值得据此改善的先验与上下文取舍，二者共同写Lambda。执行修订后的Lambda，加入真实H并重新读取V；实际预算与证据决定停止，不设固定轮数、不要求二值成功每次严格增加。

最终冻结本链最后实际执行过的一套完整38-target/r8 LoRA；未执行的预算尾提案不作最终产物。之后Phi、E、H、分支器和修订器退出，policy仅以当前RGB/proprio/exact language闭环，不在最终新初态继续适应。自身动作只用于真实干预与score信用，没有先挑出或合成目标动作轨迹再BC。所有实践、重置、读取与评分探索按实际成本计入，最终评测反馈不训练E。

本议案希望减轻共享模型必须同时发现的关系：事实标签约束视频说了什么；真实干预给出当前怎样改变这些关系；跨初态功能/回报教E哪些改变值得转成完整参数修订。实践因此既改变参数响应，也通过H改变对教学对象、片段和关系用途的读取。示意例是“手路径接近但抽屉未动”与“手路径不同而抽屉被带动”；哪项应得高分由训练任务的独立控制后果学习，不为held手写答案。已完成的前置关系在H中变化后，后续读取可以转向另一操作；这是待学的上下文选择，不能由attention图直接宣称理解。

同一任务不同真实失败位置应产生不同的有用关系取舍；相同关系在不同布局下应仍形成对新初态有益的修订。这是本议案可失败的预测。若只把实践视觉分数做高、E权重有变化或FM下降，而完整新初态能力仍不改善，就仍没有解决EMBER，不能继续用局部正例保护这一假设。旧N16与native阴性使这个风险真实存在。

训练评分以改善使用该评分学习的策略，有已有方法学依据，例如[On Learning Intrinsic Rewards for Policy Gradient Methods](https://proceedings.neurips.cc/paper_files/paper/2018/file/51de85ddd068f0bc787691d356176df9-Paper.pdf)。该文不涉及本项目的视频信息墙、source/r8编译与最终冻结要求，也不为本方案提供EMBER性能证据；这里新增的具体选择是视频关系约束、真实干预响应和独立初态完整LoRA消费者。

当前只形成上述完整科学议案。真实分支是主要训练成本，现有MT/N16缓存不能冒充source起点的当前完整学习链；不从一次旧批吞吐推断整项共享训练时间。Owner要求先不开实验，本次0新模型/环境/GPU计算或实现，未来预算与执行合同尚未登记。

## 复核：后果准确没有补上视频目标的学习依据

Owner进一步要求将E的实际学习关系与旧负结果对齐。主讨论据实际消费者重新判断：这个分解改变了动作后果信用的表示、约束和校准方式，没有自动改变视频操作目标的监督。把前者写成后者的主要修复依据超出了现有论证；下述完整链路保留为已讨论候选，不据此实施。

旧FR形成`p_old = -d_a E_old(V,H,a)`；本稿形成`p_new = -J_f(x,a)^T d_y E(V,H,x,y)`，其中`y=f(x,a)`。真实转移损失`L_dyn(f(x,a),y_observed)`只教psi。在原议案中f不读V，事实loss也不训练视频Reader/E；自身物理坐标与视频patch之间没有因此新增一个已学习的语义对应。外层FM仍经最终LoRA、原生J、p与E混合导数返回Reader，完整回报仍给整条提案路径信用。

为看清信号，暂略rank重表示与尺度，固定当前incoming/H/J，令`Lambda_plus=Lambda-eta J_pi^T J_f^T e_theta`、`e_theta=d_y E`、`g=d_Lambda_plus L_FM`，则`d_theta L_FM=-eta (d_theta e_theta)^T J_f J_pi g`。实际rank/尺度的导数改变这个传递算子，不新增视频语义标签。f可能使旧外层标签更容易教E，也可能更准确地传递错误视频目标；准确性本身没有决定哪种情况发生。全失败转移给f密集事实标签，不等于已经给E密集的正确操作目标。

一个明确反例是准确的`f(x,a)=a`：新式直接退化为旧动作能量。更一般地，在固定x/H的局部光滑可逆后果坐标下，定义`E_tilde(V,H,x,a)=E(V,H,x,f(x,a))`，函数形式可以吸收到一个条件动作能量中；不声称两套有限网络等容量或同样易学。物理分解可能改变统计效率与优化，不能由此推出表达能力或视频理解必然提高。若后果表示丢失动作方向，`p_new`还受`range(J_f^T)`限制。这不证明所有模型分解无效，而是反驳“学准f便解决E”的推理。

## 具体模块和条件内过程
A. 视频记忆M：stride5双相机真实RGB经冻结source视觉特征，再保序编码。保留patch和时序内容，不把整个视频压成固定Phi坐标/DTW距离。exact language用于对象/目标查询，policy仍读exact language；没有独立task-ID或语言到参数的索引分支。视频侧不读teacher动作、state、成功或对象pose。当前讨论K1，不据此宣称dynamic-K已实现。
B. 真实H：当前完整LoRA实际执行产生自身RGB、proprio、执行动作及mask、reward/terminal；允许新增自身物理观测x，包括手端/夹爪、对象/关节状态和接触等。当前原生H缓存没有完备物理标签；不能把policy-code零向量当物理state。既有PhysicalEntities只提供部分位置/朝向/关节结构，速度/接触/逐动作物理后果需要实际采集，不能从teacher标签补。
C. 物理后果模型f_psi(x,a_1:5)：预测实际将执行动作所造成的逐步物理变化及接触分布。包括机器人运动，不能只预测物体位移而令接触前信用全部为零。预测值不是观测事实。f不输入teacher视频/任务ID，也不生成正确动作。
   新condition复制共享f，更新带state-action交互的局部适应块psi_c；损失为真实执行后的物理预测误差。不是仅改与动作无关的偏置。旧行为的动作和后果始终成对；当前LoRA在旧真实观测上的新动作只能用f作反事实预测，不能冒充已经发生。
D. 学习准则E_theta：以自身当前视觉/物理状态、实际变化、模型残差和H为query，读取有序M；对f预测的物理后果输出标量代价。可微候选动作只经f进入E，E没有另一条直接候选动作→余切通路。H中的已执行动作是固定事实条件。视频的贡献是学习哪些后果与操作内容有用；f负责哪些动作可能造成这些后果。注意力位置或物理预测准确不单独构成理解证据。
E. 参数写入：a_i=F_Lambda(o_i,L,epsilon_i)必须用真实RGB/proprio、完整原生prefix及十步flow，取前五动作；J_i是当前完整38处附加权重算子的导数。连续部分p_i=-d_a E_theta(M,x_i,f_psi_c(x_i,a),H)|a_i。于是G=sum_i J_i^T p_i/n，Lambda_new=R8(Lambda+eta G)。R8表示每层完整算子重新表示为rank8，两侧空间可变；可沿现有范围迭代接口构造，不声称是最优SVD。尺度按真实动作响应处理，继承native首写的功能尺度理由，不称新原理。
   该式定义递推方法，不把现有仅source首写的代码宣称为已经完成递推。所有38处共同作用于自身执行hidden；不限定旧参考bank或固定A子空间。rank8、有限支撑点和跨状态Jacobian仍约束可达修改，完整38不等于任意函数修改。
   夹爪部署取sign，不能用普通导数穿过sign。用f分别预测真实开/关模式后果，按raw输出诱导的Bernoulli概率计算期望E并形成模式信用；这是可训练替代目标，最终硬符号控制仍须由真实闭环回报约束。连续接触的后果导数也来自学得模型，不称真实模拟器精确梯度。
F. 执行Lambda_new，获取新H，校准f并重新读V、形成后继完整Lambda。当前参数沿这条真实学习链更新，不以二值成功必须严格增加作为每次更新的接受条件，避免全失败时所有中间修改都被退回；不再训练一个独立候选排序器。轮数由实际预算、信息和表现决定；实践覆盖不同起始布局，所有检查计入适应预算，最终评测场景隔离。最终冻结本链最后实际执行过的完整Lambda；预算尾尚未实际执行的新提案不能当最终产物。共享学习和独立新初态回报必须训练同一出口，不能训练末端却部署oracle最佳点。最终仅source+一套Lambda运行，f、E、H、特权state和修订器全部退出。不在最终执行时看video或继续适应。

## 共享训练的实际标签和梯度消费者
1. f的训练数据是真实(x,a,x')，短真实动作分支约束邻近动作的不同后果。只拟合同一已见动作的值不能识别斜率。共享初始化采用过去转移更新psi_c、另一批后续真实转移评价更新后的预测损失，使模型实际学会校准，而非全局训练后假定随意微调有效。成功和失败转移都有标签。物理模型只接受事实预测信用，不由FM把它变成无物理含义的余切decoder。
2. Reader/E的密集目标：在合法non-held任务上，真实当前Lambda/H经过上面完整编译得到Lambda_new；同task、不同teacher episode的原始动作query只在外层给出原生FM损失。梯度FM→完整Lambda_new→rank8算子/尺度/J→p→E/Reader。动作query、参考答案不进入Compiler条件。当前事件固定incoming/J，对theta可求真实混合导数，不需对source权重求Hessian；此前修订/环境分布不伪称自动被这项事件梯度覆盖。
3. 完整回报目标：在non-held任务上实际运行整条编译过程，然后用未参加该过程适应的新初态评估最终固定LoRA。共享E产生有已知密度的余切提案q_theta(p|M,H,Lambda)，native写入本身给定p后确定；真实回报通过(R-b)sum_j grad_theta log q_theta(p_j|M,H_j,Lambda_j)训练整条提案路径，包括最终退出部署的中间尝试，不能只给最后一次修订信用。H、incoming及样本p按score-function的条件取值处理，不能误将重参数化样本代入logprob消掉均值梯度。f有独立事实学习路径；本条只训练共享准则/读取器。
4. FM提供密集操控学习，完整回报约束真实访问分布、信息获取和跨初态效果；可在同一共享训练中交错，不把旧固定两阶段或固定轮数当硬原则。训练必须真实消费当前模型产生的新参数/H，包括失败与成功、早期与后期；不能只在同一source-H缓存训练后宣称已学多轮反馈。
5. 共享梯度仅来自train24及明确审计授权的non-held任务；新validation/test教学不读离线标签。新condition的自身动作只作为f的输入及真实经历，不成为最终LoRA的动作拟合目标。此方法不准备动作轨迹后BC，不从最终评测反馈产生梯度。

## 为何值得考虑及什么仍是科学未知
任务内失败也提供大量动作后果标签；共享训练负责把教学内容和这些可校准后果连接到完整策略能力，避免任务内全失败时只能等待首次终局成功才有学习信号。它不能保证新task目标或未访问阶段自动学会：E的迁移、f的局部反事实质量、J与rank8的跨状态作用均须真实结果支持。
超过MT的机会来自教学决定操作偏好、实践补上当前动作后果证据、最终参数形成可随自身状态变化的task专化控制；不是因为MT没有闭环RGB反馈，也不假设MT必可由本rank8参数族复现。已有reference容量和G/D增益支持存在余量，近期实践/query分离则要求完整共享学习真正针对泛化。
本稿不把动力学不准定为旧失败唯一根因。若已有f在当前状态本来准确，校准应接近不动；不能为制造H作用而人为要求改模型。若只改善f/实践而完整LoRA不改善，则这条分解未解决EMBER，而不能改口以局部效果为目标。现有native首写批至多回答写入/共享FM的有限问题，不能承担本稿完整方法证明。
