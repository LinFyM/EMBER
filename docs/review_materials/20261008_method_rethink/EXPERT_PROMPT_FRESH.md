**这次首要请你形成一套具体、完整的方法架构设计。**请对关键结构、信息流、训练目标和更新机制作出明确选择，给出你最推荐的完整方案。随后，再基于这套架构制定推进规划，以及遇到关键困难时的判断和调整原则。

Owner 后续会让主讨论负责长期自主分析、决策和接续，实验 session 负责实现、测试与运行。因此，这份设计需要成为后续研究的实际依据。尚未验证的部分可以保留为假说，但核心学习过程应当有具体定义。

**当前第一阶段目标，是最终 source＋一套固定 LoRA 的完整任务表现明显超过强 MT。**可以采用你认为合理的训练与适应方式，不要求先证明优于同预算的充分语言适应，也不把所有视频因果对照设为开始工作的前置门槛。

方法的出发点始终是：**根据提供的教师视频，学习任务怎样完成，结合自身实践获得对应能力，最终将能力落实到 LoRA。**

请以以下信息边界为准：

- **训练 EMBER 时**，可以使用训练任务的动作标签、状态及其它合法监督。
- **validation 任务适应时**，离线教学输入只有指定视频及既定语言，不能额外读取其示范 episode 的动作、proprio、状态等配套标签。
- **模型自己与 validation 环境交互获得的信息可以使用**，包括自身动作、观测、环境状态、接触、奖励、成功和终止信号，也可以据此学习和更新。
- **已有模型及其内部计算可以充分利用**，包括 action expert hidden、完整 horizon、候选动作和预测结果；解释时区分模型推断与实际环境证据。
- **观看与实践可以进行多轮**，可以重看完整视频或相关片段，在实践、理解和参数修订之间反复循环，没有“一遍或两遍”的限制。
- **适应结束后，每个教学条件最终形成唯一一套完整、固定的 LoRA**，安装到 source 上，在未参与适应的新初态独立评测。最终不再更新参数，适应期的搜索、外部阶段选择等辅助模块退出。

Owner 一直使用“学习乒乓球发球”的例子。请准确理解这个类比：

| 乒乓球学习中的情形                | EMBER 中对应的内容                              |
| ------------------------ | ----------------------------------------- |
| 学习者已有身体控制和运动基础           | source／MT 已经通过共享训练获得的控制能力                 |
| 观看别人成功发球的视频              | 输入 action-hidden 教学视频，观察怎样完成动作和任务         |
| 自己练习，感知自身动作和球的结果         | 模型实际执行动作，获得自身观测、环境状态、奖励及其它反馈              |
| 根据练习中的差距回看视频，再调整和练习      | 自身经验参与教学理解、行动选择与 LoRA 修订，可进行多轮            |
| 练习后形成稳定的发球能力             | 最终固定一套 LoRA，安装到 source 上，在新初态独立完成任务       |
| 假设采用另一种学习方式，由教练手把手给出正确动作 | 对应新任务上额外提供正确动作标签，用于监督模仿或纠正训练；本方案不依赖这种额外资料 |

“教练手把手”只是用于说明另一种信息来源，并不是当前方案中的实际模块。这个类比不否定训练 EMBER 时使用训练任务的动作监督，也不否定模型把自己实践得到的有效动作用于 FM 等训练；后者属于利用自身经验学习。

**教学理解与自身实践之间的联系，是架构中需要重点定义的部分。**

视频不仅可能提供最终目标和阶段名称，还可能展示接近方向、操作部件、退出方式、动作先后，以及过程中需要保持的条件。这些内容怎样改变实际动作候选、候选评价或参数更新？

自己的实践结果怎样进入下一次视频理解？例如，模型实际退出时把抽屉关回去了，它怎样结合这次经历重新理解教师的释放与退出过程，并产生更有针对性的下一次尝试？

请充分考虑 source／MT 的动作知识和完整 action horizon，也可以选择其它更合适的读取方式。关键是具体解释：已有能力、视频证据和环境反馈怎样共同形成有效控制。

多次观看应当如何组织，也请由方法需要决定。可以重读完整视频，可以针对相关片段，也可以让当前已经学习的策略参与后续理解。请说明这些操作在实际计算中怎样受到新经验影响。

**训练目标和 LoRA 更新机制也需要完整定义。**

训练任务的动作标签分别怎样用于共享能力、动作评价或其它必要模块？教学读取器通过什么监督和实际消费者获得功能信用？

到 validation 适应时，自己的哪些经历用于更新哪些参数？怎样区分完整成功、有效局部行为和失败经验？失败经验怎样帮助评价、探索或下一次理解？有效局部行为怎样进入当前 LoRA，从而改善后续实践？

请说明多阶段能力怎样在同一套 LoRA 中积累，以及如何处理新行为学习与已有能力保持之间的关系。具体采用 FM、价值学习、其它策略优化或组合方式，由你根据机制选择，但需要明确目标、标签来源、梯度消费者和更新过程。

还请明确适应结束后哪些模块退出，最终策略保留什么输入，并解释为什么它有机会独立完成此前依靠搜索、目标选择或特权状态评价完成的行为。

**在完整架构之后，请制定与它对应的渐进推进规划。**

请说明从什么最小但完整的学习循环开始，第一批工作主要解决哪项决定性未知，怎样利用已有模型与数据，以及哪些新工作确实必要。

之后，什么证据支持继续训练、扩大任务或初态范围，或者进入更完整的评测？什么情况下应该维持架构继续学习，什么情况下应当修订其中一条关键联系？

请给出合理的工作量和时间预期，并区分已有依据与需要实测的部分。每批工作应当产生能够改变判断的证据，并逐步接近最终性能目标。局部模块改善不能自动等于完整方法成立，早期不佳也不能自动触发整套换架构。

**最后，请挑出最关键的困难，给出能够支持自主接续的处理原则。**

例如：

- 视频能够描述目标，却没有帮助产生更有效的尝试；
- 候选动作长期缺少有效行为，或评价高分与真实效果不一致；
- 局部行为改善，但完整任务持续没有进展；
- 带搜索时能成功，最终固定 LoRA 却不能吸收；
- 学会后续阶段时，前面已经获得的能力明显退化；
- 适应初态有效，换新初态后失败。

不必穷举所有故障。请围绕你推荐架构最可能遇到的关键问题，说明竞争解释、优先查看的证据、最小辨识方法、合理修订方向，以及什么结果应当降低某项核心假说的支持度。

这些原则应帮助主讨论在既定目标下自主判断和推进，避免每个障碍都等待 owner 指定下一步，也避免无限续训、参数小扫或不断换模块。

请继承已有正反证据，区分工程违约、学习尚未充分和方法假说受到削弱。规划应支持依据实际结果修订，不要求预先保证成功。

请用一个具体操作任务贯穿你的架构说明：

**怎样读教学 → 怎样尝试 → 反馈提供什么新认识 → 怎样回看和修正理解 → 怎样更新同一套 LoRA → 怎样逐步获得完整能力 → 怎样固定后独立完成任务。**

这个循环可以进行多轮。请先把具体完整架构设计清楚，再给出由该架构推导出的推进规划与困难处理原则。
